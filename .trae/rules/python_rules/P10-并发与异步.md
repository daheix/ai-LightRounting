# 规则 P10：并发与异步

### 10.1 选型
| 场景 | 推荐方案 | 理由 |
|------|---------|------|
| CPU 密集 | `multiprocessing.Pool` | 绕过 GIL |
| I/O 密集 | `asyncio` | 协程轻量 |
| 混合 | 进程池 + 协程 | 各取所长 |
| 数值并行 | JAX `vmap`/`pmap` | 向量化/多核 |

### 10.2 禁止
- ❌ 禁止 `threading` 做 CPU 密集任务（GIL 限制）
- ❌ 禁止全局可变状态（线程安全灾难）
- ❌ 禁止未设超时的网络/锁操作（死锁风险）
