# R12 时间戳规范（强制）

每个聊天消息和操作记录必须带时间戳。

## 1. 聊天时间戳
- 每次回复用户时，开头标注当前时间戳：`[YYYY-MM-DD HH:MM:SS CST]`
- 长时间任务的进度汇报必须包含时间戳

## 2. 操作记录时间戳
- `操作记录.md` 每条记录必须包含精确时间戳
- 格式：`### YYYY-MM-DD HH:MM 轮次编号`
- 禁止遗漏时间戳

## 3. 提交信息时间戳
- git commit message 可选附带时间戳（长任务推荐）
- 保活脚本输出必须带时间戳（已在 keepalive.sh 实现）

## 4. 日志时间戳
- 所有日志文件（auto_commit.log/keepalive.log）每行必须带时间戳
- 格式：`[YYYY-MM-DD HH:MM:SS]`

## 违规处理
| 违规 | 处理 |
|------|------|
| 聊天无时间戳 | 补充时间戳后重新发送 |
| 操作记录无时间戳 | 追加时间戳 |
| 日志无时间戳 | 修复日志格式 |
