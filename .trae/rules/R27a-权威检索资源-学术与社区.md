# 规则 R27：权威检索资源清单（强制使用）— 学术与社区

研发专属可公开检索权威资源总清单。所有架构疑难、性能瓶颈、技术短板必须优先检索以下资源。

## 一、国际顶级学术期刊与会议
1. arXiv — 预印本库，最新 AI/架构/算法论文 https://arxiv.org
2. IEEE Xplore — 工科/计算机/分布式权威 https://ieeexplore.ieee.org
3. ACM Digital Library — 计算机最高权威 https://dl.acm.org
4. SpringerLink — 工程/软件系统 https://link.springer.com
5. ScienceDirect (Elsevier) — 软件工程/系统架构 https://www.sciencedirect.com
6. Nature Computer Science — 前沿研究 https://www.nature.com/ncommsci
7. MDPI — 开源工程期刊 https://www.mdpi.com
8. USENIX — 系统/分布式顶会 https://www.usenix.org
9. VLDB / SIGMOD — 数据库/存储权威

## 二、海外研发工程师实战论坛
1. Stack Overflow — 问题解决第一社区 https://stackoverflow.com
2. Hacker News — 架构师讨论 https://news.ycombinator.com
3. Reddit r/programming — 工程实践 https://reddit.com/r/programming
4. Dev.to — 高质量实战博客 https://dev.to
5. Medium Engineering Blog — 大厂技术专栏 https://medium.com
6. InfoQ International — 架构案例 https://infoq.com
7. CodeProject — 工程代码案例 https://www.codeproject.com

## 三、顶级开源官方研发社区
1. GitHub Discussions — 官方架构讨论 https://github.com
2. GitHub Issues — 真实 bug/修复方案 https://github.com
3. GitLab Community — 企业架构/CI-CD https://about.gitlab.com/community
4. Apache Community — 中间件官方讨论 https://community.apache.org
5. CNCF Community — 云原生/微服务标准 https://www.cncf.io

标准与智库见 R27b。
