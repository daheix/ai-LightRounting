# 规则 R26：学术诚信与质量来源（强制）

本项目为科研型工程，所有算法、参数、数据、方案必须遵守学术诚信，质量来源必须真实可溯源。

## 强制要求

1. **禁止抄袭**：禁止复制他人代码而不标注来源
2. **来源标注**：所有引用的算法/参数/模型/数据集必须标注：作者/机构、标题、年份、URL 或 DOI
3. **参考内部文档**：质量来源优先参考项目内部文档的文件名与子标题作为溯源依据
4. **参数须溯源**：所有物理参数（折射率/损耗/弯曲半径等）须标注来源文献或 PDK
5. **禁止假数据**：禁止编造未经文献或实验验证的参数与结果
6. **引用须准确**：引用的论文须实际检索核实，禁止仅凭标题臆断内容

## 引用格式

代码引用算法或参数时：
```python
"""模块说明。

来源:
- 论文: Author et al., "Title", Conference/Journal Year, https://doi.org/...
- 仓库: https://github.com/org/repo (协议: MIT)
- 内部文档: 2026-2028开发计划/功能清单与实现/A01-RCWA严格耦合波分析.md §3.1
"""
```

## 禁止行为
- ❌ 禁止洗稿（变量重命名掩盖抄袭）
- ❌ 禁止选择性引用（只引用支持自己结论的部分）
- ❌ 禁止数据造假（伪造实验结果/性能数据/对比基准）
- ❌ 禁止编造 URL
