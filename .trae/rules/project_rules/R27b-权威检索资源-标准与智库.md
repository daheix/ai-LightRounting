# 规则 R27：权威检索资源清单（强制使用）— 标准与智库

## 四、国际技术标准与规范
1. IETF RFC — 网络协议唯一权威 https://www.rfc-editor.org
2. W3C — 前端/协议/数据格式标准 https://www.w3.org
3. OASIS — 分布式/消息/安全规范 https://www.oasis-open.org
4. OpenAPI Official — 接口契约标准 https://www.openapis.org
5. ISO/IEC 软件工程标准 — 架构/质量 https://www.iso.org

## 五、海外高端技术智库
1. Google Research — 分布式/性能前沿 https://research.google
2. Meta Engineering Blog — 大规模系统实践 https://engineering.fb.com
3. Amazon AWS Architecture Blog — 云架构最佳实践 https://aws.amazon.com/blogs/architecture
4. Microsoft Research — 软件工程治理 https://www.microsoft.com/en-us/research
5. Cloudflare Blog — 网络/性能/抗雪崩 https://blog.cloudflare.com
6. Netflix Tech Blog — 微服务容错标杆 https://netflixtechblog.com

## 六、专项高性能/架构垂直社区
1. High Scalability — 高并发架构案例 https://highscalability.com
2. Database Internals — 存储/事务/锁机制 https://databaseinternals.com
3. Martin Fowler Blog — 架构/重构/建模权威 https://martinfowler.com

## 使用规则
1. 架构疑难/性能瓶颈/技术短板必须优先检索以上海外资源
2. 解决方案须交叉验证：国外工程实践 + 学术论文 + 官方标准
3. 项目劣势须找到最新 3 年内最优开源方案/学术改进方案
4. 权威优先级：国际顶会 > 大厂官方博客 > 海外高赞社区 > 国内内容
