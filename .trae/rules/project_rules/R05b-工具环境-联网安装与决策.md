# 规则 R05：工具环境安装与使用规范（强制）— 联网安装与决策矩阵

## 5.1.2 联网 pip 安装（备用方案，离线包不可用时）

仅当离线 wheel 包不存在、不兼容当前平台、或需安装新工具时使用：

```bash
pip install numpy scipy networkx torch gymnasium matplotlib pyyaml   # 全部依赖（联网安装）
pip install klayout simphony sax
pip install pytest ruff mypy wheel setuptools
pip install -e .                                                      # 安装本项目（开发模式）
```

**未安装工具说明**（项目未直接使用，无需安装）：gdsfactory/gdstk（版图生成，项目用自研 PDK）；SiPANN（已有 pyCopySiPANN 完整复刻）；meep（项目未使用器件级 FDTD）；femwell/meow（FEM 模式求解器，项目未使用）；shapely（constraint_checker 用纯 Python 实现）。

**重要**：联网安装新工具后，必须同步更新离线 wheel 包（规则 5.5.1）。

## 5.2 工具安装决策矩阵

| 工具 | 是否安装 | 决策依据 |
|------|---------|----------|
| numpy/scipy/networkx/matplotlib/pyyaml | ✅ 必装 | 核心依赖，pip 即用 |
| torch | ✅ 必装 | GNN/PPO 训练核心（CPU 版 2.12.1+cpu） |
| gymnasium | ✅ 必装 | RL 环境核心 |
| klayout | ✅ 必装 | GDS 导出 + DRC |
| simphony | ✅ 必装 | S 参数仿真 |
| sax | ✅ 必装 | 已离线打包（含 jax/jaxlib/optax 依赖链） |
| pytest/ruff/mypy/wheel/setuptools | ✅ 必装 | 开发工具链 |
| gdsfactory/gdstk | ❌ 未装 | 版图生成，项目未直接使用 |
| SiPANN | ❌ 未装 | 依赖 tensorflow 无 Py3.14 wheel，已有 pyCopySiPANN 复刻 |
| meep | ❌ 未装 | FDTD 重型依赖，项目未使用 |
| femwell/meow | ❌ 未装 | FEM 模式求解器，项目未使用 |
| lygadgets | ❌ 未装 | KLayout 已直接安装 |
| shapely | ❌ 未装 | constraint_checker 用纯 Python 实现 |

注：所有 ✅ 必装工具均已在 `3dtool/wheels/` 离线打包，由 install.sh 统一安装。
