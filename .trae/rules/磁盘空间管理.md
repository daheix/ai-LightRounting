# 磁盘空间管理规则

## 1. 核心原则

PoLaRIS 项目运行在远程沙箱环境中，磁盘空间有限。当空间不足时，必须按以下规则清理，**优先删除系统冗余工具，保留 PoLaRIS 开发必需的 Python 环境**。

## 2. 主要冗余识别（可删除）

以下系统自定义安装的工具占用大量空间，且 PoLaRIS 不依赖它们，**可全部删除**：

| 工具 | 路径 | 占用空间 | 删除命令 |
|------|------|----------|----------|
| swiftly | `/root/.swiftly` | 6.5G | `rm -rf /root/.swiftly` |
| mise | `/root/.mise` | 3.0G | `rm -rf /root/.mise` |
| rustup | `/root/.rustup` | 1.8G | `rm -rf /root/.rustup` |
| cargo | `/root/.cargo` | ~1G | `rm -rf /root/.cargo` |
| go | `/root/.go` / `/usr/local/go` | ~1G | `rm -rf /root/.go /usr/local/go` |
| npm 全局缓存 | `/root/.npm` | ~0.5G | `rm -rf /root/.npm` |

**合计可释放：约 13.8G+**

## 3. 保留清单（禁止删除）

以下为 PoLaRIS 开发必需，**禁止删除**：

### 3.1 Python 环境（核心）
- `pyenv` 及其安装的 Python 3.13.13（`/root/.pyenv`）
- pip 缓存（`/root/.cache/pip`）— 可定期清理但保留目录

### 3.2 PoLaRIS 项目
- `/workspace` — 项目根目录
- `/workspace/.git` — Git 仓库

### 3.3 系统必需
- `/usr/bin`、`/usr/lib`、`/usr/local/bin` — 系统二进制
- `/root/.ssh` — SSH 配置
- `/tmp` — 临时目录（可清理内容，保留目录）

## 4. 空间检查命令

```bash
# 检查磁盘总使用情况
df -h /

# 检查 /root 下各目录占用
du -sh /root/.*/ 2>/dev/null | sort -rh | head -20

# 检查 PoLaRIS 项目占用
du -sh /workspace

# 识别大文件（>100M）
find /root /workspace -type f -size +100M 2>/dev/null
```

## 5. 清理执行流程

当 `df -h /` 显示使用率 > 85% 时，按以下顺序执行：

### 步骤 1：删除系统冗余工具
```bash
rm -rf /root/.swiftly /root/.mise /root/.rustup /root/.cargo /root/.go /usr/local/go /root/.npm
```

### 步骤 2：清理 pip 缓存（保留目录）
```bash
pip cache purge 2>/dev/null || rm -rf /root/.cache/pip/*
```

### 步骤 3：清理临时文件
```bash
rm -rf /tmp/*.tmp /tmp/pytest* /tmp/polaris_* 2>/dev/null
```

### 步骤 4：清理 Python __pycache__
```bash
find /workspace -type d -name __pycache__ -exec rm -rf {} + 2>/dev/null
```

### 步骤 5：验证空间
```bash
df -h /
```

## 6. Git 仓库清理（可选）

如果 `.git` 目录过大：
```bash
cd /workspace
git gc --aggressive --prune=now
git repack -ad
```

## 7. 自动化建议

- 每次会话启动时检查磁盘空间
- 使用率 > 85% 自动执行步骤 1-4
- 清理后记录到操作记录.md

## 8. 禁止操作

- **禁止删除** `/root/.pyenv`（Python 环境）
- **禁止删除** `/workspace`（项目代码）
- **禁止删除** `/root/.ssh`（SSH 配置）
- **禁止 `rm -rf /`** 或任何可能导致系统不可用的操作
- **禁止删除** 系统必需的二进制和库

## 9. 学术诚信

本规则基于实际沙箱环境磁盘空间管理需求制定，清理目标经过实际验证（swiftly 6.5G、mise 3.0G、rustup 1.8G 均为实测值）。
