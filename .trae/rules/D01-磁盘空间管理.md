# 规则 D01：磁盘空间管理（强制）

PoLaRIS 项目运行在远程沙箱环境中，磁盘空间有限。当空间不足时，优先删除系统冗余工具，保留 PoLaRIS 开发必需的 Python 环境。

## 1. 主要冗余识别（可删除，合计可释放约 13.8G+）

| 工具 | 路径 | 占用 | 删除命令 |
|------|------|------|----------|
| swiftly | `/root/.swiftly` | 6.5G | `rm -rf /root/.swiftly` |
| mise | `/root/.mise` | 3.0G | `rm -rf /root/.mise` |
| rustup | `/root/.rustup` | 1.8G | `rm -rf /root/.rustup` |
| cargo | `/root/.cargo` | ~1G | `rm -rf /root/.cargo` |
| go | `/root/.go` `/usr/local/go` | ~1G | `rm -rf /root/.go /usr/local/go` |
| npm 全局缓存 | `/root/.npm` | ~0.5G | `rm -rf /root/.npm` |

## 2. 保留清单（禁止删除）
- `pyenv` 及其安装的 Python 3.13.13（`/root/.pyenv`）；pip 缓存（`/root/.cache/pip`，可定期清理但保留目录）
- `/workspace`（项目根目录）与 `/workspace/.git`（Git 仓库）
- `/usr/bin`、`/usr/lib`、`/usr/local/bin`（系统二进制）；`/root/.ssh`（SSH 配置）；`/tmp`（可清理内容，保留目录）

## 3. 空间检查命令
```bash
df -h /                                            # 检查磁盘总使用情况
du -sh /root/.*/ 2>/dev/null | sort -rh | head -20 # 检查 /root 下各目录占用
du -sh /workspace                                  # 检查 PoLaRIS 项目占用
find /root /workspace -type f -size +100M 2>/dev/null  # 识别大文件（>100M）
```

## 4. 清理执行流程（当 `df -h /` 使用率 > 85% 时按顺序执行）
1. 删除系统冗余工具：`rm -rf /root/.swiftly /root/.mise /root/.rustup /root/.cargo /root/.go /usr/local/go /root/.npm`
2. 清理 pip 缓存（保留目录）：`pip cache purge 2>/dev/null || rm -rf /root/.cache/pip/*`
3. 清理临时文件：`rm -rf /tmp/*.tmp /tmp/pytest* /tmp/polaris_* 2>/dev/null`
4. 清理 Python `__pycache__`：`find /workspace -type d -name __pycache__ -exec rm -rf {} + 2>/dev/null`
5. 验证空间：`df -h /`

## 5. Git 仓库清理（可选，`.git` 过大时）
```bash
cd /workspace && git gc --aggressive --prune=now && git repack -ad
```

## 6. 禁止操作
- **禁止删除** `/root/.pyenv`（Python 环境）、`/workspace`（项目代码）、`/root/.ssh`（SSH 配置）
- **禁止 `rm -rf /`** 或任何可能导致系统不可用的操作
- **禁止删除** 系统必需的二进制和库

自动化建议：每次会话启动时检查磁盘空间，使用率 > 85% 自动执行步骤 1-4，清理后记录到操作记录.md。本规则清理目标经过实际验证（swiftly 6.5G、mise 3.0G、rustup 1.8G 均为实测值）。
