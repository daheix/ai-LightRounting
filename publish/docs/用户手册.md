# PoLaRIS 用户手册

## 概述

PoLaRIS（光弈）是面向光电子芯片的 AI 自动布局布线引擎，支持 SOI / SiN / InP / LNOI 四大工艺平台。
本手册介绍如何使用 PoLaRIS 完成光子电路的自动布局、布线、仿真、GDS 导出与 DRC 校验。

## 快速开始

### 1. 安装

```bash
# 沙箱/离线环境首选：一键离线安装全部依赖（70 秒恢复）
bash 3dtool/wheels/install.sh --all

# 联网环境：开发模式安装
pip install -e ".[dev]"
```

详细安装步骤见 [安装指南.md](./安装指南.md)。

### 2. 运行第一个电路（CLI）

```bash
# 端到端：网表 → 布局 → 布线 → GDS/OAS/PNG → report.json
python -m polaris run --netlist data/benchmarks/mzi.json --output out/
```

输出文件：

| 文件 | 说明 |
|------|------|
| `out/layout.gds` | GDSII 版图（klayout 可打开） |
| `out/layout.oas` | OASIS 版图 |
| `out/layout.png` | 版图渲染图 |
| `out/report.json` | 损耗/长度/DRC 报告 |

### 3. 运行第一个电路（Python API）

```python
from polaris.data.specs import CircuitSpec, DeviceSpec
from polaris.pipeline.integrated import IntegratedPipeline, PipelineConfig

circuit = CircuitSpec(
    name="minimal_mzi",
    devices=[
        DeviceSpec(name="gc1", device_type="grating_coupler", width_um=10.0, height_um=10.0),
        DeviceSpec(name="mmi1", device_type="mmi_1x2", width_um=20.0, height_um=10.0),
        DeviceSpec(name="gc2", device_type="grating_coupler", width_um=10.0, height_um=10.0),
    ],
    connections=[
        ("gc1", "o1", "mmi1", "o1"),
        ("mmi1", "o2", "gc2", "o1"),
    ],
    canvas_w=200.0,
    canvas_h=200.0,
)

pipeline = IntegratedPipeline(PipelineConfig())
result = pipeline.run(circuit)
print(f"成功: {result.success}, 损耗: {result.total_loss_db:.2f} dB, DRC: {result.drc_passed}")
```

## 完整工作流

PoLaRIS 端到端流水线覆盖以下阶段：

```
网表 (YAML/JSON/GDS)
   ↓
布局 (FloorplanEnv + RL)
   ↓
布线 (WaveguideRouter + A*)
   ↓
仿真 (S 参数级联 + SimLoop 反馈闭环)
   ↓
GDS 导出 (klayout.db)
   ↓
DRC 检查 (constraint_checker)
```

### 1. 网表加载

支持多种格式（LiDAR PIC IR / PICBench / gdsfactory YAML / PhIDO / SiEPIC GDS）：

```python
from polaris.engine.netlist import load_netlist

# YAML/JSON 网表
net, devices, graph = load_netlist("data/benchmarks/mzi.json")

# 多格式自动识别
from polaris.data.data_loader import load_directory
circuits = load_directory("data/benchmarks/", fmt="auto")
```

### 2. 从 GDS 文件提取电路（SiEPIC 格式）

读取 SiEPIC EBeam PDK 格式的 GDS 文件，自动提取器件与连接：

```python
from polaris.data.gds_loader import load_gds_to_circuit

circuit = load_gds_to_circuit("data/benchmarks/siepic_examples/RingResonator.gds")
print(f"提取: {len(circuit.devices)} 器件, {len(circuit.connections)} 连接")
```

GDS 解析依赖 klayout（`pip install klayout`），识别 DEVREC (68,0) 与 PIN (69,0) 层。

### 3. 布局（Placement）

布局引擎使用强化学习（PPO）自动放置器件：

```python
from polaris.engine.floorplan_env import FloorplanEnv, FloorplanEnvConfig
from polaris.engine.netlist import load_netlist

net, devices, _ = load_netlist("data/benchmarks/mzi.json")
env = FloorplanEnv(net, devices, config=FloorplanEnvConfig(
    canvas_w=200.0,
    canvas_h=200.0,
    grid_size=20.0,
))
obs, _ = env.reset()
```

### 4. 布线（Routing）

布线引擎使用 A* 算法 + 拥塞感知排序：

```python
from polaris.router.waveguide_router import WaveguideRouter

router = WaveguideRouter(
    placements=env.state.placements,
    netlist=net,
    canvas_w=200.0,
    canvas_h=200.0,
)
routes = router.route_all()
```

### 5. 仿真（S 参数）

S 参数级联仿真 + 仿真回馈闭环（SimLoop）：

```python
from polaris.sim.simulator import CircuitSimulator

sim = CircuitSimulator()
result = sim.simulate(circuit)
```

### 6. GDS 导出

通过 klayout.db 导出 SiEPIC 格式 GDS：

```python
from polaris.eval.layout_render import export_gds, run_drc

export_gds(placements, paths, "out/layout.gds")
drc_report = run_drc(placements, paths)
print(f"DRC 通过: {drc_report.passed}, 违规数: {drc_report.total_violations}")
```

### 7. DRC 检查

约束检查器支持 8 种违规检查（弯曲半径/间距/损耗/交叉/重叠/最小宽度/耦合间隙等）：

```python
from polaris.sim.constraint_checker import ConstraintChecker, ConstraintConfig

checker = ConstraintChecker(ConstraintConfig(
    min_bend_radius_um=5.0,
    max_insertion_loss_db=5.0,
))
violations = checker.check(placements=placements, paths=paths, context=ctx)
```

## CLI 用法

PoLaRIS 提供三个子命令：

### `run` — 端到端运行

```bash
python -m polaris run --netlist circuit.yaml --output out/
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--netlist` | （必填） | 网表文件路径（YAML/JSON） |
| `--output`, `-o` | `out` | 输出目录 |
| `--canvas-w` | 200.0 | 画布宽度 (μm) |
| `--canvas-h` | 200.0 | 画布高度 (μm) |
| `--grid-size` | 5.0 | 栅格大小 (μm) |

### `train` — PPO 训练

```bash
python -m polaris train --episodes 50 --output checkpoints/
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--episodes` | 50 | 训练轮次 |
| `--rollout-steps` | 64 | 每轮 rollout 步数 |
| `--num-netlists` | 50 | 训练数据集网表数 |
| `--canvas-w` | 200.0 | 画布宽度 |
| `--canvas-h` | 200.0 | 画布高度 |
| `--grid-size` | 5.0 | 栅格大小 |
| `--hidden-dim` | 64 | 神经网络隐藏层维度 |
| `--output`, `-o` | `checkpoints` | 检查点输出目录 |

### `catalog` — 器件目录查询

```bash
python -m polaris catalog --platform SOI
```

## Python API 用法

### IntegratedPipeline（推荐入口）

```python
from polaris.pipeline.integrated import IntegratedPipeline, PipelineConfig

# 无参调用：使用内置默认 MZI 电路
pipeline = IntegratedPipeline()
result = pipeline.run()

# 自定义电路
result = pipeline.run(circuit)
```

### SimLoop（仿真回馈闭环）

```python
from polaris.sim.sim_loop import SimLoop, SimLoopConfig
from polaris.sim.constraint_checker import ConstraintConfig

loop = SimLoop(
    placer=placer,
    router=router,
    simulator=simulator,
    config=SimLoopConfig(
        max_iterations=3,
        constraint_config=ConstraintConfig(min_bend_radius_um=5.0),
    ),
)
result = loop.run(circuit)
```

### GDS 读取与 SiEPIC 集成

```python
# 从 GDS 提取电路
from polaris.data.gds_loader import load_gds_to_circuit
circuit = load_gds_to_circuit("path/to/layout.gds")

# SiEPIC 器件名映射
from polaris.pdk.siepic_mapping import siepic_to_polaris, polaris_to_siepic
polaris_name = siepic_to_polaris("ebeam_y_1550")  # → "y_branch"
siepic_name = polaris_to_siepic("y_branch")        # → "ebeam_y_1550"

# gdsfactory 集成（可选，缺失时降级到原生 GDS 导出）
from polaris.pdk.gdsfactory_integration import generate_mzi_gds, is_available
if is_available():
    generate_mzi_gds("out/mzi.gds", delta_length_um=100.0)
```

## 配置选项

### PipelineConfig

`IntegratedPipeline` 的配置：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `canvas_w` | float | 1000.0 | 画布宽度 (μm) |
| `canvas_h` | float | 1000.0 | 画布高度 (μm) |
| `grid_size` | float | 10.0 | 栅格大小 (μm) |
| `max_sim_iterations` | int | 3 | SimLoop 最大迭代次数 |
| `router_type` | str | `"curvy"` | 布线器类型（curvy/diagonal/hybrid/opto_electrical） |
| `loss_target_db` | float | 5.0 | 目标插入损耗 (dB) |
| `min_bend_radius_um` | float | 5.0 | 最小弯曲半径 (μm) |
| `output_dir` | str | `"out"` | 输出目录 |
| `placement_checkpoint` | str \| None | None | RL 布局 agent 检查点路径 |
| `use_real_simulator` | bool | False | 是否使用真实 S 参数仿真器 |

### FloorplanEnvConfig

布局环境配置：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `canvas_w` | float | 1000.0 | 画布宽度 |
| `canvas_h` | float | 1000.0 | 画布高度 |
| `grid_size` | float | 10.0 | 栅格分辨率 (μm) |
| `overlap_penalty` | float | 3.0 | 重叠惩罚权重 |
| `hpwl_weight` | float | 0.01 | HPWL 线长权重 |
| `area_reward` | float | 0.5 | 面积利用率奖励权重 |
| `expert_shaper` | ExpertRewardShaper \| None | None | 专家奖励塑形器 |
| `state_encoder` | GNN \| None | None | GNN 状态编码器 |

## PDK 器件库

PoLaRIS 支持四大工艺平台：

| 平台 | 典型器件 | 用途 |
|------|----------|------|
| SOI | 波导/MMI/DC/Y分支/环/光栅耦合器 | 硅光集成 |
| SiN | 低损耗波导/低对比度器件 | 传感/低损耗 |
| InP | 有源器件/调制器/激光器 | 光源/高速调制 |
| LNOI | 铌酸锂波导/电光调制器 | 高速/低损耗 |

```python
from polaris.pdk import default_catalog

catalog = default_catalog()
print(f"总器件数: {len(catalog)}, 平台: {catalog.platforms}")

# 按平台/类别检索
soi_passive = catalog.list_devices(platform="SOI", category="passive")
```

## 训练框架

### PPO 训练

```bash
# 启动 2M 轮 RL 训练（自动断点续训）
python scripts/train_2m.py

# 查看训练进度
cat checkpoints/rl_2m/progress.json | python -m json.tool | head -10
```

### 专家奖励塑形

ICLR'26 专家知识注入 RL 奖励函数：

```python
from polaris.trainer.reward_shaping import ExpertRewardShaper, ExpertRewardInput

shaper = ExpertRewardShaper()
result = shaper.compute(ExpertRewardInput(
    device_positions={"a": (0.0, 0.0), "b": (100.0, 0.0)},
    connections=[("a", "p1", "b", "p2")],
))
print(f"专家奖励: {result.total_expert_reward:.3f}")
```

## 仿真校准

对比自研仿真与基准数据，验证仿真精度：

```python
from polaris.sim.calibration import calibrate, CalibrationConfig

result = calibrate(CalibrationConfig(
    benchmark_dir="data/benchmarks",
    loss_tolerance_db=0.5,
))
print(f"校准: {result.passed_items}/{result.total_items} 通过")
print(f"最大误差: {result.max_error_db:.2f} dB")
```
