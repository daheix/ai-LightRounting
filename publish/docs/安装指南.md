# PoLaRIS 安装指南

## 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Linux x86_64（推荐）/ macOS / Windows |
| Python | 3.9+（推荐 3.14） |
| 内存 | ≥ 4 GB（训练推荐 ≥ 8 GB） |
| 磁盘 | ≥ 2 GB（含离线 wheel 包） |
| GPU | 可选（PyTorch CPU 版即可运行，GPU 版加速训练） |

## 安装方式

### 方式一：离线一键安装（沙箱/离线环境首选）

PoLaRIS 将全部依赖打包为离线 wheel 包，沙箱重启后 70 秒即可恢复：

```bash
# 一键离线安装全部依赖（运行 + 开发）
bash 3dtool/wheels/install.sh --all

# 仅安装运行依赖子集
bash 3dtool/wheels/install.sh --core

# 仅安装开发依赖
bash 3dtool/wheels/install.sh --dev

# 仅检查环境（不安装）
bash 3dtool/wheels/install.sh --check
```

**离线 wheel 包结构**：
- `3dtool/wheels/*.whl`：小 wheel（<24MB，79 个，直接存放）
- `3dtool/wheels/parts/*.part_*`：大 wheel 分卷片段（≤20MB，18 个）
  - torch 184MB → 9 个分片
  - jaxlib 82MB → 5 个分片
  - scipy 34MB → 2 个分片
  - klayout 27MB → 2 个分片
- `install.sh` 自动合并分卷 + gunzip 还原 + pip install --no-index

### 方式二：联网 pip 安装

```bash
# 1. 克隆仓库
git clone https://github.com/daheix/ai-LightRounting.git
cd ai-LightRounting

# 2. 创建虚拟环境
python -m venv .venv
source .venv/bin/activate

# 3. 安装项目（开发模式）
pip install -e ".[dev]"
```

### 方式三：仅安装运行依赖子集（最小化安装）

```bash
pip install numpy scipy networkx gymnasium matplotlib pyyaml
pip install -e .
```

## 环境验证

安装完成后，运行以下命令验证环境：

```bash

bash 3dtool/wheels/install.sh --check

# 2. 验证运行依赖
python -c "import numpy, scipy, networkx, gymnasium, matplotlib, yaml; print('core OK')"

```

## 常见问题

### Q: 沙箱重启后依赖丢失怎么办？

A: 执行 `bash 3dtool/wheels/install.sh --all`，70 秒恢复全部依赖。

### Q: torch 安装失败怎么办？

A: 使用 CPU 版本：`pip install torch --index-url https://download.pytorch.org/whl/cpu`。
或使用复刻品 `pyCopyTorch`（纯 NumPy 实现，功能完整但速度较慢）。

### Q: sax 依赖链过大怎么办？

A: sax 依赖 jax/jaxlib/optax（200+ MB）。项目已用 `pyCopySAX` 完整复刻其子网络增长算法，
缺失 sax 时自动回退到复刻品。

### Q: 如何生成新的离线 wheel 包？

A: 在有网络的环境中执行：

```bash
pip download --dest 3dtool/wheels/ numpy scipy networkx torch gymnasium matplotlib pyyaml
pip download --dest 3dtool/wheels/ klayout simphony sax
pip download --dest 3dtool/wheels/ pytest ruff mypy wheel setuptools

# 大 wheel 分卷压缩（>24MB 的文件）
for f in 3dtool/wheels/*.whl; do
  size=$(stat -c%s "$f")
  if [ "$size" -gt 25165824 ]; then
    gzip -c "$f" | split -b 20M - "3dtool/wheels/parts/${f##*/}.gz.part_"
    rm "$f"
  fi
done
```
