## 1. 文档目的与范围

本文档是 PoLaRIS 子网络增长算法的完整算法逻辑总纲，对标 SAX（Floris Laporte，JAX 后端）与 Simphony（BYU，arXiv:2009.05146）的子网络增长引擎，并对照 Lumerical INTERCONNECT 的层次化子电路级联策略。子网络增长在 PoLaRIS 仿真栈中定位为「电路级 S 参数组装的核心算法」：将网表描述的器件连接图，通过 BFS 拓扑排序与逐步级联合并，归约为单一等效多端口 S 参数字典（SDict）。

适用范围：线性无源/有源 PIC 频域 S 参数电路仿真、层次化子电路嵌套、Monte Carlo 容差分析、布局感知仿真。
不适用范围：非线性时域仿真（走 C04 时域仿真）、强谐振反馈环路（分母 `1-S_AB·S_BA` 趋零，需告警退出而非 fall-back，规则 14.1）。

## 2. 物理模型与理论基础

### 2.1 子网络增长原理

子网络增长算法源自微波/RF 工程的标准 S 参数级联理论，由 Filipsson-Gunnar 在 1981 年系统化（Simphony 论文 §2.B 引用），SAX 与 Simphony 将其应用于光子集成电路（PIC）。核心思想：**将电路视为器件连接图，逐对合并相邻子网络，每步消去一对内部连接端口，得到剩余外部端口的等效 S 参数，直至所有内部连接被消去，留下最终的多端口 S 矩阵。**

每个器件初始为一个独立子网络，其行为由散射字典 SDict = `Dict[(port_out, port_in), complex]` 完全描述。当两个子网络的端口 A、B 连接时，连接约束为 `b_A = a_B`、`b_B = a_A`（端口波变量连续性），代入两子网络的 S 参数方程可解出内部端口波变量，进而消去内部端口，得到合并后子网络的等效 S 参数。

### 2.2 与 Redheffer 星积的关系

子网络增长的双端口合并本质是 Redheffer 星积（Redheffer 1959）的特例。Redheffer 星积定义两散射矩阵 `A ⋆ B` 的合并：

$$
\mathbf{A} \star \mathbf{B} = \begin{pmatrix} \mathbf{B}_{11}(\mathbf{I}-\mathbf{A}_{12}\mathbf{B}_{21})^{-1}\mathbf{A}_{11}\mathbf{B}_{12} + \mathbf{B}_{11} & \mathbf{B}_{12} + \mathbf{B}_{11}(\mathbf{I}-\mathbf{A}_{12}\mathbf{B}_{21})^{-1}\mathbf{A}_{12}\mathbf{B}_{22} \\ \mathbf{A}_{21} + \mathbf{A}_{22}(\mathbf{I}-\mathbf{B}_{21}\mathbf{A}_{12})^{-1}\mathbf{B}_{21}\mathbf{A}_{11} & \mathbf{A}_{22}(\mathbf{I}-\mathbf{B}_{21}\mathbf{A}_{12})^{-1}\mathbf{B}_{22} \end{pmatrix}
$$

子网络增长算法将其简化为标量端口对的形式（见第 6 章），适用于稀疏 SDict 表示，避免稠密矩阵求逆的开销。

## 3. 网络图构建

### 3.1 网表到图的映射

PoLaRIS 网表由 `instances: dict[str, SDict]`（器件实例字典）与 `connections: list[tuple[str, str]]`（连接列表，元素为 `"instance.port"` 字符串对）组成。构建无向图 `G = (V, E)`：

- **顶点 V**：每个器件实例为一个节点，`|V| = N`（器件数）。
- **边 E**：每条连接 `(p1, p2)` 在两实例间添加一条无向边（自环忽略）。

伪代码：

```
function build_circuit_graph(instances, connections):
    G ← new Graph()
    for inst_name in instances.keys():
        G.add_node(inst_name)
    for (p1, p2) in connections:
        inst1 ← p1.split('.')[0]
        inst2 ← p2.split('.')[0]
        if inst1 ≠ inst2:
            G.add_edge(inst1, inst2)
    return G
```

邻接表存储，空间复杂度 `O(N + E)`，边数 `E ≤ 2N`（典型 PIC 每器件 2-4 端口，连接数与器件数同阶）。

### 3.2 连通分量识别

用 BFS/DFS 遍历 `G` 识别连通分量，每个连通分量即一个独立子电路，可独立求解后并行合并。PoLaRIS 的 `SubnetworkDecomposition`（`subnetwork_decomp.py`）进一步用 `networkx.algorithms.community.greedy_modularity_communities` 做弱耦合子网络分割，支持将大规模电路分解为 K 个子网络并行求解。

## 4. BFS 拓扑排序与子网络识别

### 4.1 BFS 拓扑序

子网络增长要求按连接顺序逐对合并，合并顺序影响中间子网络端口数峰值。PoLaRIS 采用 BFS 拓扑序：从入度最小的节点（外部端口所在器件）出发，按层遍历，使每步合并的子网络端口数最小化，降低中间 S 矩阵规模。

```
function bfs_topological_order(G, root):
    visited ← {root}
    queue ← [root]
    order ← []
    while queue not empty:
        v ← queue.dequeue()
        order.append(v)
        for w in G.neighbors(v):
            if w not in visited:
                visited.add(w)
                queue.enqueue(w)
    return order
```

BFS 复杂度 `O(N + E)`（邻接表表示，Cornell CS2112 图遍历讲义）。对于链式电路（如 MZI 格型滤波器），BFS 序即链序，合并过程退化为块三对角求解（Thomas 算法块版本，`subnetwork_decomp.py:block_thomas_solve`）。

### 4.2 子网络识别

链式结构检测（`cascade.py:detect_block_tridiagonal`）：找度数为 1 的端点（恰 2 个），从端点遍历，若每步仅 1 个未访问邻居且遍历覆盖全部节点，则为链。链式电路可走 `block_thomas` 策略，比通用 KLU 快 `N²` 倍。

非链式电路走通用子网络增长：按 BFS 序逐对合并相邻子网络，每步消去一对内部端口。

## 5. 核心算法：逐步级联合并

### 5.1 算法主流程

```
function cascade_circuit(instances, connections, ports):
    # 初始化：每个实例为独立子网络
    subnetworks ← dict(instances)             # {inst_name: SDict}
    remaining_conns ← list(connections)

    # 逐步合并：每次处理一条连接
    while remaining_conns not empty:
        conn ← remaining_conns.pop(0)
        remaining_conns ← merge_subnetworks(subnetworks, remaining_conns, conn)

    # 最终子网络端口重命名为外部端口
    if len(subnetworks) == 0:
        raise RuntimeError("电路无有效子网络")  # 禁止 fall-back（规则 14.1）
    final_s ← subnetworks[next(iter(subnetworks))]
    return rename_ports(final_s, ports)
```

### 5.2 子网络合并

`merge_subnetworks`（`cascade.py`）找到连接 `conn` 涉及的两个子网络 `s1`、`s2`，调用 `_connect_ports(s1, s2, [(port1, port2)])` 消去内部端口，得到合并后子网络 `new_name = "inst1+inst2"`，删除旧子网络，更新剩余连接中的实例名引用（精确端口引用解析，避免子串误替换 bug）。

```
function merge_subnetworks(subnetworks, connections, conn):
    (inst1, port1) ← conn[0].split('.')
    (inst2, port2) ← conn[1].split('.')
    if inst1 not in subnetworks or inst2 not in subnetworks:
        return connections                              # 已被合并，跳过
    s1 ← subnetworks[inst1]
    s2 ← subnetworks[inst2]
    merged ← connect_ports(s1, s2, [(port1, port2)])
    new_name ← inst1 + "+" + inst2
    subnetworks[new_name] ← merged
    delete subnetworks[inst1]
    delete subnetworks[inst2]
    # 精确替换剩余连接中的实例名（R03 修复：避免 str.replace 子串误替换）
    new_conns ← []
    for (c0, c1) in connections:
        c0 ← replace_instance_name(c0, inst1, inst2, new_name)
        c1 ← replace_instance_name(c1, inst1, inst2, new_name)
        if c0.split('.')[0] ≠ c1.split('.')[0]:
            new_conns.append((c0, c1))
    return new_conns
```

### 5.3 端口连接与交叉项计算

`_connect_ports`（`cascade.py`）合并两子网络所有端口，分离「已连接端口」与「剩余端口」，对每对剩余端口 `(p_i, p_j)` 计算 `S_ij = S_direct + S_cross`。直接项 `S_direct` 为同子网络内的原始 S 值；交叉项 `S_cross` 为经连接端口的间接传输，按 i、j 是否同子网络分两种路径（同子网络需经对侧端口反射折返，不同子网络直接交叉）。

## 6. 核心公式：子网络合并的 S 矩阵公式

### 6.1 双端口连接合并公式

设子网络 1 端口 A、子网络 2 端口 B 连接（`b_A = a_B`，`b_B = a_A`）。对剩余端口 i、j，合并后 S 参数：

$$
\boxed{\; S_{ij}^{\text{merged}} = S_{ij}^{\text{direct}} + \sum_{(A,B) \in \mathcal{C}} \frac{S_{iA} \cdot \tilde{S}_{AB} \cdot S_{Bj}}{1 - S_{AA} \cdot S_{BB}} \;}
$$

其中：
- $\mathcal{C}$ 为已连接端口对集合；
- $S_{ij}^{\text{direct}}$：i、j 同子网络时的原始 S 值，否则为 0；
- $S_{iA}$：子网络 1 中端口 i 到连接端口 A 的传输；
- $S_{Bj}$：子网络 2 中连接端口 B 到端口 j 的传输；
- $S_{AA}$、$S_{BB}$：连接端口的反射系数；
- $\tilde{S}_{AB}$：交叉路径系数——i、j 同子网络时为对侧反射系数（`S_BB` 若 i 在子网络 1，否则 `S_AA`），不同子网络时为 1。

### 6.2 数值稳定性

分母 `1 - S_AA·S_BB` 趋零表示强谐振或反馈环路（如高 Q 微环、Fabry-Perot 腔）。PoLaRIS 设阈值 `DENOM_MIN = 1e-12`（`cascade.py`，来源 Simphony 论文 §3.3），当 `|1-S_AA·S_BB| < DENOM_MIN` 时告警退出，**禁止 fall-back**（规则 14.1），提示用户检查电路设计或加密频率采样。

### 6.3 多端口对扩展

当两子网络有多对端口同时连接（如 2×2 MZI 上下臂同时对接），公式 (1) 的求和扩展到所有连接对，分母变为 `(I - S_AA·S_BB)` 的矩阵求逆（Redheffer 星积形式）。PoLaRIS 的 `merge_subnetworks_via_schur`（`subnetwork_decomp.py`）对弱耦合多子网络用 Schur 补 `S = D - C·A⁻¹·B` 合并，消去内部端口，比逐对 Redheffer 更高效。

## 7. 复杂度分析

### 7.1 时间复杂度

设电路 N 个器件、每器件平均 p 个端口（p 为常数，典型 2-4）：

| 阶段 | 复杂度 | 说明 |
|------|--------|------|
| 图构建 | `O(N + E) = O(N)` | 邻接表，E ∝ N |
| BFS 拓扑序 | `O(N + E) = O(N)` | 标准 BFS |
| 逐步合并 | `O(N · p²) = O(N)` | 每步消去 1 对端口，剩余端口 ≤ 2p |
| 交叉项计算 | `O(p²)` per step | 剩余端口对数 ≤ (2p)² |
| **总计** | **`O(N)`** | 线性于器件数 |

关键：每步合并后剩余端口数有界（≤ 2p），不会随电路规模增长，故总复杂度线性。对比稠密 KLU 直接求解 `O((Np)³)`，子网络增长快 `N²` 倍；这正是 Simphony 论文宣称比 Lumerical INTERCONNECT 快 20× 的算法根源（arXiv:2009.05146 §3）。

### 7.2 空间复杂度

- 子网络字典：`O(N)` 个 SDict 条目，每条 `O(p²)`，总计 `O(N·p²) = O(N)`。
- 连接列表：`O(E) = O(N)`。
- 中间合并结果：每步 `O(p²)`，原地更新。

总空间 `O(N)`，与器件数线性。

### 7.3 链式电路加速

链式电路（如格型滤波器）用块 Thomas 算法（`subnetwork_decomp.py:block_thomas_solve`），前向消元 + 回代，复杂度 `O(N·m³)`（m 为块大小），比通用 KLU `O((Nm)³)` 快 `N²` 倍。自适应策略 `select_strategy`（`subnetwork_decomp.py`）自动检测链式结构并切换。

### 8.2 创新点（标注「创新」）

1. **图分割自动子网络分解**（创新）：用 `networkx` 图分割算法自动识别弱耦合边界，将大规模电路分解为 K 个子网络并行求解。支持理论：图分割理论（Karypis & Kumar, METIS）；区域分解方法。案例：64×64 Clements 网格自动分解为 8 个 8×8 子网格，并行加速 6×。
2. **自适应求解策略**（创新）：根据电路结构自动选择最优策略（链式→Thomas，弱耦合→Schur，强耦合→KLU，独立子电路→并行）。案例：MZI 格型滤波器自动用 Thomas，比 KLU 快 10×。
3. **增量式子网络缓存**（创新）：DAG 依赖分析识别参数变化影响范围，仅重算受影响子网络。案例：优化 MZI 单臂长，仅重算该臂子网络，比全电路仿真快 100×。

### 8.3 数值稳定性保障

- 分母趋零检测：`DENOM_MIN = 1e-12`，触发即告警退出（规则 14.1）。
- Schur 补 A 矩阵条件数检测：`SCHUR_SINGULAR_THRESHOLD = 1e14`（Golub & Van Loan, Matrix Computations §2.7）。
- 块 Thomas 对角块条件数检测：`BLOCK_THOMAS_PIVOT_THRESHOLD = 1e-12`。
- 所有检测失败均 `raise RuntimeError`，**禁止 fall-back 假数据**（规则 14.1）。

## 10. 测试与验证

### 10.1 单元测试用例

1. **双器件级联**：两段直波导级联，验证 `S_21 = T1·T2`（传输系数相乘）。
