## 2. 学术背景与商业工具对标

### 2.1 核心学术依据

时域光子电路仿真主要建立在三类数学框架之上：

1. **耦合模理论（CMT）时域形式**：CAPHE 框架（Fiers et al. 2012）将每个节点描述为状态变量 ODE，节点输出含线性 S 矩阵叠加与非线性状态函数。来源: https://biblio.ugent.be/publication/2036548/file/3146073.pdf
2. **速率方程建模**：激光器动力学由粒子数密度与光子数密度的非线性 ODE 描述，需用数值积分（RK4）求解。来源: https://www.rp-photonics.com/rate_equation_modeling.html
3. **传输线模型（TLM）**：将麦克斯韦方程离散为传输线网络上的电压冲激传播，天然支持时域双向仿真。来源: https://www.sci-hub.ru/storage/moscow/2275/34d15ada7a5462efcf8cc8cffd341bb4/romo2004.pdf

### 2.2 商业工具对标

| VPIphotonics | 时域+频域无缝合并：无源子电路频域 S 矩阵，有源时域接口 | 大规模 PIC（千级器件）精度高，无单时间步延迟 | https://www.vpiphotonics.com/Tools/PhotonicCircuits/ |

## 3. 核心数学模型

### 3.1 状态空间方程

时域光子电路可统一描述为状态空间形式：

```
dx/dt = A·x(t) + B·u(t) + f_nl(x, u, t)
y(t)  = C·x(t) + D·u(t) + g_nl(x, u, t)
```

其中：
- `x(t) ∈ R^n`：状态向量（谐振腔模式幅度、载流子密度、相位等）
- `u(t) ∈ R^m`：输入激励（外部光场、驱动电流）
- `y(t) ∈ R^p`：输出（端口光场、探测电流）
- `A, B, C, D`：线性系统矩阵（来自 S 参数频域拟合）
- `f_nl, g_nl`：非线性函数（克尔效应、增益饱和、速率方程非线性项）

### 3.2 CAPHE 时域 CMT 形式

CAPHE 框架（Fiers 2012 §III-B）将节点输出与状态演化分离：

```
节点输出:  s_out,i(t) = Σ_j S_ij · s_in,j(t) + g_i(a(t), s_in(t), t)
状态 ODE:  da_k(t)/dt = f_k(a(t), s_in(t), t)
```

其中 `a(t)` 为节点状态变量向量，`S_ij` 为线性散射矩阵，`g_i` 与 `f_k` 为非线性函数。

### 3.3 激光器速率方程（行波形式）

Lumerical TWLM 1D 行波速率方程（来源: https://optics.ansys.com/hc/en-us/articles/39727136204051）：

```
∂N(z,t)/∂t = η_i·I(t)/(q·V) - R(N) - v_g·g(N)·S(z,t)
∂S(z,t)/∂t = Γ·g(N)·S(z,t) - S(z,t)/τ_p + Γ·β·R_sp(N) + v_g·∂S/∂z
```

其中 `N` 为载流子密度，`S` 为光子密度，`g(N)` 为增益，`Γ` 为限制因子，`τ_p` 为光子寿命，`β` 为自发辐射耦合因子。

### 3.4 数值积分公式

#### 四阶 Runge-Kutta（RK4）

```
k1 = h·f(t_n,     y_n)
k2 = h·f(t_n+h/2, y_n + k1/2)
k3 = h·f(t_n+h/2, y_n + k2/2)
k4 = h·f(t_n+h,   y_n + k3)
y_{n+1} = y_n + (k1 + 2·k2 + 2·k3 + k4) / 6
```

局部截断误差 O(h⁵)，全局误差 O(h⁴)。来源: https://www.rp-photonics.com/encyclopedia.html

#### 梯形法则（Trapezoidal，隐式 A-稳定）

```
y_{n+1} = y_n + h/2 · [f(t_n, y_n) + f(t_{n+1}, y_{n+1})]
```

适用于刚性系统（stiff ODE），如载流子寿命与光子寿命相差悬殊的激光器方程。

## 4. 算法整体流程

```
1. 状态空间模型构建
   ├─ 遍历网络节点，收集状态变量，构建全局索引 {node.state_var: offset}
   └─ 装配线性矩阵 A/B/C/D（从频域 S 参数拟合）+ 记录非线性 ODE 句柄
2. 激励信号生成
   ├─ 高斯脉冲 / 阶跃 / PRBS / 正弦调制 / 任意波形
   └─ 构造 inputs(t) → {ext_port: amplitude} 闭包
3. 数值积分
   ├─ 选择积分器: RK45（自适应）/ RK4（定步）/ 梯形或 BDF（刚性）
   └─ 每步计算 dy/dt = A·y + B·u + f_nl(y, u, t)，误差控制 rtol=1e-6, atol=1e-9
4. 输出提取
   ├─ 状态时间序列 {state_name: array(n_times)}
   ├─ 端口输出 y(t) = C·x + D·u + g_nl
   └─ 后处理: FFT 频谱、眼图、BER、L-I 曲线
```

## 5. 状态空间模型构建算法

### 5.1 算法描述与伪代码

将异构光子电路节点（无源 S 参数元件 + 有源 ODE 元件）统一映射为全局状态向量。无源线性节点无状态变量，仅通过 S 矩阵贡献线性部分；有源节点贡献状态变量与非线性 ODE。复杂度: 状态索引构建 O(N_nodes · N_states)，矩阵装配 O(N_ports²)，典型中等 PIC ~100 状态变量 < 1ms。

```python
def build_state_space(network):
    """构建全局状态空间模型。"""
    state_names, state_offsets, offset = [], {}, 0
    # 步骤1: 收集所有节点的状态变量，建立全局索引
    for node in network.get_nodes():
        for sname in node.state_variables:
            global_key = f"{node.name}.{sname}"
            state_names.append(global_key)
            state_offsets[global_key] = offset
            offset += 1

    n_states = len(state_names)
    n_ports = network.n_external_ports

    # 步骤2: 装配线性矩阵（从频域 S 参数在中心频率处拟合）
    A = zeros((n_states, n_states))   # 状态-状态耦合
    B = zeros((n_states, n_ports))    # 输入-状态耦合
    C = zeros((n_ports, n_states))    # 状态-输出耦合
    D = assemble_scattering_matrix(network)  # 直接传输（S 矩阵）

    # 步骤3: 记录非线性函数句柄
    nonlinear_funcs = {}
    for node in network.get_nodes():
        if node.ode_func is not None:
            nonlinear_funcs[node.name] = node.ode_func

    return StateSpaceModel(A, B, C, D, state_offsets, nonlinear_funcs)
```

## 6. 激励信号生成算法

### 6.1 支持的激励类型

| 类型 | 数学形式 | 应用场景 |
|------|---------|---------|
| 高斯脉冲 | `u(t) = exp(-((t-t0)/τ)²) · exp(j·ω0·t)` | 瞬态响应、色散测量 |
| 阶跃信号 | `u(t) = A · H(t-t0)` | 开关特性、稳态建立 |
| PRBS | 伪随机二进制序列 @比特率 R_b | 数字调制、眼图 |
| 正弦调制 | `u(t) = A·(1 + m·cos(2π·f_m·t))` | 小信号调制响应 |

### 6.2 伪代码

```python
def make_gaussian_pulse(t0, tau, omega0, amplitude=1.0):
    """生成高斯脉冲激励闭包。"""
    def inputs(t):
        envelope = amplitude * exp(-((t - t0) / tau) ** 2)
        return {"in_port": envelope * exp(1j * omega0 * t)}
    return inputs

def make_prbs(bit_rate, n_bits, seed=42, amplitude=1.0):
    """生成 PRBS 激励闭包（NRZ 编码）。"""
    rng = Random(seed)
    bits = [rng.randint(0, 1) for _ in range(n_bits)]
    T_b = 1.0 / bit_rate
    def inputs(t):
        idx = int(t / T_b)
        return {"in_port": amplitude * (2 * bits[idx] - 1) if idx < n_bits else 0.0}
    return inputs
```

### 6.3 Nyquist 采样约束

时间步长 `dt` 必须满足 `dt ≤ 1 / (2 · f_max)`，其中 `f_max` 为光信号带宽。对于 1550nm 载波 + 40GHz 调制带宽，`dt ≤ 12.5ps`；若需解析载波振荡则 `dt ≤ 0.1fs`（包络仿真可降采样）。

## 7. 数值积分算法

### 7.1 积分器选择策略

```
IF 系统刚性（载流子寿命 << 光子寿命）:
    使用隐式梯形法则或 BDF（scipy method="Radau"/"BDF"）
ELIF 需要定步长（数据流调度、FIR 卷积）:
    使用定步长 RK4
ELSE:
    使用自适应 RK45（scipy.integrate.solve_ivp 默认）
```

### 7.2 ODE 系统构建与 RK45 求解伪代码

```python
def build_ode_system(t, y, inputs, state_space, network):
    """构建全局 ODE 右端函数 dy/dt = f(t, y, u)。"""
    dydt = zeros(state_space.n_states)
    current_inputs = inputs(t) if callable(inputs) else inputs
    u_vec = assemble_input_vector(current_inputs, network)
    # 线性部分: A·y + B·u
    dydt += state_space.A @ y + state_space.B @ u_vec
    # 非线性部分: 各节点 ODE 函数
    for node in network.get_nodes():
        if node.ode_func is None:
            continue
        node_state = extract_node_state(y, node, state_space)
        s_in = assemble_node_inputs(node, current_inputs, network)
        dstate = node.ode_func(t, node_state, s_in)
        scatter_node_state(dydt, dstate, node, state_space)
    return dydt

def solve_time_domain(state_space, t_span, inputs, y0=None, n_points=100):
    """RK45 自适应步长时域求解（scipy.integrate.solve_ivp）。"""
    from scipy.integrate import solve_ivp
    t_eval = linspace(t_span[0], t_span[1], n_points)
    sol = solve_ivp(
        fun=lambda t, y: build_ode_system(t, y, inputs, state_space, network),
        t_span=t_span, y0=initialize_state(state_space, y0),
        method="RK45", t_eval=t_eval, rtol=1e-6, atol=1e-9)
    if not sol.success:
        raise RuntimeError(f"ODE 求解未收敛: {sol.message}")
    return {"t": sol.t, "y": sol.y.T, "states": extract_state_series(sol)}
```

### 7.3 INTERCONNECT 数据流调度（FIR 卷积）

对于离散时间数据流仿真（`InterconnectTimeDomainSimulator`），每个元件用 FIR 滤波器表示冲激响应：

```
y(t) = Σ_{τ=0}^{T-1} h(τ) · x(t - τ)
```

调度算法：拓扑排序元件 DAG → 按时间步推进 → 每元件读输入缓冲、卷积 FIR、写输出缓冲。

来源: https://optics.ansys.com/hc/en-us/articles/360042323574

## 8. 输出提取与后处理

### 8.1 状态时间序列提取伪代码

```python
def extract_output(sol, state_space, inputs, network):
    """从解向量提取端口输出与状态序列。"""
    states_ts = {name: sol.y[:, i] for i, name in enumerate(state_space.names)}
    outputs = {port: zeros(len(sol.t), dtype=complex) for port in network.external_ports}
    for k, t in enumerate(sol.t):
        u_vec = assemble_input_vector(inputs(t), network)
        y_k = state_space.C @ sol.y[k, :] + state_space.D @ u_vec
        for p, port in enumerate(network.external_ports):
            outputs[port][k] = y_k[p]
    return {"states": states_ts, "outputs": outputs, "t": sol.t}
```

### 8.2 后处理指标

| 指标 | 计算方法 | 应用 |
|------|---------|------|
| 频谱 | FFT(y(t)) | 模式分析、谐波失真 |
| 眼图 | 叠加比特周期波形 | 数字通信质量 |
| L-I 曲线 | 稳态输出功率 vs 驱动电流 | 激光器表征 |
| 调制响应 | 小信号 FFT → S21 | 带宽测量 |
| BER/Q 因子 | 统计判决 | 通信链路（聚类 G03） |

## 9. PoLaRIS 现有实现详解

### 9.1 CAPHETimeDomainSolver（`src/polaris/sim/caphe_time_domain.py`）

基于 CMT 耦合模理论的 ODE 求解器。关键方法：`_build_state_index()` 构建全局状态索引；`build_ode_system(t, y, inputs)` 遍历节点调用 `node.ode_func` 构建 ODE 右端；`solve()` 调用 `scipy.integrate.solve_ivp`（RK45，rtol=1e-6, atol=1e-9）；`extract_states(y)` 提取状态字典。
学术依据: Fiers 2012 §III-B (https://biblio.ugent.be/publication/2036548/file/3146073.pdf)；依赖 scipy (https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.solve_ivp.html)

### 9.2 InterconnectTimeDomainSimulator（`src/polaris/sim/interconnect.py:91`）

INTERCONNECT 风格数据流调度器。拓扑排序元件 DAG（Kahn 算法，检测反馈环路告警退出）；按时间步推进，每元件 FIR 卷积 `y(t) = Σ h(τ)·x(t-τ)`；双向传播维护正向/反向缓冲区。验收标准: 高斯脉冲通过 1mm 波导，时域波形与解析解误差 < 1%。
学术依据: https://optics.ansys.com/hc/en-us/articles/360042323574

### 9.3 CAPHEBackend 统一后端与创新点

`CAPHEBackend` 提供 `simulate_time()` 统一接口封装 `CAPHETimeDomainSolver`，并支持与 sax 后端交叉验证（误差阈值 `CROSS_VALIDATE_TOL`，规则 R26 §1）。

**创新点（标注"创新"）**：自动稀疏化 — CAPHEBackend 自动检测无源线性节点并消去，无需用户手动标记。创新逻辑: 节点实例化时分析是否含状态变量/ODE；支持理论: 图论"叶子节点消去"；预期收益: 降低使用门槛。
