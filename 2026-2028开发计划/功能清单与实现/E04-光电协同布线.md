## 1. 文档概述与聚类定位

### 1.1 聚类定义

光电协同布线聚类（E04）覆盖电子-光子集成芯片（EPIC）中光波导与电金属互连在同一物理版图上的联合规划与详细布线。区别于 E01（纯光波导 A*/JPS-Bend）与 E02/E03（纯电金属通道/多层布线），E04 的核心特征是 **跨物理域协同**：光波导需弯曲半径约束与低损耗路径，电金属需曼哈顿走线与多金属层堆叠，两者在同一画布上争夺布线资源并存在交叉干扰约束。

## 3. 核心数学模型

### 3.1 光电联合布线代价函数

将光电协同布线形式化为约束最小化问题。设光网络集合 `N^opt = {n_i^opt}`，电网络集合 `N^ele = {n_j^ele}`，全局代价函数：

```
J = α · Σ_i L_opt(n_i)              # 光波导总长度（μm）
  + β · Σ_j L_ele(n_j)              # 电金属总长度（μm）
  + γ · Σ_i InsertionLoss(n_i)      # 光波导插入损耗（dB），≈ 2 dB/cm × L
  + δ · Σ_{i,j} Cross(n_i, n_j)     # 光电交叉数（每处 0.05 dB 串扰损耗）
  + ε · Σ_j ViaCount(n_j)           # 电金属通孔数（每孔 0.1Ω 电阻 + 5fF 电容）
  + ζ · Σ DRC_violations             # 设计规则违例（硬约束，罚值极大）
```

权重取值（来源: OptoSynthesizer arXiv 2604.15493 与 IMEC 130nm SiPh 工艺标定）：
- `α=1.0, β=0.1`（光波导成本远高于电金属，因损耗敏感）
- `γ=10.0`（1 dB 损耗对应 10 μm 等效长度）
- `δ=50.0`（光电交叉代价高，需热光调谐补偿）
- `ε=5.0, ζ=1e6`（DRC 为硬约束）

### 3.2 光波导损耗模型

```
InsertionLoss(n_i) = α_wg · L_straight + α_bend · L_bend + N_cross · α_cross
其中:
  α_wg     = 2.0 dB/cm   # 直波导传播损耗（来源: IMEC 130nm SiPh）
  α_bend   = 0.005 dB/°  # 弯曲损耗（与弯曲半径 R 相关，R≥5μm 时）
  α_cross  = 0.05 dB     # 波导-波导交叉损耗
```

PoLaRIS 实现简化为 `loss = 2.0 * length / 1e4`（dB，length 单位 μm），见 `opto_electrical.py:167`。

### 3.3 电金属延迟与寄生模型

```
T_delay(n_j) = R_wire · C_load + (R_via · N_via + L_wire/c) · jitter
其中:
  R_wire = ρ_Cu · L / (W · T)        # 铜电阻率 1.7e-8 Ω·m
  C_load = C_fringe · L + C_via · N_via
  R_via  = 0.1 Ω/孔                  # M1-M2 通孔（IMEC 标定）
  C_via  = 5 fF/孔                   # 通孔电容
```

电金属布线代价以 RC 延迟为主，与光波导的损耗代价在量纲上不可直接相加，故通过 `β=0.1` 折算到统一长度代价。

### 3.4 光电交叉串扰模型

当电金属线穿越光波导上方/下方时，金属-介质-波导形成寄生电容，引入光场微扰损耗：

```
C_parasitic = ε_ox · A_overlap / d_oxide
Δn_eff      = -(1/2) · n_eff³ · r_33 · E_field   # Pockels 效应（LN/Si 无，聚合物有）
Δα          = α_free_carrier · ΔN_electrons       # 自由载流子吸收（Si 基）
```

PoLaRIS 采用 **物理屏蔽等价策略**：将已布光波导通过 Bresenham 栅格化标记为电层障碍，使电金属 A* 自动绕开，等效于零交叉。剩余不可避免交叉通过 `δ · Cross` 项惩罚。

## 4. 算法整体流程

```
1. 输入解析
   ├─ 光网表 N^opt: [(net_id, start, end), ...]   # 单位 μm
   ├─ 电网表 N^ele: [ElectricalNet(net_id, start, end, layer, width), ...]
   └─ 工艺约束: min_bend_radius_um, metal_spacing, metal_width
2. 障碍物初始化
   ├─ add_optical_obstacle(rect): 光层已放置器件区域
   └─ add_electrical_obstacle(rect): 电层已放置器件区域
3. 光波导布线（先光后电策略，优先级高）
   ├─ 对每个 n_i ∈ N^opt 调用 CurvyRouter.route(start, end)
   ├─ 失败 → 撕除并重布（rip-up-reroute, E02 聚类）
   └─ 成功 → 路径栅格化并标记为电层障碍（_mark_optical_as_electrical_obstacle）
4. 电金属布线（避开光波导）
   ├─ 对每个 n_j ∈ N^ele 调用 GridRouter.route（曼哈顿 A*，min_bend_radius=0）
   ├─ 失败 → 切换金属层 M2/M3（多层布线，E03 聚类）
   └─ 成功 → 计算 crossings_with_optical（CCW 叉积法）
5. 全局优化（迭代）
   ├─ 计算 J = α·L_opt + β·L_ele + γ·Loss + δ·Cross + ε·Via + ζ·DRC
   ├─ 若 Cross > 0: 选择电金属重布（改层或改路径）
   └─ 若 J 未收敛: 返回步骤 3 重排光波导顺序（拥塞感知）
6. 输出 OptoElectricalResult
   ├─ optical_paths: {net_id: WaveguidePath}
   ├─ electrical_paths: {net_id: ElectricalPath}
   └─ 统计: total_optical_length, total_electrical_length, total_crossings, total_loss_db
```

## 5. 光电网络联合建模算法

### 5.1 算法描述

将光网表与电网表统一映射到同一栅格画布（grid_w × grid_h，grid_size μm/cell），共享障碍物坐标系但维护独立路由器实例。光路由器 `GridRouter` 配置 `min_bend_radius_um=5.0, min_spacing_um=1.0`，电路由器配置 `min_bend_radius_um=0.0, min_spacing_um=0.3`（金属更紧凑）。复杂度: 网表解析 O(N_opt + N_ele)，栅格构建 O(grid_w · grid_h)。

### 5.2 伪代码

```python
def build_opto_electrical_network(optical_nets, electrical_nets, grid_w, grid_h, grid_size=1.0):
    """构建光电联合网络模型。"""
    # 光路由器（弯曲半径约束严格）
    optical_router = GridRouter(grid_w, grid_h, grid_size,
        RouterConstraints(min_bend_radius_um=5.0, min_spacing_um=1.0))
    # 电路由器（曼哈顿走线，无弯曲约束）
    electrical_router = GridRouter(grid_w, grid_h, grid_size,
        RouterConstraints(min_bend_radius_um=0.0, min_spacing_um=0.3))
    # 光波导路径缓存（用于交叉检测与障碍标记）
    optical_cache = {}
    return OptoElectricalRouter(
        grid_w, grid_h, grid_size,
        optical_router=optical_router,
        electrical_router=electrical_router,
        optical_paths_cache=optical_cache)
```

## 6. 光波导布线算法（先光阶段）

### 6.1 弯曲感知 A* 算法

复用 `CurvyRouter`（E01 聚类）的 grid-based curvy-aware A* 引擎。光波导必须满足最小弯曲半径约束，标准 A* 的 8 邻域会产生直角拐弯（弯曲半径=0，物理不可实现），故需弯曲代价项：

```
g(n) = g(parent) + segment_length(parent, n) + bend_penalty(θ)
其中:
  bend_penalty(θ) = 0                         if θ == 0°
                   = K_bend · max(0, R_min - R(θ))   if θ > 0°
  R(θ) = segment_length / (2 · sin(θ/2))     # 由相邻段长度与转角反推弯曲半径
  K_bend = 1e3                                # 弯曲违规强惩罚
```

来源: LiDAR (Zhou 2025 ISPD) §III-B。

### 6.2 伪代码

```python
def route_optical(self, net_id, start, end):
    """光波导布线（先光阶段，优先级高）。"""
    sg = (int(start[0] / self.grid_size), int(start[1] / self.grid_size))
    eg = (int(end[0] / self.grid_size), int(end[1] / self.grid_size))
    grid_path = self.optical_router.route(sg, eg)  # 弯曲感知 A*
    if grid_path is None:
        logger.error("光波导布线失败: %s", net_id)
        return WaveguidePath()  # 上层 rip-up-reroute 处理
    pts = [(g[0] * self.grid_size, g[1] * self.grid_size) for g in grid_path]
    pts[0], pts[-1] = start, end  # 锚定起止点
    length = sum(math.hypot(pts[i+1][0]-pts[i][0], pts[i+1][1]-pts[i][1])
                 for i in range(len(pts)-1))
    loss = 2.0 * length / 1e4  # dB，传播损耗简化模型
    self._optical_paths_cache[net_id] = pts
    return WaveguidePath(points=pts, length_um=length, loss_db=loss)
```

## 7. 电金属布线算法（后电阶段）

### 7.1 曼哈顿 A* 算法

电金属走线遵循曼哈顿几何（90° 拐弯），无弯曲半径约束。8 邻域 A* 退化为 4 邻域（上下左右），代价 `g(n) = g(parent) + 1`。多金属层通过层切换代价 `K_via = 5` 实现：

```
g(n, layer) = g(parent, layer) + 1            # 同层移动
            = g(parent, layer') + K_via       # 跨层通孔
```

来源: Cadence Allegro X 与 Synopsys ICC2 Zroute（E02 聚类）。

### 7.2 伪代码

```python
def route_electrical(self, net):
    """电金属布线（后电阶段，避开光波导）。"""
    sg = (int(net.start[0] / self.grid_size), int(net.start[1] / self.grid_size))
    eg = (int(net.end[0] / self.grid_size), int(net.end[1] / self.grid_size))
    # 电路由器障碍已包含光波导栅格化标记（步骤 3 副作用）
    grid_path = self.electrical_router.route(sg, eg)
    if grid_path is None:
        logger.error("电金属布线失败: %s", net.net_id)
        return ElectricalPath(layer=net.layer)  # 上层多金属层切换处理
    pts = [(g[0] * self.grid_size, g[1] * self.grid_size) for g in grid_path]
    pts[0], pts[-1] = net.start, net.end
    length = sum(math.hypot(pts[i+1][0]-pts[i][0], pts[i+1][1]-pts[i][1])
                 for i in range(len(pts)-1))
    crossings = self._count_optical_crossings(pts)
    return ElectricalPath(points=pts, length_um=length, layer=net.layer,
                          crossings_with_optical=crossings)
```

## 8. 光电交叉避免算法（Bresenham 栅格化）

### 8.1 算法描述

光电交叉避免的核心是 **虚拟屏蔽结构** 策略：将已布光波导路径用 Bresenham 直线算法栅格化，把经过的栅格标记为电层障碍。电金属 A* 在路径搜索时自动避开这些栅格，等效于在光波导上方/下方形成"虚拟屏蔽桥"。复杂度: 单段栅格化 O(max(|dx|, |dy|))，全路径 O(Σ segments)。物理屏蔽结构（金属桥/介质隔离层）版图生成留作未来工作，失败必须告警退出，不引入 fall-back 假数据。

### 8.2 Bresenham 伪代码

```python
def _mark_segment_as_obstacle(self, x0, y0, x1, y1):
    """用 Bresenham 算法标记线段经过的所有栅格为电层障碍。"""
    gx0, gy0 = int(x0 / self.grid_size), int(y0 / self.grid_size)
    gx1, gy1 = int(x1 / self.grid_size), int(y1 / self.grid_size)
    dx, dy = abs(gx1 - gx0), abs(gy1 - gy0)
    sx = 1 if gx0 < gx1 else -1
    sy = 1 if gy0 < gy1 else -1
    err = dx - dy
    gx, gy = gx0, gy0
    while True:
        self.electrical_router.add_obstacle(gx, gy)  # 标记为电层障碍
        if gx == gx1 and gy == gy1:
            break
        e2 = 2 * err
        if e2 > -dy:
            err -= dy
            gx += sx
        if e2 < dx:
            err += dx
            gy += sy
```

### 8.3 残余交叉检测（CCW 叉积法）

栅格化存在亚栅格间隙，残余交叉需用几何方法检测。两线段相交当且仅当彼此跨立在对方两侧（CCW 叉积符号相反）：

```python
def _segments_cross(a1, a2, b1, b2):
    """检测两线段是否相交（CCW 叉积法）。"""
    d1 = _cross2d(b1, b2, a1)  # a1 相对 b1->b2 的叉积
    d2 = _cross2d(b1, b2, a2)
    d3 = _cross2d(a1, a2, b1)
    d4 = _cross2d(a1, a2, b2)
    return (((d1 > 0 and d2 < 0) or (d1 < 0 and d2 > 0)) and
            ((d3 > 0 and d4 < 0) or (d3 < 0 and d4 > 0)))

def _cross2d(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])
```

来源: 计算几何经典算法（O'Rourke 1998 §7.6）。

## 9. 光电器件放置与全局优化

### 9.1 光电器件放置约束

光电器件（如 MZM 调制器、SOA、热光移相器）需同时满足：
1. 光端口对齐：波导方向与器件光轴一致，偏差 < 0.1 μm
2. 电极引出：RF 焊盘与电极距离 < 100 μm（高频损耗约束）
3. 热隔离：热光器件间距 > 50 μm（避免热串扰，H02 聚类）

PoLaRIS 当前器件放置由 `IntegratedPipeline` 上游阶段处理（D03 PPO 强化学习），E04 仅接收放置结果做布线。商业工具 OptoCompiler/Virtuoso 支持放置-布线联合优化。

### 9.2 全局优化迭代（rip-up-reroute 联动）

```python
def global_optimize(self, optical_nets, electrical_nets, max_iter=10):
    """光电联合全局优化（迭代 rip-up-reroute）。"""
    best_result, best_cost = None, float('inf')
    for iteration in range(max_iter):
        result = self.route_all(optical_nets, electrical_nets)
        cost = (1.0 * result.total_optical_length_um
              + 0.1 * result.total_electrical_length_um
              + 10.0 * result.total_optical_loss_db
              + 50.0 * result.total_crossings)
        if cost < best_cost:
            best_result, best_cost = result, cost
        if result.total_crossings == 0:
            break  # 零交叉即收敛
        # 拥塞感知网络重排：交换高交叉电网络的布线顺序
        electrical_nets = self._reorder_by_crossings(electrical_nets, result)
        self._reset_electrical_obstacles()  # 清除光波导障碍标记，重新栅格化
    if best_result.total_crossings > 0:
        logger.warning("光电协同布线 %d 处残余交叉未消除", best_result.total_crossings)
    return best_result
```

### 9.3 多金属层切换策略

当电金属在某层布线失败（无路径），切换至上一层金属（M1→M2→M3），通过 `MultiLayerRouter`（E03 聚类）插入通孔 OTV，通孔代价 `K_via = 5`，电阻 0.1Ω + 电容 5fF（IMEC 130nm 标定）。

### 10.3 创新点（PoLaRIS 独有，标注 *创新*）

*创新* **虚拟屏蔽策略**（Virtual Shielding）：PoLaRIS 通过 Bresenham 栅格化将光波导标记为电层障碍，等效于"零物理成本虚拟屏蔽桥"。该策略创新逻辑：传统商业工具（OptoCompiler/Virtuoso）通过显式生成金属桥版图实现屏蔽，PoLaRIS 通过算法层等价避免物理屏蔽结构生成。底层理论支持：电金属 A* 在栅格化障碍图上等价于带障碍约束的最短路径问题（Dijkstra 1959），且栅格化分辨率 ≥ 工艺最小间距时无穿越风险。案例支持：IMEC 130nm SiPh 工艺最小金属间距 0.3μm，PoLaRIS 默认 grid_size=1.0μm，栅格化间隙 < 0.5μm < 最小间距，理论无穿越。

*创新* **光电联合代价显式公式**：将光损耗（dB）、电延迟（RC）、交叉数、通孔数统一折算为长度代价，首次在开源 EPDA 中实现可微代价函数（与 F02 自动微分聚类联动），支持梯度优化。
