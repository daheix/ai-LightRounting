## 1. 物理模型与适用范围

E03 处理多层光子/光电混合芯片的 3D 布线问题，包含两类垂直互连：
- **电子通孔（Electrical Via）**：金属层间垂直互连，沿用 VLSI 3D-IC 体系（Innovus ICCAD'19 基准），存在电阻 $R_{via}$ 与电容 $C_{via}$，需最小化数量以降低 IR Drop/电迁移风险。
- **光学通孔（Optical Tunnel Via, OTV）**：层间垂直光耦合器，将光从 SOI 器件层耦合至 SiN/LNOI 上层波导，由 Sarad JSTQE 2025 提出，SiN 核心、CMOS 兼容、损耗 < 0.1 dB（1550 nm）。

**适用范围**：
- 3D PIC 多层波导布线（SOI + SiN + LNOI 异质集成）
- 光电协同 3D 封装（Co-Packaged Optics, CPO）
- 多 chiplet 3D-IC（TSV/微凸点 + 光学 OTV 混合）
- 量子光子多层路由（量子层 + 经典层）

**不适用**：单层波导布线（用 E01-A*）、通道布线（用 E02）、纯光波导曲线布线（用 E01-CurvyRouter）。

## 2. 控制方程

### 2.1 3D 网格图模型

将多层芯片离散为 3D 网格图 $G=(V,E)$，节点 $v=(x,y,l)$ 表示层 $l$ 上 $(x,y)$ 位置的 GCell，边 $E=E_{wire}\cup E_{via}$：

- 同层布线边 $e_{wire}=\langle(x,y,l),(x',y',l)\rangle$，代价为线长 × 单位长度损耗/电阻；
- 层间通孔边 $e_{via}=\langle(x,y,l),(x,y,l')\rangle$，仅当 $(x,y)$ 处存在 OTV/TSV 时启用，代价为通孔损耗/电阻。

### 2.2 电子通孔电阻（TSV/Via Stack）

单个通孔直流电阻（按 Innovus via pillar 模型，参考 Hadke 2008）：

$$R_{via} = \frac{\rho \cdot h_{via}}{\pi r_{via}^{2}} + R_{barrier} + R_{interface}$$

其中 $\rho$ 为通孔金属电阻率（Cu: $1.7\times10^{-8}$ Ω·m，W-plug: $5.6\times10^{-8}$ Ω·m），$h_{via}$ 为层间距，$r_{via}$ 为通孔半径，$R_{barrier}$ 为扩散势垒电阻（TaN/TiN），$R_{interface}$ 为界面接触电阻。

$n$ 个通孔并联（multi-cut 阵列）：$R_{via}^{(n)} = R_{via}/n$。Via Pillar 跨 $k$ 层串联：$R_{pillar}^{(k)} = k \cdot R_{via}^{(n)}$。

### 2.3 光学通孔耦合效率（OTV）

OTV 上下两层模式重积分（Sarad JSTQE 2025）：

$$\eta_{OTV} = \left| \int_A \mathbf{E}_1^{*}(x,y) \times \mathbf{H}_2(x,y) \cdot d\mathbf{A} \right|^2 \Big/ \left( \int_A \mathbf{E}_1 \times \mathbf{H}_1^{*} \cdot d\mathbf{A} \cdot \int_A \mathbf{E}_2 \times \mathbf{H}_2^{*} \cdot d\mathbf{A} \right)$$

插入损耗：$IL_{OTV} = -10\log_{10}\eta_{OTV}$ (dB)。Sarad 2025 SiN-OTV 实测 $IL < 0.1$ dB @ 1550 nm，WDL < 0.05 dB（1480-1620 nm），PDL < 0.05 dB。

层间耦合损耗（Shang 2017 三层 SiN 平台）：渐失场垂直耦合 $IL_{vc} = -10\log_{10}(\sin^2(\kappa L_c))$，其中 $\kappa$ 为耦合系数，$L_c$ 为耦合长度，实测 < 0.23 dB。

## 3. 离散化与层分配策略

### 3.1 多层网格化

每层独立网格化（参考 PoLaRIS `multilayer.py:33` LayerSpec）：
- Layer 0: SOI 器件层，`grid_size=0.5μm`，有源/无源器件密集；
- Layer 1: SiN 无源层，`grid_size=1.0μm`，低损传输；
- Layer 2: LNOI 调制层，`grid_size=1.0μm`，高速调制。

各层网格大小可独立设置，OTV/TSV 位置需在各层网格上对齐（双向 snapping）。

### 3.2 层分配算法

3D 布线主流策略（V-GR ASPDAC 2024）：
1. **2D + Layer Assignment**：先在压缩 2D 平面布线，再按拥塞/通孔预算分层（FastRoute 4.0、NTHU-Route 2.0）；
2. **Direct 3D Routing**：直接在 3D 网格上 A*/Maze，自然处理通孔（V-GR、CUHK GRAR）；
3. **Pattern + Rip-up-Reroute**：先用 3-bend pattern 求初始解，再用 3D Maze 优化（FastRoute 4.0 经典框架）。

PoLaRIS 采用策略 2（Direct 3D），与 `multilayer.py:95` MultiLayerRouter 一致：每层独立 A*，OTV 边作层间跳跃。

### 3.3 通孔最小化

V-GR via-aware cost（Zhang 2024）：

$$c(e) = w_w \cdot d(e) + w_v \cdot \mathbb{1}_{via}(e) + w_c \cdot congestion(e)$$

其中 $\mathbb{1}_{via}$ 在通孔边为 1，$w_v$ 控制 via 数量偏好，$congestion$ 来自 RUDY 拥塞图。PoLaRIS OTV 选择（`multilayer.py:193`）使用曼哈顿距离 $|o.x-s_x|+|o.y-s_y|+|o.x-e_x|+|o.y-e_y|$ 作为初筛。

## 4. 边界条件与 OTV 约束

- **OTV 可用性**：仅在 `(layer_from, layer_to)` 层对存在 OTVSpec 时启用层间边（`multilayer.py:188`，无 OTV 则告警退出，规则 14）；
- **OTV 容量**：每个 OTV 节点容量上限 $C_{OTV}$（避免多 net 共用导致串扰），违反则触发 rip-up-reroute（E02 接口）；
- **DRC 间距**：通孔间最小间距 $S_{via}$（foundry 规则，由 B02-DRC 提供），双通孔插入（Chen 2008）要求每个 critical via 必须有 redundant via；
- **层跳限制**：禁止跨 >2 层的 via stack（除非显式声明 Via Pillar），保证可制造性；
- **极化保持**：光 OTV 必须保持 TE/TM 极化（Sarad 2025 PDL < 0.05 dB），违反则告警退出。

## 5. 核心算法逻辑（完整伪代码）

```
ALGORITHM MultiLayerRoute(layers, otvs, net, constraints):
  # 输入：
  #   layers = [LayerSpec(name, grid_w, grid_h, grid_size, platform)]  # 多层规格
  #   otvs   = [OTVSpec(name, layer_from, layer_to, x, y, loss_db)]    # OTV 列表
  #   net    = (start_layer, start_pos, end_layer, end_pos)            # 待布线网
  #   constraints = RouterConstraints(min_via_spacing, max_via_stack, ...)
  # 输出：MultiLayerRouteResult(layer_paths, otv_used, total_length, total_loss)

  # === 步骤 0：初始化每层 GridRouter + OTV 映射 ===
  for l, layer in enumerate(layers):
      routers[l] = GridRouter(layer.grid_w, layer.grid_h, layer.grid_size, constraints)
  otv_map = build_bidirectional_otv_map(otvs)        # (l_from, l_to) -> [OTVSpec]

  # === 步骤 1：层分配决策 ===
  if net.start_layer == net.end_layer:
      return route_single_layer(net.start_layer, net.start_pos, net.end_pos)

  # === 步骤 2：候选 OTV 筛选 ===
  candidates = otv_map.get((net.start_layer, net.end_layer), [])
  if candidates is empty:
      log_error("无可用 OTV 层 %d->%d" % (net.start_layer, net.end_layer))
      return None                                     # 业务规则：失败告警退出（规则 14）

  # === 步骤 3：3D A* 代价评估（含通孔/拥塞/损耗） ===
  best_otv = None
  best_cost = +inf
  for otv in candidates:
      # 同层 A* 探索：起点 -> OTV
      path1, cost1 = routers[net.start_layer].astar(
          start_pos, (otv.x, otv.y),
          cost_fn = lambda e: w_wire * d(e) + w_cong * congestion(e))
      if path1 is None: continue
      # 同层 A* 探索：OTV -> 终点
      path2, cost2 = routers[net.end_layer].astar(
          (otv.x, otv.y), net.end_pos,
          cost_fn = lambda e: w_wire * d(e) + w_cong * congestion(e))
      if path2 is None: continue
      # 总代价 = 线长代价 + OTV 损耗代价 + OTV 数量代价（V-GR via-aware）
      total_cost = cost1 + cost2 + w_via * 1 + w_loss * otv.loss_db
      if total_cost < best_cost:
          best_cost, best_otv = total_cost, otv
          best_path1, best_path2 = path1, path2

  if best_otv is None:
      log_error("所有候选 OTV 布线均失败 net=%s" % net)
      return None

  # === 步骤 4：合并结果 + 损耗累加 ===
  result = MultiLayerRouteResult()
  result.layer_paths[net.start_layer] = best_path1
  result.layer_paths[net.end_layer]   = best_path2
  result.otv_used = [best_otv]
  result.total_length_um = path_length(best_path1) + path_length(best_path2)
  result.total_loss_db   = (
      path_loss(best_path1, layers[net.start_layer].platform)
    + path_loss(best_path2, layers[net.end_layer].platform)
    + best_otv.loss_db)                              # OTV 耦合损耗累加
  return result

# === 单层 A* 子程（参考 E01 GridRouter） ===
FUNCTION route_single_layer(layer_idx, start, end):
  router = routers[layer_idx]
  grid_path = router.route(snap_to_grid(start), snap_to_grid(end))
  if grid_path is None:
      log_error("层 %s 布线失败" % layers[layer_idx].name)
      return None
  return MultiLayerRouteResult(layer_paths={layer_idx: grid_path},
                                total_loss_db = length * propagation_loss_per_um)
```

## 6. 核心公式（LaTeX）

**3D A* 代价函数**（V-GR Zhang 2024 via-aware）：

$$f(n) = g(n) + h(n), \quad g(n) = \sum_{e \in path(n)} \big[ w_w d(e) + w_v \mathbb{1}_{via}(e) + w_c \rho(e) + w_l IL(e) \big]$$

其中 $h(n)$ 为 3D 曼哈顿距离启发（含层间距离权重），$\rho(e)$ 为 RUDY 拥塞，$IL(e)$ 为光波导传播损耗（SOI: 2 dB/cm，SiN: 0.1 dB/cm，LNOI: 0.5 dB/cm）。

**通孔电阻**（Innovus via pillar 模型，Cu via $r=0.1\mu m$, $h=1\mu m$）：

$$R_{via} = \frac{\rho_{Cu} h_{via}}{\pi r_{via}^2} \approx 5.4 \times 10^{-3}\,\Omega, \quad R_{pillar}^{(k)} = k \cdot R_{via}^{(n)} = \frac{k R_{via}}{n}$$

**OTV 耦合效率**（Sarad 2025 SiN-OTV，模式重积分）：

$$\eta_{OTV} = \frac{\left| \int \mathbf{E}_1^{*} \times \mathbf{H}_2 \cdot d\mathbf{A} \right|^2}{\left(\int \mathbf{E}_1 \times \mathbf{H}_1^{*} \cdot d\mathbf{A}\right)\left(\int \mathbf{E}_2 \times \mathbf{H}_2^{*} \cdot d\mathbf{A}\right)}, \quad IL_{OTV} = -10\log_{10}\eta_{OTV} < 0.1\,\text{dB}$$

**总损耗累加**（PoLaRIS `multilayer.py:212`）：

$$IL_{total} = \sum_{l} L_l \cdot \alpha_l + \sum_{v \in OTV_{used}} IL_{OTV}^{(v)} + \sum_{v \in TSV_{used}} IL_{TSV}^{(v)}$$

其中 $\alpha_l$ 为层 $l$ 传播损耗系数，$L_l$ 为层 $l$ 上路径长度。

**待补齐**（与商业工具差距，对应 P3 开发计划）：
1. **V-GR via-aware cost**：将 `multilayer.py:193` 曼哈顿距离初筛替换为完整 3D A* 代价 $f(n)=g(n)+h(n)$，含 $w_v \mathbb{1}_{via}$ 通孔数量权重（对齐 INV-3.x PRO 3D）；

3. **Double-Via Insertion**：critical OTV 自动插入 redundant OTV（对齐 Chen 2008 ICCAD，提升成品率）；
4. **Via Pillar 优化**：跨 >2 层时自动构造 via pillar，电阻按 $R_{pillar}^{(k)}=k R_{via}/n$ 计算（对齐 ICC2-2.4 NDR/via pillar）；
5. **3DFabric / chiplet**：多 chiplet 物理实现，TSV + 微凸点 + OTV 混合（对齐 INV-11.2/11.3，P5 阶段评估）；
6. **45° 对角布线**：层内 GridRouter 增加 45° 模式（对齐 T03-22）。

*创新*：光子 OTV + 电子 TSV 混合 3D 布线，纯 CPU 实现，与 AI 布局引擎深度耦合。

- **底层逻辑**：
  1. **光子 OTV 模型**：首次将 Sarad 2025 SiN-OTV 模型（$IL<0.1$ dB）集成进 3D 布线器，作为光子层间跳跃边代价（`multilayer.py:212` loss_db 累加），区别于 Innovus/ICC2 仅处理电子 via；
  2. **3D 代价统一**：3D A* 代价函数 $f(n)=g(n)+h(n)$ 同时编码电子通孔电阻 $R_{via}$、光 OTV 损耗 $IL_{OTV}$、拥塞 $\rho(e)$，支持光电协同 3D 布线（与 E04 共享）；
  3. **AI 引导层分配**：通过 D02-CongestionCNN 预测每层拥塞热图，反向引导层分配，避免商业工具事后拥塞修复的开销；
  4. **跨层 OTV 容量约束**：每个 OTV 节点容量 $C_{OTV}$ 限制多 net 共用，触发 rip-up-reroute（与 E02 接口），保证极化保持与串扰约束。

- **支持理论**：
  - Sarad 2025 已证明 SiN-OTV 在 1480-1620 nm 波段 WDL < 0.05 dB，PDL < 0.05 dB，满足极化保持约束；
  - Shang 2017 三层 SiN 平台垂直耦合器实测 $IL < 0.23$ dB，验证层间 OTV 阵列可行性；
  - V-GR 2024 via-aware cost 在 ICCAD'19 基准上 via -8%、overflow -7.5%，证明 via 权重 $w_v$ 的有效性；
  - Chen 2008 二部图匹配 double-via 插入在 ≤3 层场景下最优，理论保证可制造性。

- **案例**：
  - SOI + SiN 双层 3D PIC：上层 SiN 低损传输，下层 SOI 器件，OTV 在边缘耦合，$IL_{total} < 0.5$ dB；
  - LNOI 调制器 + SiN 滤波器异质集成：通过 OTV 实现调制层→滤波层垂直互连；
  - 光电协同 CPO：电子 TSV 供电 + 光 OTV 信号互连混合布线（与 E04 协同）；
  - 量子光子多层：量子层（极化保持）+ 经典层，OTV 严格 PDL < 0.05 dB。

- **差异化点**：商业工具（Innovus/ICC2）仅处理电子 via，不建模光子 OTV 损耗与极化；PoLaRIS 在 3D 代价函数中同时纳入 $R_{via}$（电子）与 $IL_{OTV}$（光子），是首个面向光电混合 3D PIC 的多层布线器，与 D02-CongestionCNN/AI 布局引擎闭环。
