## 1. 概述与定位

频域扫描（Frequency Domain Sweep）是光子集成电路（PIC）系统级仿真最核心的求解模式：在指定频率/波长网格上，对每个频率点求解整个电路的散射矩阵（S 参数），从而获得传输谱、反射谱、相位响应、群延迟等频域特性。与时域仿真相比，频域扫描天然适合线性无源电路、窄带谐振器、滤波器、干涉仪的快速评估，且无需时间步进收敛判据，单频独立求解可天然向量化并行。

**PoLaRIS 定位**：频域扫描是 PoLaRIS 仿真栈的"主力求解路径"。`CircuitSimulator`（`src/polaris/sim/simulator.py:57`）以 SAX 子网络增长算法为基础，借助 JAX 后端（`src/polaris/sim/jax_backend.py:65`）对多频率点进行 `vmap` 向量化并行求解，覆盖 T10/T11 全部频率扫描能力，对齐 Lumerical INTERCONNECT 频域求解器与 VPI 频域仿真模块。纯 CPU + JAX/XLA 单机路径（规则 26，不参与 GPU）。

**对标状态**：6 工具共用，PoLaRIS 完整覆盖（✅12/⚠️4/❌2，覆盖率 ≈78%）。优势在于 JAX 原生可微（与 F02 自动微分、F01 伴随法逆向设计无缝衔接）；差距在于全局/嵌套参数分发、频率分辨率基准测试两项为 ⚠️部分，KLU 直接稀疏后端为 ❌缺失（见 §9）。

## 2. 物理模型与控制方程

### 2.1 频域 S 参数定义

对一个 $N$ 端口线性光子网络，给定频率 $f$（对应波长 $\lambda=c_0/f$），定义归一化入射波向量 $\mathbf{a}\in\mathbb{C}^N$ 与归一化出射波向量 $\mathbf{b}\in\mathbb{C}^N$，则频域 S 矩阵 $\mathbf{S}(f)\in\mathbb{C}^{N\times N}$ 满足：

$$\mathbf{b}(f) = \mathbf{S}(f)\,\mathbf{a}(f), \quad S_{ij}(f)=\left.\frac{b_i(f)}{a_j(f)}\right|_{a_k=0,\,k\ne j}$$

其中 $S_{ij}(f)$ 表示在端口 $j$ 注入单位入射波、其余端口匹配时，端口 $i$ 的出射波复振幅（含幅度与相位）。对互易无源网络满足 $S_{ij}=S_{ji}$（互易性），对无耗网络满足 $\mathbf{S}^\dagger\mathbf{S}=\mathbf{I}$（幺正性）。

### 2.2 传输函数 H(f)

针对单输入单输出（SISO）链路（如 MZI、环形谐振器），从输入端口 in 到输出端口 out 的传输函数：

$$H(f) = S_{\text{out,in}}(f) = |H(f)|\,e^{i\varphi(f)}$$

由此派生关键频域指标：
- **功率传输谱**：$T(f)=|H(f)|^2$（单位 dB：$10\log_{10}T$）
- **相位响应**：$\varphi(f)=\arg H(f)$
- **群延迟**：$\tau_g(f)=-\dfrac{1}{2\pi}\dfrac{d\varphi}{df}$
- **自由光谱范围 FSR**：相邻谐振峰频率间隔
- **Q 因子**：$Q=f_0/\Delta f_{\text{FWHM}}$

### 2.3 单器件频域 S 参数模型

以波导为例（SAX 标准模型，flaport/sax）：

$$S_{\text{wg}}(f) = \alpha(f)\,\exp\!\left(i\,\frac{2\pi\,n_{\text{eff}}(f)\,L}{\lambda}\right), \quad \alpha(f)=10^{-\text{loss}\cdot L/20}$$

其中 $n_{\text{eff}}(f)=n_{\text{eff},0}-(\lambda-\lambda_0)\cdot(n_g-n_{\text{eff},0})/\lambda_0$ 为一阶色散展开有效折射率，$n_g$ 为群折射率，$L$ 为波导长度。所有内置模型（环形谐振器、定向耦合器、Y 分支、光栅耦合器等 10 种，`src/polaris/sim/models.py:159-455`）均为频率的复值函数。

### 2.4 电路级联 S 矩阵

电路由多个器件经子网络增长算法级联（C01 聚类），整体 S 矩阵由 Redheffer 星积（C03 聚类）或 SAX 的 Filipsson-Gunnar 后端（`src/polaris/sim/cascade.py:397`）逐级合并得到。对每个频率 $f_k$，独立求解一次完整级联，得到 $\mathbf{S}_{\text{ckt}}(f_k)$。

## 3. 频率点生成策略

频率点网格的质量直接决定频域响应精度与计算成本。PoLaRIS 支持三种生成模式：

### 3.1 线性频率网格

$$f_k = f_{\min} + \frac{k-1}{N_f-1}(f_{\max}-f_{\min}), \quad k=1,2,\dots,N_f$$

适用于窄带分析、谐振峰局部精细扫描（恒定频率分辨率 $\Delta f=(f_{\max}-f_{\min})/(N_f-1)$）。

### 3.2 线性波长网格（光子学默认）

光子学惯例以波长等间隔采样（SiEPIC/Lumerical 标准）：

$$\lambda_k = \lambda_{\min} + \frac{k-1}{N_\lambda-1}(\lambda_{\max}-\lambda_{\min}), \quad f_k = c_0/\lambda_k$$

注意：等波长间隔对应非等频率间隔，群延迟等频率导数需做 Jacobian 修正 $\frac{d\varphi}{df}=\frac{d\varphi}{d\lambda}\cdot\frac{d\lambda}{df}=-\frac{\lambda^2}{c_0}\frac{d\varphi}{d\lambda}$。

### 3.3 对数频率网格

$$f_k = f_{\min}\left(\frac{f_{\max}}{f_{\min}}\right)^{(k-1)/(N_f-1)}$$

适用于跨数量级宽带扫描（如 1 GHz–1 THz 偏振分析），每十倍频程恒定点数。

### 3.4 自适应采样（PoLaRIS 增强策略）

对高 Q 谐振器，先用粗网格定位谐振峰，再在峰附近以 $\Delta f < \text{FWHM}/10$ 加密。PoLaRIS `analyze_dispersion`（`src/polaris/sim/simulator.py:357`）从扫描结果自动提取 FSR/Q，反馈指导加密。

## 4. 逐频率 S 参数计算

### 4.1 单频求解流程

对每个频率点 $f_k$，独立执行：

1. **更新器件模型**：对电路中每个器件 $d$，按其参数化模型计算 $\mathbf{S}_d(f_k)$（含色散 $n_{\text{eff}}(f_k)$、损耗 $\alpha(f_k)$、耦合系数 $\kappa(f_k)$）。
2. **子网络增长级联**：按网表拓扑（`src/polaris/data/data_loader.py:105` 的 `circuit_spec_to_netlist_dict`）调用 SAX `cascade_circuit`（`src/polaris/sim/cascade.py:315`）合并为整体 $\mathbf{S}_{\text{ckt}}(f_k)$。
3. **提取响应**：按端口对提取 $S_{ij}(f_k)$，组装到频率响应数组。

### 4.2 数据结构：SDict

SAX 以 `SDict = Dict[Tuple[str,str], Complex[Array, '...']]` 表示 S 参数（`src/polaris/sim/cascade.py:315`）。键为端口对 `(out, in)`，值为标量或频率数组。字典天然稀疏（多端口器件大部分 $S_{ij}=0$），优于稠密 ndarray。

### 4.3 多波长 S 参数

PoLaRIS 支持将 $N_f$ 个频率点作为 JAX 数组广播到 SDict 值维度（`simulator.py:57` 多波长 S 参数功能点 7.5），单次 `cascade_circuit` 调用即可返回全频段 S 矩阵，避免 Python for 循环开销。

## 5. JAX vmap 向量化加速

### 5.1 向量化原理

JAX `vmap`（`jax.vmap`）是"向量化映射"：将函数 $g(f, \theta)$ 沿频率轴 $f$ 批量执行，编译期融合为单一 XLA 内核，消除 Python 解释器开销与逐次调度成本。对应数学操作：

$$\text{vmap}(g)(\mathbf{f}, \theta) = \big[g(f_1,\theta),\,g(f_2,\theta),\,\dots,\,g(f_{N_f},\theta)\big]^\top$$

与 Python `for f in freqs: g(f)` 相比，`vmap` 在 XLA 层做循环融合、内存布局优化与指令级并行，对 1000+ 频率点可获得 10–100× 加速（TMMax 在 TMM 多层膜仿真报告 100× 加速，见文献 4）。

### 5.2 PoLaRIS vmap 调用模式

PoLaRIS 在两处使用 `vmap`：

- **`monte_carlo_simulate`**（`src/polaris/sim/monte_carlo.py:63`）：JAX `vmap` 并行蒙特卡洛仿真，对参数扰动样本批量求解（功能点 6.1）。
- **`CircuitSimulator` 频率扫描**（`src/polaris/sim/simulator.py:57`）：将频率数组作为广播维度，单器件模型函数 `model(wl=jnp.array(freqs))` 内部对波长向量化，级联在 SDict 值数组维度上自动传播。

### 5.3 JIT 编译

`jax.jit` 对频率扫描主循环做即时编译，将器件模型 + 级联算子融合为单一 XLA 图。首次调用编译开销约 1–5 s，后续相同形状调用接近原生机器码速度。PoLaRIS `jax_backend.py:101` 提供 JIT 加速入口（功能点 1.5 XLA 加速、功能点 42 functor 加速）。

### 5.4 双精度配置

频率扫描对相位敏感（谐振峰相位累积达 $10^3$ rad 量级），必须启用 JAX 双精度（Simphony/SAX 官方推荐）：

```python
from jax import config
config.update("jax_enable_x64", True)  # 必须在 JAX 初始化前设置
```

PoLaRIS 通过环境变量 `JAX_ENABLE_X64=True` 默认启用（对齐功能点 1.7 双精度支持）。

## 6. 频域响应输出与后处理

### 6.1 输出数据结构

频率扫描返回 `SweepResult`（对齐 T11 Simphony `SweepSimulation`）：

```
SweepResult:
    freqs:     jnp.ndarray  (N_f,)     频率点 Hz
    wavelengths: jnp.ndarray (N_f,)    波长点 m
    sdict:     Dict[(out,in) -> jnp.ndarray (N_f,)]  全频段 S 参数
    metadata:  {f_min, f_max, N_f, grid_type, sweep_time}
```

### 6.2 后处理指标

由 `analyze_dispersion`（`src/polaris/sim/simulator.py:357`）从扫描结果提取：
- **传输谱**：$T_{ij}(f)=|S_{ij}(f)|^2$
- **FSR**：谐振峰频率间隔，由峰值检测 + 抛物线插值亚像素定位
- **Q 因子**：$Q=f_0/\Delta f_{\text{FWHM}}$，FWHM 由半高线性插值
- **群延迟**：$\tau_g(f)=-\frac{1}{2\pi}\frac{d\varphi}{df}$，中心差分
- **消光比**：谐振谷深度 $10\log_{10}(T_{\max}/T_{\min})$

### 6.3 可视化

由 `src/polaris/eval/layout_render.py:123` 的 matplotlib 渲染器输出传输谱/相位谱/群延迟曲线，对应 I02 可视化聚类。

## 7. 算法伪代码

```text
function frequency_domain_sweep(circuit_spec, f_min, f_max, N_f, grid_type="linear_wavelength"):
    # 1. 频率点生成
    if grid_type == "linear_wavelength":
        wavelengths = jnp.linspace(c0/f_max, c0/f_min, N_f)   # 等波长间隔
        freqs = c0 / wavelengths
    elif grid_type == "linear_frequency":
        freqs = jnp.linspace(f_min, f_max, N_f)
    elif grid_type == "log":
        freqs = f_min * (f_max/f_min) ** (jnp.arange(N_f)/(N_f-1))
    else:
        raise ValueError(f"未知网格类型: {grid_type}")   # 规则 14：禁止 fall-back

    # 2. 解析网表为 SAX 电路
    netlist = circuit_spec_to_netlist_dict(circuit_spec)         # data_loader.py:105
    circuit_fn = cascade_circuit(netlist)                        # cascade.py:315 SAX 子网络增长

    # 3. JIT + vmap 向量化频率扫描
    @jax.jit
    def single_freq_sparam(wl):
        # 器件模型在内部对 wl 标量求值，返回 SDict 标量值
        sdict = circuit_fn(wl=wl)
        return sdict

    # vmap 沿波长轴广播，XLA 融合为单内核
    vectorized_sweep = jax.vmap(single_freq_sparam, in_axes=(0,), out_axes=0)
    sdict_over_freqs = vectorized_sweep(wavelengths)   # Dict[(out,in) -> Array(N_f,)]

    # 4. 组装结果
    result = SweepResult(
        freqs=freqs,
        wavelengths=wavelengths,
        sdict=sdict_over_freqs,
        metadata={f_min, f_max, N_f, grid_type}
    )

    # 5. 后处理：FSR / Q / 群延迟
    metrics = analyze_dispersion(result)              # simulator.py:357
    return result, metrics


function analyze_dispersion(sweep_result):
    # 提取传输谱 T(f) = |S_out,in(f)|^2
    T = jnp.abs(sweep_result.sdict[("out", "in")])**2
    # 峰值检测 + 抛物线插值定位谐振峰
    peaks = find_peaks(-T)                              # 谐振谷
    fsr = jnp.diff(sweep_result.freqs[peaks])           # 自由光谱范围
    # FWHM 由半高线性插值
    fwhm = interpolate_fwhm(T, sweep_result.freqs, peaks)
    Q = sweep_result.freqs[peaks] / fwhm
    # 群延迟：相位中心差分
    phase = jnp.unwrap(jnp.angle(sweep_result.sdict[("out", "in")]))
    tau_g = -jnp.gradient(phase, sweep_result.freqs) / (2*jnp.pi)
    return {peaks, fsr, fwhm, Q, tau_g}
```

**说明**：
- 步骤 3 的 `jax.jit` + `jax.vmap` 组合是 PoLaRIS 频率扫描核心加速机制：JIT 融合器件模型与级联算子，vmap 沿频率轴批量执行，XLA 编译期消除 Python 循环开销。
- 步骤 1 失败时 `raise`（规则 14），不返回空数组兜底。
- `cascade_circuit` 内部使用 SAX Filipsson-Gunnar 后端（`src/polaris/sim/cascade.py:397`），对齐 C03 Redheffer 星积聚类。

## 11. 验收与测试要点

### 11.1 正确性验证

- **MZI 传输谱基准**：对平衡 MZI（两臂等长），传输谱应在全频段恒为 1（理想 3 dB 耦合器）；对非平衡 MZI（臂长差 $\Delta L$），FSR 解析值 $c_0/(n_g\Delta L)$ 与扫描提取值相对误差 $\le 10^{-3}$。
- **环形谐振器 Q 因子**：Add-Drop 环形谐振器，解析 Q $=\pi n_g L/(\lambda_{\text{res}}\cdot\text{loss}\cdot L)$（损耗主导）与 `analyze_dispersion` 提取值相对误差 $\le 5\%$。
- **群延迟守恒**：单波导群延迟 $\tau_g=n_g L/c_0$ 与扫描提取值绝对误差 $\le 10^{-15}$ s（双精度）。
- **互易性检查**：所有 $S_{ij}(f_k)=S_{ji}(f_k)$，相对误差 $\le 10^{-12}$（双精度数值精度）。

### 11.2 向量化加速验证

- **vmap vs for 循环**：1000 频率点 MZI 扫描，`jax.jit+vmap` 较 Python `for` 循环加速 $\ge 10\times$（CPU 单线程基准）。
- **JIT 编译稳定性**：第二次调用与第 $N$ 次调用耗时差 $\le 1\%$（编译缓存命中）。
- **双精度一致性**：`jax_enable_x64=True` 与 `False` 下，谐振峰位置相对漂移 $\le 10^{-6}$（相位累积误差可控）。

### 11.3 网格类型验证

- 线性波长/线性频率/对数三种网格下，对同一电路同一频段，传输谱插值后 $L^2$ 范数差 $\le 10^{-4}$（密度足够时）。
- 自适应采样在高 Q 谐振器（$Q>10^5$）下，谐振峰 FWHM 提取相对误差 $\le 1\%$（粗网格漏峰为不合格）。

### 11.4 边界与异常

- 频率点数 $N_f=1$ 时退化为单频求解，结果与单次 `circuit_fn(wl=w0)` 一致。
- 频率范围越界（如 $\lambda < 100$ nm 真空紫外）必须 `raise`（规则 14），不返回零场兜底。
- 网表含未连接端口时 `raise`，不静默丢弃。

### 11.5 质量门禁

- 实现位于 `src/polaris/sim/simulator.py`（CircuitSimulator）与 `src/polaris/sim/cascade.py`（cascade_circuit），遵循规则 7（圈复杂度 ≤15、函数 ≤80 行、文件 ≤800 行）。
- 测试位于 `tests/test_frequency_sweep.py`，覆盖率 ≥ 90%（规则 10）。
- 文档字符串标注所有公式来源 URL（规则 18），代码无待办标记，无 fall-back。
