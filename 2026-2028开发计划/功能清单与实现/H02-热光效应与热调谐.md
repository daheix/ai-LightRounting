## 2. 物理模型与数学基础

热光效应是指材料折射率随温度变化的物理现象，由热光系数 $dn/dT$ 表征。在硅光子学中，硅在 1550 nm 处 $dn/dT \approx 1.8 \times 10^{-4}\,\mathrm{K^{-1}}$（室温），是 SiO₂（$+1.0 \times 10^{-5}\,\mathrm{K^{-1}}$）的约 18 倍、SiN（$2.4 \times 10^{-5}\,\mathrm{K^{-1}}$）的约 7.5 倍，使 SOI 平台成为热光调谐/调相的高效载体。热光调谐的物理链条为：**电学焦耳热 → 傅里叶导热 → 稳态温度场 T(x,y,z) → 折射率分布 n(T) → 模式本征值 n_eff(T) → 相移 Δφ = (2π/λ)·Δn_eff·L**。

**适用范围**：
- SOI/SiN 热光移相器（TOPS，Pπ ~20-30 mW）
- 微环谐振器热调谐（典型效率 0.15-1.0 nm/mW）
- MZM 热光开关（switch time 1-50 μs）
- DWDM 多通道热串扰补偿与热稳定
- 3D 集成 PIC-EIC 热设计优化

**不适用**：纳秒级快速调制（应使用载流子耗尽电光效应）、深低温（<30 K，$dn/dT$ 急剧下降至 $10^{-8}\,\mathrm{K^{-1}}$）、相变材料（如 GST，需焓方法）。

## 3. 控制方程

### 3.1 热传导方程（傅里叶导热，与 A07 共享）

瞬态：

$$\rho c_p \frac{\partial T}{\partial t} = \nabla \cdot (k \nabla T) + Q$$

稳态（$\partial T/\partial t = 0$）：

$$-\nabla \cdot (k \nabla T) = Q$$

其中 $\rho$ 为密度（kg/m³），$c_p$ 为比热容（J/(kg·K)），$k$ 为导热系数（W/(m·K)），$Q$ 为体积热源密度（W/m³）。

### 3.2 热光耦合方程（折射率温度依赖）

线性一阶近似（Lumerical FEEM 工作流采用，对硅在 300 K 附近 ΔT < 50 K 时误差 < 5%）：

$$n(T) = n_0 + \frac{dn}{dT}(T - T_0)$$

**Cocorullo 1999 经验公式**（晶硅 1523 nm，300-550 K 拟合，二阶精度）：

$$\frac{dn}{dT}\bigg|_{\mathrm{Si}}(T) = 1.86 \times 10^{-4} + 4.3 \times 10^{-7}(T - 300) \quad [\mathrm{K^{-1}}]$$

**SiO₂ 热光系数**（Lumerical 文档典型值）：

$$\frac{dn}{dT}\bigg|_{\mathrm{SiO_2}} \approx 1.0 \times 10^{-5}\,\mathrm{K^{-1}}$$

**SiN 热光系数**（PoLaRIS `v5.0 已移除（原 `modules/pdk/src/polaris_pdk/passive.py`，SiN 无源器件库未迁移（热光系数见 modules/multiphysics/src/polaris_multiphysics/coupling/thermo_optic.py））:413` 文献典型值 2.4-2.5×10⁻⁵/K）：

$$\frac{dn}{dT}\bigg|_{\mathrm{SiN}} \approx 2.4 \times 10^{-5}\,\mathrm{K^{-1}}$$

### 3.3 模式本征值温度依赖

将 $n(T)$ 注入 FDE/FEEM 本征方程：

$$\nabla \times \left( \frac{1}{\varepsilon_r(T)} \nabla \times \mathbf{H} \right) = k_0^2 \mathbf{H}, \quad \beta(T) = k_0 n_{eff}(T)$$

热光相移：

$$\Delta\varphi(T) = \frac{2\pi}{\lambda_0} \int_0^L \Delta n_{eff}(T(z))\, dz$$

## 4. 离散化方法

### 4.1 FEM 网格（热场，与 A07 共享）

Galerkin 有限元弱形式（权函数 $N_i$ 取形函数）：

$$\int_\Omega k \nabla N_i \cdot \nabla T\, d\Omega - \int_\Gamma N_i q_n\, d\Gamma = \int_\Omega N_i Q\, d\Omega$$

刚度矩阵 $\mathbf{K}$、热容矩阵 $\mathbf{M} = \mathrm{diag}(\rho c_p \Delta V_i)$、载荷向量 $\mathbf{Q}$ 的组装与 A07 完全一致，复用 `modules/multiphysics/src/polaris_multiphysics/heat/solver.py`（待建）。

### 4.2 热导率张量

各向异性材料（如层状石墨烯、单晶硅特定晶向）使用热导率张量：

$$\mathbf{k} = \begin{pmatrix} k_x & 0 & 0 \\ 0 & k_y & 0 \\ 0 & 0 & k_z \end{pmatrix}$$

界面导热系数取调和平均保证通量连续：$k_{ij} = 2 k_i k_j / (k_i + k_j)$。

### 4.3 FDE/FEEM 网格（光学场，A04 共享）

Yee 网格差分算子，本征值问题 $\mathbf{A}\mathbf{x} = \lambda \mathbf{x}$，$\lambda = \beta^2$。温度场插值到 Yee 网格节点后，更新 $\varepsilon_r(T)$ 重新求解本征模。

## 5. 边界条件

5 类标准边界（COMSOL Heat Transfer Module / Lumerical HEAT 共同支持）：

1. **等温边界（Dirichlet）**：$T|_\Gamma = T_0$（如恒温基底 300 K）。
2. **绝热边界（Neumann）**：$-k \partial T/\partial n|_\Gamma = 0$。
3. **对流换热（Robin）**：$-k \partial T/\partial n|_\Gamma = h(T - T_\infty)$，$h$ 为对流换热系数（W/(m²·K)）。
4. **辐射散热**：$-k \partial T/\partial n|_\Gamma = \varepsilon \sigma (T^4 - T_\infty^4)$，$\sigma = 5.67 \times 10^{-8}\,\mathrm{W/(m^2 \cdot K^4)}$ 为 Stefan-Boltzmann 常数。Newton 线性化：$h_{rad}(T_{old}) = \varepsilon \sigma (T_{old} + T_\infty)(T_{old}^2 + T_\infty^2)$。
5. **接触热阻**：$-k \partial T/\partial n|_\Gamma = (T - T_{contact})/R_{th}$，$R_{th}$ 为界面热阻（m²·K/W）。

## 6. 核心算法逻辑（热-光迭代 + 热调谐伪代码）

```
ALGORITHM H02_ThermoOpticTuning(device, heater_power_sweep, mesh, materials, bcs):
  # 输入：device 含波导+加热器几何，heater_power_sweep = [P1, ..., PK]
  # 输出：Δφ(P), n_eff(P), Pπ（π 相移功率），效率 η = dλ/dP

  # === 步骤 1：基线模式求解（T = T0 = 300 K） ===
  n_eff_0 = FDE_solve(device.cross_section, T=T0).n_eff

  # === 步骤 2：热-光自洽迭代（对每个加热功率 P_k） ===
  results = []
  for P_k in heater_power_sweep:
      T_field = T0  # 初始猜测
      for outer_iter in range(MAX_OUTER=5):    # 自洽迭代
          # (a) 热场求解：HEAT 稳态
          Q_joule = P_k / heater_volume        # 均匀焦耳热源
          T_new = HEAT_solve_steady(mesh, materials, Q=Q_joule, bcs=bcs)

          # (b) 折射率更新：n(T) = n0 + (dn/dT)*(T - T0)
          n_profile = materials.n0 + materials.dndT * (T_new - T0)

          # (c) 模式求解：FDE/FEEM with n(T)
          n_eff_new = FDE_solve(device.cross_section, n=n_profile).n_eff

          # (d) 收敛判定
          if |n_eff_new - n_eff_old| / n_eff_old < 1e-6: break
          T_field, n_eff_old = T_new, n_eff_new

      # (d) 后处理：相移与效率
      Δφ = (2*pi/λ0) * (n_eff_new - n_eff_0) * L
      results.append((P_k, Δφ, n_eff_new, T_field))

  # === 步骤 3：提取 Pπ 与调谐效率 ===
  Pπ = interp_P_for_Δφ_eq_pi(results)         # 线性插值
  η = dλ_dP = (dλ_dnT) * (dn_eff_dT) / (dP_dT)  # 链式法则
  assert 1e-3 < Pπ < 1.0   # 业务规则：Pπ 异常告警（规则 14，禁止 fall-back）
  return results, Pπ, η
```

## 7. 核心公式（LaTeX）

**傅里叶导热定律**：

$$\mathbf{q} = -k \nabla T, \quad Q_{Joule} = \frac{1}{2}\mathrm{Re}(\mathbf{J} \cdot \mathbf{E}^*)$$

**硅热光系数 Cocorullo 1999 经验公式**（300-550 K，1523 nm）：

$$\frac{dn}{dT}\bigg|_{\mathrm{Si}}(T) = 1.86 \times 10^{-4} + 4.3 \times 10^{-7}(T - 300) \quad [\mathrm{K^{-1}}]$$

**SiO₂ 温度系数**（Lumerical FEEM 工作流典型值）：

$$\frac{dn}{dT}\bigg|_{\mathrm{SiO_2}} = 1.0 \times 10^{-5}\,\mathrm{K^{-1}}$$

**SiN 温度系数**（PoLaRIS `pdk/sin/passive.py` 文献典型值）：

$$\frac{dn}{dT}\bigg|_{\mathrm{SiN}} = 2.4 \times 10^{-5}\,\mathrm{K^{-1}}$$

**热光相移与 Pπ**：

$$\Delta\varphi(P) = \frac{2\pi}{\lambda_0} \int_0^L \frac{dn_{eff}}{dT}\cdot \Delta T(P, z)\, dz, \quad P_\pi = P\big|_{\Delta\varphi=\pi}$$

**热调谐效率**（链式法则）：

$$\eta = \frac{d\lambda}{dP} = \frac{d\lambda}{dn_{eff}} \cdot \frac{dn_{eff}}{dT} \cdot \frac{dT}{dP}$$

**热串扰矩阵**（Lumerical INTERCONNECT Method-1，Teofilovic 2024 TPM 模型）：

$$\Delta\lambda_i = \sum_{j=1}^{N} C_{ij}\, P_j, \quad C_{ij} = \frac{\partial \lambda_i}{\partial P_j}\bigg|_{P_k=0,\, k\neq j}$$

其中 $C_{ij}$ 为热耦合矩阵元（pm/mW），由 HEAT 多次单独激励加热器 $j$、提取器件 $i$ 谐振波长漂移得到。对角元 $C_{ii}$ 为自加热系数，非对角元 $C_{ij}$ 为串扰系数。

**ThDM 热衰减模型**（Teofilovic 2024）：

$$C_{ij}(d) = C_{ij}(0) \cdot e^{-d/\lambda_{th}}$$

$d$ 为器件间距，$\lambda_{th}$ 为热衰减长度（典型 100-300 μm，取决于 SOI 埋氧层厚度与衬底下切）。

## 11. 创新点与差异化【创新】

*创新*：PoLaRIS 将 H02 热光调谐嵌入 AI 布局布线闭环优化，实现"热仿真→温度场→折射率→模式→S 参数→布局代价"零摩擦闭环，并基于 Cocorullo 1999 温度依赖 $dn/dT$ 提供超越 Lumerical 线性近似的二阶精度热光模型。

- **底层逻辑**：
  1. 复用 A07 HEAT 稳态求解器得到 $T(x,y,z)$，复用 A04 FDE 求解器得到 $n_{eff}(T)$，H02 仅实现耦合层（feedback.py + cocorullo.py + crosstalk.py）；
  2. Cocorullo 1999 二阶经验公式 $dn/dT(T) = 1.86\times10^{-4} + 4.3\times10^{-7}(T-300)$ 嵌入折射率更新，对 ΔT > 50 K 场景（如激光器自热）精度优于 Lumerical 线性近似；
  3. 热串扰耦合矩阵 $C_{ij}$ 由 HEAT 多次单源激励自动构建，输出至 E01/E02 布线引擎作为代价函数项，自动搜索热串扰最小的器件排布；
  4. 紧凑模型提取对标 Lumerical Thermal phase shifter workflow，输出 JSON 供 SAX 电路仿真复用，避免商业 CML Compiler 的格式壁垒；
  5. ThDM 指数衰减模型（Teofilovic 2024）支持布局无关的早期设计阶段热串扰预测。

- **支持理论**：
  - Cocorullo 1999（Appl. Phys. Lett.）证明晶硅 $dn/dT$ 在 300-550 K 范围与掺杂/晶向无关，仅依赖温度，为 PoLaRIS 二阶经验公式提供物理基础；
  - Lumerical HEAT+FEEM Thermally tuned waveguide 示例（Pπ=28 mW @ L=200 μm）验证热-光反馈链路可精确预测 π 相移功率；
  - Teofilovic 2024（arXiv:2404.10589）在 72-MZI 可编程光子网格上验证 TPM/ThDM/LR 三种热串扰模型，建模误差达 0.5 pm，证明矩阵化热串扰建模可行；
  - IMEC 3D PIC-EIC 热设计研究证明 FEM 多物理联合可量化 EIC 集成对加热器效率/串扰的 44% 影响，为 PoLaRIS 等效热导率建模提供方法论。

- **案例**：
  - SOI 热光 MZM 调相器（Pπ ≈ 28 mW，对标 Lumerical FEEM 示例）
  - SiN 微环热调谐（效率 0.15-0.8 nm/mW，对标 Opt. Lett. 2026 SiN MZI lattice）
  - 4 通道 DWDM 热串扰补偿（Cij 矩阵 5×5，对标 Lumerical INTERCONNECT Method-1）
  - 3D PIC-EIC 集成热设计（加热器效率退化 44%，对标 IMEC）

- **差异化点**：
  1. **AI 闭环**：PoLaRIS 是唯一将热光仿真嵌入 AI 布局布线闭环的开源工具，商业工具需手动导出温度场再喂入布局工具；
  2. **二阶精度**：Cocorullo 1999 温度依赖 $dn/dT$ 优于 Lumerical 线性近似，对大温差场景精度更高；
  3. **共享内核**：与 A07 HEAT 共享 FEM 内核，与 A04 FDE 共享 Yee 网格，避免商业工具的网格重复生成开销；
  4. **紧凑模型 JSON 输出**：跨工具兼容（SAX/INTERCONNECT），打破 CML Compiler 商业格式壁垒；
  5. **ThDM 早期预测**：布局无关的热串扰指数衰减模型，支持早期设计阶段快速评估。
