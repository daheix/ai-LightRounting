## 1. 概述与定位

奖励塑造（Reward Shaping）与课程学习（Curriculum Learning）是 PoLaRIS 光子 AI 布局布线引擎中强化学习训练范式的两大核心机制，对应聚类清单 D04（14 功能点）。本聚类承接 T13 AlphaChip 的预训练范式（AC-3.1~3.5）与奖励函数设计（AC-10.1~10.5）共 10 个对标功能点，并扩展 4 个光子专属功能点（端口对齐、弯曲半径、波导交叉、热串扰）。

**核心问题**：光子布局布线是稀疏奖励、长时序、多约束任务，PPO 直接训练难以收敛。需要：
- **奖励塑造**：将稀疏的"最终布局质量"奖励分解为密集的多目标分量（DRC/拥塞/线长/对称），引导中间动作；
- **课程学习**：按规模递增（5 器件 → 50 器件 → 200 器件）调度训练样本，由易到难，加速收敛并避免局部最优。

**学术定位**：本聚类为 PoLaRIS 的"差异化优势区"（共用工具数 ≤ 2），对标 AlphaChip 的预训练 + 奖励范式，并在光子领域引入专家知识奖励（独有）。

## 4. 奖励分解：多目标分量

PoLaRIS 奖励函数遵循 AlphaChip 负加权和范式（AC-10.1），并扩展光子专属分量。设布局布线状态 s，动作 a，奖励分解为：

**公式 4.1 多目标奖励分解**

```
R_total(s, a) = w_wl · r̂_wl + w_cong · r̂_cong + w_den · r̂_den
              - w_drc · r̂_drc - w_sym · r̂_sym - w_exp · r̂_exp
```

其中 r̂ 为归一化分量（见第 5 章），w 为权重（见 `ExpertRewardConfig`）。

**分量定义**：

| 分量 | 公式 | 来源 | 实现位置 |
|------|------|------|---------|
| 线长 r_wl | HPWL = Σ_e (max_x - min_x + max_y - min_y) | AC-10.2 | `benchmark_evaluator.py` |
| 拥塞 r_cong | LRT 模型预测拥塞概率 | AC-10.3 | `benchmark_evaluator.py` |
| 密度 r_den | DREAMPlace 网格化密度场 | AC-10.4 | `density_field.py` |
| DRC 惩罚 r_drc | 端口对齐 + 弯曲 + 交叉 + 热（见 4.2） | *创新* | `reward_shaping.py` |
| 对称惩罚 r_sym | 对称对位置偏差 Σ |d_i - d_j| | *创新*（光子 MZI 对称约束） | 待实现 ⚠️ |

**公式 4.2 DRC 惩罚子分量（ExpertRewardShaper）**

```
r_drc = w_align · (1 - port_alignment_score)      # 端口对齐
      + w_bend  · bend_violation_rate              # 弯曲半径违规率
      + w_cross · crossing_density                 # 交叉密度
      + w_therm · thermal_crosstalk_rate           # 热串扰违规率
```

参数取值（来源 `ExpertRewardConfig`，引用 SiEPIC EBeam PDK 推荐）：
- `port_alignment_weight = 0.3`（对齐对布线质量影响中等）
- `bend_violation_weight = 0.5`（弯曲违规导致制造失败，权重最高）
- `crossing_weight = 0.2`（交叉增加 0.5-1dB 损耗）
- `thermal_weight = 0.1`（热效应影响相对较小）
- `min_bend_radius_um = 5.0`（SiEPIC EBeam PDK 推荐 ≥5μm）

**理论保证**（L1, Ng 1999）：上述加权和形式满足势函数奖励塑形（PBRS）条件，即存在势函数 Φ(s) 使得 R'(s,a,s') = R(s,a,s') + γΦ(s') - Φ(s) 不改变最优策略。PoLaRIS 通过将所有分量设计为状态函数的差分形式，保证策略不变性。

## 5. 奖励归一化与加权求和

不同分量量纲差异巨大（线长 ~10^3 μm，拥塞 ~0-1，DRC ~0-1），直接加权会导致梯度尺度不平衡。PoLaRIS 采用运行均值方差归一化：

**公式 5.1 分量归一化**

```
r̂_i = (r_i - μ_i) / (σ_i + ε)
```

其中 μ_i, σ_i 为分量 i 在最近 N=1000 步的滑动均值与标准差，ε=1e-8 防除零。

**公式 5.2 加权求和（线性标量化，L5 MORLAIF）**

```
R = Σ_{i=1}^{K} w_i · r̂_i,    Σ w_i = 1
```

**公式 5.3 非线性扩展（L6 p-范数聚合，可选）**

```
R_p = (Σ_{i=1}^{K} w_i · r̂_i^p)^{1/p},    p ≤ 1
```

p < 1 时促进多目标公平性，避免单一目标主导。PoLaRIS 默认 p=1（线性），p<1 为可选增强项，仅在多目标冲突严重时启用。

## 6. 课程调度：规模递增

借鉴 Bengio 2009（L2）的 continuation method 思想，PoLaRIS 将光子网表按器件规模分级：

**课程等级表**：

| 等级 | 器件数 | 典型场景 | 训练轮数占比 |
|------|--------|---------|-------------|
| L0 | ≤ 5 | 单 MZI / 单环形谐振器 | 10% |
| L1 | 6-15 | 光子开光阵列 | 20% |
| L2 | 16-50 | WDM 解复用器 | 30% |
| L3 | 51-100 | 中规模 PIC | 25% |
| L4 | 101-200 | 大规模 PIC / 拓扑光子电路 | 15% |

**公式 6.1 课程调度函数（基于进度）**

```
L(ep) = L_k,  若 ep ∈ [T_k, T_{k+1})
其中 T_k = round(α_k · N_total),  α_k = Σ_{j<k} p_j
```

p_j 为第 j 等级轮数占比，N_total 为总训练轮数。

**公式 6.2 Bengio 课程样本分布（L2）**

```
Q_λ(z) ∝ W_λ(z) · P(z),  W_λ(z) = exp(-λ · d(z))
```

其中 d(z) 为样本 z 的难度（器件数），λ 从 0（全简单）递增到 ∞（原始分布 P）。PoLaRIS 采用离散化版本：λ 随等级 L_k 线性递增。

## 7. 自适应难度调节

固定课程可能因训练进度快慢不匹配而效率低下。PoLaRIS 引入学习进度（Learning Progress, LP）驱动的自适应升级（L7 Bootstrapped Reward Shaping 思想）：

**公式 7.1 学习进度估计**

```
LP_k(ep) = (1/τ) · Σ_{i=ep-τ+1}^{ep} R_i - (1/τ) · Σ_{i=ep-2τ+1}^{ep-τ} R_i
```

即最近 τ 轮平均奖励相对前 τ 轮的增量。LP > 0 表示仍在学习，LP ≈ 0 表示已收敛。

**公式 7.2 自适应升级判定**

```
升级到 L_{k+1}  当  LP_k < δ_hold  且  ep ≥ ep_min_k
回退到 L_{k-1}  当  LP_k < -δ_drop  且  k > 0
```

参数：δ_hold = 0.01（收敛阈值），δ_drop = 0.05（退化阈值），ep_min_k = 50（每级最少轮数）。

**伪代码 7.1 自适应课程调度器**

```python
class CurriculumScheduler:
    def __init__(self, levels, alpha, tau=20, delta_hold=0.01, delta_drop=0.05):
        self.levels = levels          # [5, 15, 50, 100, 200]
        self.alpha = alpha            # 各级轮数占比
        self.tau = tau
        self.delta_hold = delta_hold
        self.delta_drop = delta_drop
        self.current_level = 0
        self.reward_history = []

    def select_netlist(self, ep):
        # 1. 固定调度部分
        scheduled_level = self._scheduled_level(ep)
        # 2. 自适应修正
        if len(self.reward_history) >= 2 * self.tau:
            lp = self._learning_progress()
            if lp < self.delta_hold and ep >= self._min_episodes():
                self.current_level = min(self.current_level + 1, len(self.levels) - 1)
            elif lp < -self.delta_drop and self.current_level > 0:
                self.current_level -= 1
        target_level = max(scheduled_level, self.current_level)
        return self._sample_by_size(self.levels[target_level])

    def _learning_progress(self):
        recent = self.reward_history[-self.tau:]
        previous = self.reward_history[-2*self.tau:-self.tau]
        return sum(recent)/len(recent) - sum(previous)/len(previous)
```

## 9. 核心算法伪代码

### 9.1 完整训练循环（含奖励塑造 + 课程学习）

```python
def train_polaris_rl(config: TrainConfig) -> tuple[PPOAgent, list[dict]]:
    """PoLaRIS PPO 训练：奖励塑造 + 课程学习 + 自适应难度。

    Args:
        config: 训练配置（含课程调度参数）。
    Returns:
        (训练后的 agent, 训练日志)。
    """
    # 1. 初始化
    scheduler = CurriculumScheduler(
        levels=[5, 15, 50, 100, 200],
        alpha=[0.10, 0.20, 0.30, 0.25, 0.15],
    )
    shaper = ExpertRewardShaper(ExpertRewardConfig())
    normalizer = RewardNormalizer(num_components=5, window=1000)
    agent = PPOAgent(obs_dim, action_dim, config.ppo, hidden_dim=config.hidden_dim)

    logs = []
    for ep in range(config.num_episodes):
        # 2. 课程调度：选择当前等级网表
        netlist = scheduler.select_netlist(ep)
        net, devices, connections = load_netlist(netlist)
        env = FloorplanEnv(net, devices, canvas_w, canvas_h, grid_size)
        obs, _ = env.reset()

        # 3. Rollout 采集
        ep_reward = 0.0
        for step in range(config.rollout_steps):
            action, logprob, value = agent.get_action(obs)
            obs, raw_reward, terminated, _, info = env.step(action)

            # 4. 奖励塑造：多目标分解
            components = shaper.compute_components(obs, action, info)
            # 5. 奖励归一化
            normalized = normalizer.normalize(components)
            # 6. 加权求和（PBRS 保证策略不变）
            shaped_reward = sum(w * r for w, r in zip(weights, normalized))

            agent.store(Transition(obs, action, shaped_reward, logprob, value, terminated))
            ep_reward += shaped_reward
            if terminated:
                break

        # 7. PPO 更新
        metrics = agent.update(last_value=0.0)
        scheduler.reward_history.append(ep_reward)

        # 8. 自适应难度升级
        scheduler.maybe_advance(ep)

        # 9. 学习率退火（cosine）
        lr_scale = _lr_scale(ep, config.num_episodes, config.lr_schedule)
        _apply_lr_scale(agent, lr_scale, config.ppo.lr)

        logs.append({"episode": ep, "reward": ep_reward, "level": scheduler.current_level, **metrics})

    return agent, logs
```

### 9.2 奖励归一化器

```python
class RewardNormalizer:
    """运行均值方差奖励归一化（滑动窗口）。

    保证各分量尺度一致，避免梯度被大量纲分量主导。
    """
    def __init__(self, num_components: int, window: int = 1000, eps: float = 1e-8):
        self.window = window
        self.eps = eps
        self.buffers = [[] for _ in range(num_components)]

    def normalize(self, components: list[float]) -> list[float]:
        normalized = []
        for i, r in enumerate(components):
            self.buffers[i].append(r)
            if len(self.buffers[i]) > self.window:
                self.buffers[i].pop(0)
            mu = sum(self.buffers[i]) / len(self.buffers[i])
            var = sum((x - mu) ** 2 for x in self.buffers[i]) / len(self.buffers[i])
            sigma = var ** 0.5
            normalized.append((r - mu) / (sigma + self.eps))
        return normalized
```

### 10.2 PoLaRIS 独有创新（光子专属）

1. **端口对齐奖励**（*创新*）：光子器件端口对齐减少弯曲，电子芯片无此约束。逻辑：连接方向角越接近水平/垂直，弯曲数越少，损耗越低。支持理论：SiEPIC EBeam PDK 推荐对齐布线。
2. **弯曲半径惩罚**（*创新*）：波导弯曲半径 < 5μm 导致高损耗与制造失败，电子布线无此约束。来源：LiDAR ISPD'25。
3. **波导交叉惩罚**（*创新*）：光波导交叉引入 0.5-1dB 损耗，电子交叉可经通孔解决。
4. **热串扰惩罚**（*创新*）：热光移相器影响邻近微环谐振器，需保持 ≥100μm 间距。来源：Xiao et al., Opt. Express 2020。

### 10.3 商业差距

- AlphaChip 已部署于 4 代 TPU（L4），PoLaRIS 课程学习未实现（❌），预训练流程不完整（⚠️），是主要差距。
- 课程调度器与自适应难度计划 2026 Q3-Q4 实现，预计收敛速度提升 2-3×（参考 Bengio 2009 实验）。
