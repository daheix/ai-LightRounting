## 1. 概述与定位

2.5D-FDTD（variational FDTD，varFDTD）将 3D 平面波导器件沿垂直方向（z）折叠为 2D 等效问题，再用 2D Yee 网格 FDTD 求解。核心假设：垂直方向仅支持少数（通常 TE/TM 两个）slab 模，模间耦合可忽略。通过变分有效折射率法（Hammer & Ivanova 2009）将 3D 介电常数分布压缩为 2D 等效色散材料，2D FDTD 计算量与 2D 仿真相当，精度接近 3D FDTD。适用于 SOI/SiN 平面光子电路（脊波导、环谐振器、MMI、光栅耦合器、光子晶体波导），相对 3D FDTD 提速约 60–100×。

**PoLaRIS 定位**：2.5D-FDTD 是 PoLaRIS 求解器栈中"大尺寸平面 PIC 高效全波"路径的核心，复用 FDE（垂直 slab 模求解）+ FDTD（2D leapfrog）双内核（ALGORITHMS.md 附录 C 共享组件），由 ALGORITHMS.md 附录 B 列为 R39 优先级实现。纯 CPU + `numpy`/`scipy.sparse` 实现（规则 26），不参与 GPU 加速路径。

**对标状态**：T01 Lumerical MODE varFDTD、T04 Tidy3D effective index approximation、T15 曼光 MaxOptics 2.5D-FDTD 均已成熟商用，PoLaRIS 当前完全缺失自研 2.5D-FDTD（`docs/feature_gap_full_analysis.md` T01 第 18 项、T15 第 4 章 4.1–4.5 均 ❌），是大尺寸 PIC 仿真效率差距最大处之一。

## 2. 物理模型与控制方程

### 2.1 3D 时域 Maxwell 方程

$$\nabla \times \mathbf{E} = -\mu_0 \frac{\partial \mathbf{H}}{\partial t}, \quad \nabla \times \mathbf{H} = \varepsilon_0 \varepsilon_r(x,y,z,\omega) \frac{\partial \mathbf{E}}{\partial t}$$

其中 $\varepsilon_r$ 含材料色散。平面波导假设：器件在垂直 z 方向由若干均匀 slab 叠加构成，z 方向仅激发 TE/TM 两类 slab 模，模间耦合可忽略。

### 2.2 slab 模展开与投影

将 3D 场按参考位置 $(x_r,y_r)$ 处的垂直 slab 模 $M(z,\omega)$（传播常数 $\beta_r$，对应参考介电常数 $\varepsilon_r(z,\omega)$）展开，对 z 积分投影到 2D 平面，得到 2D 等效 Maxwell 方程。等效介电常数 $\varepsilon_{eff}(x,y,\omega)$ 同时含材料色散与波导色散（slab 几何压缩引入），需拟合为时域 MCM 形式后进入 2D FDTD。

## 3. 垂直 slab 模求解与 3D→2D 折叠（变分有效折射率）

### 3.1 第一步：FDE 1D slab 模求解

在用户指定的 slab 参考位置 $(x_r,y_r)$（应覆盖待研究的全部垂直结构，避开刻蚀孔等不连续处）求解 1D 垂直本征模：

$$\frac{d}{dz}\left(\frac{1}{\varepsilon_r(z,\omega)}\frac{dM}{dz}\right) + \left(k_0^2 - \frac{\beta_r^2}{\varepsilon_r(z,\omega)}\right)M = 0$$

得到 $M(z,\omega)$ 与 $\beta_r(\omega)$。复用 PoLaRIS FDE 求解器的 1D 本征路径（`scipy.sparse.linalg.eigsh`）。

### 3.2 第二步：变分有效折射率折叠（Hammer & Ivanova 2009）

对每个 2D 网格点 $(x,y)$，按 Hammer & Ivanova 变分公式生成等效介电常数。TE 模：

$$\varepsilon_{eff}^{TE}(x,y,\omega) = \left(\frac{\beta_r}{k}\right)^2 + \frac{\int_z \left(\varepsilon(x,y,z) - \varepsilon_r(z,\omega)\right)|M(z,\omega)|^2\,dz}{\int_z |M(z,\omega)|^2\,dz}$$

TM 模（含 $\partial_z M$ 项以保持界面连续性）：

$$\varepsilon_{eff}^{TM}(x,y,\omega) = \left(\frac{\beta_r}{k}\right)^2 \frac{\int_z \frac{1}{\varepsilon_r}|M|^2\,dz}{\int_z \frac{1}{\varepsilon(x,y,z)}|M|^2\,dz} + \frac{\int_z \left(\frac{1}{\varepsilon_r} - \frac{1}{\varepsilon(x,y,z)}\right)|\partial_z M|^2\,dz}{k^2 \int_z \frac{1}{\varepsilon(x,y,z)}|M|^2\,dz}$$

### 3.3 互易性方法替代（Snyder & Love）

Lumerical varFDTD 提供第二种折叠路径（reciprocity-based）：

$$n_{eff}(x,y,\omega) = \frac{\beta_r}{k} + \sqrt{\frac{\varepsilon_0}{\mu_0}} \frac{\int_z (\varepsilon(x,y,z) - \varepsilon_r(z,\omega))|E(z,\omega)|^2\,dz}{\int_z \mathbf{P}\cdot\hat{n}\,dz}$$

PoLaRIS 默认采用变分法（精度更优，文献 [1] 验证），互易性法作为可选对照路径。

### 3.4 物理性约束

折叠可能产生非物理等效折射率（如人为负虚部）。Lumerical/SimWorks 提供 "Clamp values to physical material properties" 选项，将 $\varepsilon_{eff}$ 限制在原始材料 min/max 范围内。PoLaRIS 默认开启该约束，违反时 `raise`（规则 14，禁止静默 fall-back）。

## 4. 2D Yee 网格 leapfrog 时间推进

### 4.1 2D Yee 网格布局

在 2D 平面（xy）布置 Yee 网格。TE 模场分量 $(E_z, H_x, H_y)$：$E_z$ 位于网格节点，$H_x$ 位于 y 棱中点，$H_y$ 位于 x 棱中点，交错排列保证中心差分二阶精度 $O(\Delta h^2)$，散度条件 $\nabla\cdot\mathbf{D}=0$ 自然满足（Yee 1966）。

### 4.2 leapfrog 更新公式

半步交错时间推进（磁场 $n\pm 1/2$，电场 $n$）：

$$H_x^{n+1/2}(i, j+\tfrac{1}{2}) = H_x^{n-1/2} - \frac{\Delta t}{\mu_0 \Delta y}\left[E_z^n(i,j+1) - E_z^n(i,j)\right]$$

$$H_y^{n+1/2}(i+\tfrac{1}{2}, j) = H_y^{n-1/2} + \frac{\Delta t}{\mu_0 \Delta x}\left[E_z^n(i+1,j) - E_z^n(i,j)\right]$$

$$E_z^{n+1}(i,j) = E_z^n + \frac{\Delta t}{\varepsilon_0 \varepsilon_{eff}}\left[\frac{H_y^{n+1/2}(i+\tfrac{1}{2},j) - H_y^{n+1/2}(i-\tfrac{1}{2},j)}{\Delta x} - \frac{H_x^{n+1/2}(i,j+\tfrac{1}{2}) - H_x^{n+1/2}(i,j-\tfrac{1}{2})}{\Delta y}\right]$$

TM 模 $(H_z, E_x, E_y)$ 对偶更新。$\varepsilon_{eff}$ 含色散时通过辅助微分方程（ADE）或卷积递推（RC）实现时域更新。

### 4.3 Courant 稳定性条件

2D leapfrog 稳定性：

$$\Delta t \le \frac{1}{c\sqrt{\frac{1}{\Delta x^2} + \frac{1}{\Delta y^2}}}$$

PoLaRIS 取 $\Delta t = 0.95 \times \Delta t_{CFL}$ 留安全裕度，超限 `raise`（规则 14）。

## 5. 边界条件与模式注入/提取

### 5.1 2D 平面边界

- **PML**：四边 SC-PML（复用 FDFD/FDE 共享组件，Shin & Fan 2012 拉伸坐标），吸收外向辐射。
- **PEC/PMC**：对称结构设电壁/磁壁，利用对称性减半计算量（如 Lumerical PhC 波导案例 [4]）。
- **周期/Bloch**：光子晶体波导横截面。

### 5.2 垂直方向

折叠后无显式边界，由 slab 模假设隐含处理（slab 模已含 z 方向 PML/辐射行为）。

### 5.3 模式分解注入

源由 FDE 在输入端口 2D 截面求解本地模 $\mathbf{e}_m,\mathbf{h}_m$，按 slab 模 $M(z)$ 折叠为 2D 等效源分布，注入 2D Yee 网格的 TF/SF 边界。注入幅度按模式功率归一化（同 ALGORITHMS.md §6.5）。

### 5.4 模式重叠积分提取 S 参数

输出端口以参考波导模 $\mathbf{e}_n,\mathbf{h}_n$ 为投影基，2D 场 $\mathbf{E}_{2D},\mathbf{H}_{2D}$（已含 slab 模剖面）做重叠积分：

$$\eta_{m\to n} = \frac{\left|\int (\mathbf{E}_{2D}\times \mathbf{H}_n^*)\cdot\hat{z}\,dA\right|^2}{\mathrm{Re}\int(\mathbf{E}_{2D}\times\mathbf{H}_{2D}^*)\cdot\hat{z}\,dA \cdot \mathrm{Re}\int(\mathbf{E}_n\times\mathbf{H}_n^*)\cdot\hat{z}\,dA}$$

$S_{ij} = \sqrt{\eta_{i\to j}}\,e^{i\phi_{ij}}$。复用 FDE/EME 的重叠积分实现（ALGORITHMS.md 附录 C）。

## 6. 等效材料色散拟合

$\varepsilon_{eff}(x,y,\omega)$ 在宽带仿真下随频率变化（材料色散 + 波导色散）。2D FDTD 需时域形式，按 Lumerical/SimWorks 流程：

1. **采样**：在用户指定带宽内取 $N_\omega$ 个频率点，逐点计算 $\varepsilon_{eff}(\omega)$（默认 $N_\omega=21$，可调）。
2. **MCM 拟合**：用多系数模型（Multi-Coefficient Model，Lumerical 标准）将 $\varepsilon_{eff}(\omega)$ 拟合为有理函数/Lorentz-Drude 形式，RMS 误差 $\le 10^{-3}$。
3. **窄带模式**：用户可选 "Narrow Bandwidth (Ignore Waveguide Dispersion)"，仅取中心频率 $\varepsilon_{eff}$，跳过拟合，速度更快。
4. **拟合失败**：`raise`（规则 14），禁止用单频近似 fall-back 充当宽带。

PoLaRIS MCM 拟合复用 FDTD 求解器的色散材料模块（A09 共享）。

## 7. 算法伪代码

```text
function varFDTD_Solve(ε_3d grid, slab_pos (xr,yr), λ_range, ports, pml_params, mesh):
    # 1. FDE 折叠：求垂直 slab 模 M(z,ω) 与 β_r(ω)
    ω_samples = linspace(c/min(λ_range), c/max(λ_range), N_ω)
    for ω in ω_samples:
        ε_r_1d, M[:,iω], β_r[iω] = FDE_solve_1d_slab(ε_3d, slab_pos, ω)  # 复用 FDE

    # 2. 变分有效折射率折叠（Hammer & Ivanova 2009）
    for (i,j) in 2D_mesh:
        ε_2d_TE[i,j,:] = variational_TE(ε_3d[i,j,:], ε_r_1d, M, β_r, ω_samples)
        ε_2d_TM[i,j,:] = variational_TM(ε_3d[i,j,:], ε_r_1d, M, ∂z_M, β_r, ω_samples)
    ε_2d = select_polarization(ε_2d_TE, ε_2d_TM, user_polarization)

    # 3. 物理性约束（clamp 到原始材料 min/max）
    ε_2d = clamp_to_physical(ε_2d, ε_3d)
    if any_unphysical: raise RuntimeError("varFDTD 折叠产生非物理 ε_eff")  # 规则 14

    # 4. MCM 色散拟合（宽带）或单频取值（窄带）
    if broadband:
        ε_eff_time = MCM_fit(ε_2d, ω_samples, tol=1e-3)
        if fit_failed: raise RuntimeError("MCM 拟合未收敛")  # 规则 14
    else:
        ε_eff_time = ε_2d[:,:,center_index]

    # 5. 2D Yee 网格 + SC-PML 边界
    grid2d = build_yee_2d(mesh, ε_eff_time, pml_params)  # 复用 FDE/FDFD 共享组件

    # 6. Courant 限步
    dt = 0.95 / (c * sqrt(1/dx^2 + 1/dy^2))

    # 7. 模式注入源（FDE 本地模折叠为 2D）
    src = fold_mode_to_2d(FDE_local_mode(port_in, λ_center), M)

    # 8. 2D leapfrog 时间推进
    Ez, Hx, Hy = init_fields(grid2d)
    for n in range(N_steps):
        Hx = update_Hx(Hx, Ez, dt, grid2d)        # NumPy 切片向量化
        Hy = update_Hy(Hy, Ez, dt, grid2d)
        apply_pml_H(Hx, Hy, grid2d)                # SC-PML
        Ez = update_Ez(Ez, Hx, Hy, dt, grid2d, ε_eff_time)  # 含色散 ADE/RC
        inject_source(Ez, src, n*dt)
        apply_pml_E(Ez, grid2d)
        if diverged(Ez): raise RuntimeError("varFDTD 发散")  # 规则 14

    # 9. 模式重叠积分提取 S 参数
    S = extract_s_parameters_overlap(Ez, Hx, ports, λ_center)
    return E_2d, H_2d, S
```

**说明**：
- 步骤 1 复用 FDE 1D 本征求解；步骤 5/8 复用 FDTD 2D leapfrog 与 SC-PML（ALGORITHMS.md 附录 C）。
- 步骤 3/4/8 任何失败均 `raise`（规则 14），禁止返回零场或单频近似 fall-back。
- 全程 `numpy` 向量化（NumPy 切片更新 Yee 网格），禁用 GPU（规则 26）。

## 8. PoLaRIS 实现创新点

*创新*：2.5D-FDTD 复用 FDE（垂直 slab 模）+ FDTD（2D leapfrog）双内核，纯 CPU + `numpy`/`scipy.sparse` 实现，无新算法负担。

- **底层逻辑**：
  - 第一步调用 FDE 求解器 1D 路径得到 $\beta_r, M(z)$（`scipy.sparse.linalg.eigsh`）；
  - 第二步按 Hammer & Ivanova 2009 变分公式 `numpy.trapz` 积分生成 2D 等效 $\varepsilon_{eff}$（TE/TM 双公式）；
  - 第三步纯 `numpy` 2D Yee leapfrog（NumPy 切片向量化，Courant 限步），SC-PML 复用 FDFD 共享组件；
  - 模式注入/提取复用 FDE/EME 重叠积分；
  - 宽带 MCM 拟合复用 FDTD 色散材料模块。
- **支持理论**：
  - Hammer & Ivanova 2009 [1] 证明变分有效折射率对 SOI 平面波导精度优于传统有效折射率法；
  - Lumerical varFDTD 白皮书 [5] 报告相对 3D FDTD 提速约 100×（环谐振器案例），与 2D FDTD 同等内存/时间；
  - Tidy3D [3] 验证变分有效介电常数对 2D→1D、3D→2D 折叠在合理精度内可复现全波仿真响应；
  - Yee 1966 [6] 提供 2D leapfrog 与 Yee 网格基础。
- **案例**：SOI 环谐振器、MMI 功分器、光栅耦合器、Y 分支逆向设计、LNOI 微环（Han 2018 [7]）、光子晶体线缺陷波导（Ivanova [4]）。差异化点：PoLaRIS 2.5D-FDTD 与 AI 逆向设计（adjoint）耦合，2D 网格下梯度计算成本远低于 3D，支持大规模器件拓扑优化；与 FDE/FDTD/FDFD 零成本共享 Yee 网格与 SC-PML，避免商业工具的格式壁垒。
- **CPU 战略（规则 26）**：PoLaRIS 不参与 GPU 加速。Lumerical/Tidy3D 的 GPU 路径仅作公式参考，实现完全基于 `numpy`+`scipy.sparse`+`scipy.sparse.linalg`。

## 11. 验收与测试要点

### 11.1 折叠正确性验证

- **均匀 slab 基准**：单层均匀 SOI slab（无横向结构），折叠后 $\varepsilon_{eff}^{TE}$ 应严格等于 $(\beta_r/k)^2$，相对误差 $\le 10^{-6}$。
- **TE/TM 分离基准**：双层 slab（芯+包层），折叠 $\varepsilon_{eff}^{TE/TM}$ 与解析有效折射率法结果 $L^2$ 范数 $\le 10^{-4}$。
- **跨求解器对比**：与 Tidy3D `var_eps_eff` notebook [3] 同结构同参考点对比，$\varepsilon_{eff}$ 相对误差 $\le 0.5\%$。

### 11.2 2D leapfrog 正确性

- **平面波传播**：2D 均匀介质平面波，场幅值/相位与解析解 $E_z=E_0 e^{i(k_xx+k_yy-\omega t)}$ 相对误差 $\le 10^{-4}$（每波长 ≥20 网格）。
- **Courant 验证**：$\Delta t = 1.01\times\Delta t_{CFL}$ 必须 `raise`（规则 14），$\Delta t = 0.95\times\Delta t_{CFL}$ 稳定运行 $10^4$ 步无发散。

### 11.3 端到端 S 参数验证
