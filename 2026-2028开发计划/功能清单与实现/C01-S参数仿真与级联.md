## 1. 概述与定位

S 参数（Scattering Parameters，散射参数）是线性射频/光子网络在频域描述多端口器件入射波与出射波关系的复数矩阵，是光子集成电路（PIC）频域仿真与级联的标准数学语言。其优势为：(1) 直接对应可测量物理量（功率反射/透射）；(2) 端口阻抗归一化，便于级联；(3) 与器件级求解器（FDTD/EME/RCWA）通过 Touchstone 标准对接；(4) 互易网络 S 矩阵对称（$S=S^T$），减少存储与计算量。S 参数级联是 PoLaRIS 仿真栈"电路级频域"路径的核心，与 C02 子网络增长算法、C03 Redheffer 星积、C05 频域扫描共同构成 C 类仿真级联体系。

**PoLaRIS 定位**：S 参数级联是 PoLaRIS 仿真栈"电路级频域"的核心，由 ALGORITHMS.md 列为 R01/R02 优先级实现。**当前状态：✅ 已有**——`src/polaris/sim/cascade.py:315` 提供 `cascade_circuit` 双后端实现（纯 numpy 子网络增长 + SAX 集成），`src/polaris/sim/models.py:159-455` 提供 10 种基础器件 S 参数模型。**实现目标**：补齐 KLU 后端、Additive 后端、Forward-only 后端、模型拟合、RF 模型，与 SAX 0.18+ 商业级对齐。

**对标状态**：8 工具共用 S 参数级联（C 类最大聚类，42 功能点），PoLaRIS 通过 SAX 复刻完整覆盖 26 项 ✅，10 项 ⚠️ 部分覆盖（KLU 后端缺失、嵌套设置、频率分辨率基准、模型拟合等），6 项 ❌ 完全缺失（KLU/Additive/Forward-only 后端、RF 模型、sax.fit 模型拟合、QPDK 量子 RF 集成）。最大差距为"后端多样性不足"，SAX 自 v0.10.0 起默认 KLU 后端，PoLaRIS 仅支持 FG + numpy 两后端。

## 2. 物理模型与 S 参数定义

### 2.1 散射参数定义

对于 N 端口线性网络，定义入射波 $a_i$ 与出射波 $b_i$（功率归一化，单位 $\sqrt{W}$）：

$$
\begin{pmatrix} b_1 \\ b_2 \\ \vdots \\ b_N \end{pmatrix}
=
\begin{pmatrix}
S_{11} & S_{12} & \cdots & S_{1N} \\
S_{21} & S_{22} & \cdots & S_{2N} \\
\vdots & \vdots & \ddots & \vdots \\
S_{N1} & S_{N2} & \cdots & S_{NN}
\end{pmatrix}
\begin{pmatrix} a_1 \\ a_2 \\ \vdots \\ a_N \end{pmatrix}
\quad\Longleftrightarrow\quad \mathbf{b} = \mathbf{S}\,\mathbf{a}
$$

其中 $S_{ij} = b_i / a_j\big|_{a_k=0,\,k\ne j}$ 表示端口 $j$ 入射、其余端口匹配（无反射）时端口 $i$ 的出射波。$|S_{ij}|^2$ 为功率传输比，$\arg(S_{ij})$ 为相位延迟。归一化条件：所有端口参考阻抗 $Z_0=50\,\Omega$（射频）或波导模式阻抗（光子）。

### 2.2 互易性、无源性、能量守恒

- **互易性**：互易介质网络 $S = S^T$，即 $S_{ij}=S_{ji}$。光子无源器件（波导、MMI、Y 分支、定向耦合器）通常互易。SAX `sax.reciprocal()` 自动填充对称项。
- **无源性**：无源无损网络满足 $\mathbf{S}^\dagger \mathbf{S} \preceq \mathbf{I}$（耗散矩阵半负定），等价 $\sum_i |S_{ij}|^2 \le 1$（每列功率守恒）。
- **幺正性**：无损网络 $\mathbf{S}^\dagger \mathbf{S} = \mathbf{I}$，即 $\sum_i |S_{ij}|^2 = 1$。PoLaRIS `models.py` 所有器件模型默认满足此条件（除显式插损）。
- **能量守恒校验**（规则 14）：`cascade_circuit` 输出后调用方应校验 $\sum_j |S_{ij}|^2 \le 1 + \varepsilon$（$\varepsilon=10^{-3}$），失败则 raise，禁止 fall-back。

### 2.3 频率相关 S 参数

S 参数是频率（或波长 $\lambda$）的复函数：$S_{ij}(\omega)$。波导传播模型典型形式：

$$
S_{21}(\lambda) = \alpha(\lambda)\, e^{i\phi(\lambda)},\quad
\phi(\lambda) = \frac{2\pi n_{\text{eff}}(\lambda) L}{\lambda},\quad
\alpha(\lambda) = 10^{-\alpha_{\text{dB/cm}}(\lambda)\cdot L/20}
$$

其中 $n_{\text{eff}}(\lambda)$ 为有效折射率（含色散 $n_g$），$L$ 为波导长度，$\alpha_{\text{dB/cm}}$ 为传播损耗。PoLaRIS `waveguide_s`（`models.py:159`）即此模型实现，支持波长数组（多波长 S 参数，feature 7.5 ✅）。

## 3. 器件 S 参数生成

器件 S 参数来源三类（`models.py` 实现）：

### 3.1 解析模型（Compact Model）

基于物理拟合的闭式表达式，参数化（PDK 典型值）：

| 器件 | 函数 | 公式核心 | 默认值来源 |
|------|------|---------|-----------|
| 波导 | `waveguide_s` | $e^{i\beta L}\cdot 10^{-\alpha L/20}$ | SiEPIC EBeam PDK $n_{\text{eff}}=2.4, n_g=4.0$ |
| Y 分支 | `y_branch_s` | $10^{-(IL+3)/20}$ 均分 | SiEPIC y_branch IL=0.3dB |
| 定向耦合器 | `directional_coupler_s` | $\tau=\sqrt{1-\kappa^2}$, $\kappa=i\sqrt{\kappa^2}$ | SiPANN directional_coupler |
| 环谐振器 | `ring_resonator_s` | $T=(t-ae^{i\phi})/(1-tae^{i\phi})$ | Yariv 1997 §10.5 Lorentzian |
| MMI 1×2/2×2 | `mmi_1x2_s`/`mmi_2x2_s` | $10^{-(IL+3)/20}$ 均分 + 交叉 π/2 | SiEPIC MMI IL=0.4/0.5dB |
| 光栅耦合器 | `grating_coupler_s` | 高斯谱 $e^{-(\lambda-\lambda_0)^2/2\sigma^2}$ | SiEPIC GC IL=1.9dB, BW=40nm |
| 移相器 | `phase_shifter_s` | $e^{i\phi_{\text{rad}}}\cdot 10^{-IL/20}$ | gdsfactory phase_shifter |
| 终端 | `terminator_s` | $10^{R_{\text{dB}}/20}$ | SiEPIC terminator -40dB |

参数 schema 验证（R01 创新点 2）：`RingParams`/`WaveguideParams`/`CouplerParams` dataclass `__post_init__` 校验非负/范围，非法 raise `ValueError` 告警退出（禁止 fall-back）。

### 3.2 物理求解器提取（FDTD/EME/RCWA → S 参数）

器件级求解器（A09-FDTD、A02-EME、A01-RCWA）通过端口模式重叠积分提取 S 参数（A09 §8.2）：

$$
S_{ij}(f) = \frac{\langle \mathbf{M}_j^{out}, \mathbf{E}^{out}(f)\rangle}{\langle \mathbf{M}_i^{in}, \mathbf{E}^{in}(f)\rangle},\quad
\langle \mathbf{M}, \mathbf{E}\rangle = \frac{1}{2}\int (\mathbf{E}\times\mathbf{H}_M^*)\cdot\hat{z}\,dA
$$

输出 Touchstone 格式（`.s2p`/`.s4p`），由 `src/polaris/sim/touchstone.py:184` `save_touchstone` 写入、`:133` `load_touchstone` 加载。

### 3.3 测量数据导入

通过 Touchstone 文件导入实测 S 参数，与解析/仿真模型交叉校验，`load_touchstone` 支持多端口、多频点。

## 4. 网络拓扑解析

### 4.1 网表结构（SAX netlist）

电路由三元组描述（SAX/Simphony 通用）：`instances`（实例→器件模型）、`connections`（内部连接 `"inst.port" ↔ "inst.port"`）、`ports`（外部端口名↔`"inst.port"`）。

### 4.2 端口引用语法

PoLaRIS 内部使用点号分隔 `"instance.port"`，SAX 0.14.7 要求逗号分隔 `"instance,port"`。`cascade.py:377` `_to_sax_ref` 完成转换。`_replace_instance_name`（`cascade.py:257`）使用精确 `"instance.port"` 分割替换，避免子串误替换（R03 修复 `mzi1` 误匹配 `mzi10` 的 bug）。

### 4.3 拓扑校验

- **端口匹配**：每条 connection 两端的端口必须存在于对应实例 S 参数字典中。
- **无悬挂端口**：除 `ports` 声明的外部端口外，所有实例端口必须被 connection 引用。
- **无环检测**：连接图应为森林（树集合），反馈环（如环谐振器）通过子网络增长算法的多连接对处理，无需显式环路检测。
- 失败则 raise `RuntimeError` 告警退出（规则 14）。

## 5. 级联遍历：子网络增长算法

### 5.1 算法核心思想

子网络增长（Subnetwork Growth）是 SAX/Simphony 默认级联算法：从每个实例作为独立子网络出发，按 connection 列表逐对合并子网络，消去内部端口，保留外部端口，最终得到单一子网络即电路级 S 矩阵。每次合并两个子网络时，对一对连接端口应用 S 参数消去公式，更新剩余端口的 S 参数。

### 5.2 双端口连接消去公式

子网络1（端口 A 含连接端口 $a$）与子网络2（端口 B 含连接端口 $b$）连接 $a\leftrightarrow b$，消去 $a,b$ 后剩余端口 $i,j$ 的 S 参数更新（`cascade.py:86` `_compute_cross_term`）：

$$
S'_{ij} = S_{ij}^{\text{direct}} + S_{iA}\cdot \frac{R}{1 - S_{AA}\cdot S_{BB}} \cdot S_{Bj}
$$

其中：
- $S_{ij}^{\text{direct}}$：i、j 同子网络时的直接 S 参数（异子网络则为 0）。
- $S_{iA}$：从端口 $i$ 到连接端口 $a$（同子网络1）或 $b$（子网络2）的传输。
- $S_{Bj}$：从连接端口 $b$（或 $a$）到端口 $j$ 的传输。
- $S_{AA}, S_{BB}$：连接端口的反射系数（自反射）。
- $R$：反射折返因子。同子网络时 $R = S_{BB}$（i 在子网络1）或 $R = S_{AA}$（i 在子网络2），表示信号需经对侧端口反射折返；异子网络时 $R=1$，直接交叉。

分母 $1 - S_{AA}\cdot S_{BB}$ 是反馈环路增益，当其趋零（强谐振/反馈）时数值不稳定。PoLaRIS 设阈值 `DENOM_MIN = 1e-15`（`cascade.py:33`，来源 Simphony 论文 §3.3），$|1-S_{AA}S_{BB}| < $ 阈值时 raise `RuntimeError` 告警退出，禁止 fall-back（规则 14.1）。

### 5.3 多连接对扩展

当一对子网络间存在多个连接端口（如总线波导并行连接），`_connect_ports`（`cascade.py:153`）对所有连接对求和交叉项。i、j 同子网络时每个连接对独立贡献反射折返项；异子网络时每个连接对独立贡献直接交叉项。

### 5.4 子网络合并与实例名重写

`_merge_subnetworks`（`cascade.py:207`）：
1. 解析 connection `"inst1.port1" ↔ "inst2.port2"`。
2. 从 `subnetworks` 字典取出两子网络 S 参数。
3. 调用 `_connect_ports` 合并，得到新子网络 S 参数。
4. 新子网络命名为 `f"{inst1}+{inst2}"`（如 `"lft+rgt"`），删除旧子网络。
5. 遍历剩余 connection，用 `_replace_instance_name` 精确替换实例名（R03 修复）。
6. 跳过两端口已同属一个合并子网络的 connection（避免自连接）。

### 5.5 端口重命名

最终子网络端口仍为内部名（如 `lft.in0`），需通过 `ports` 映射重命名为外部名（如 `in0`）。`_rename_ports`（`cascade.py:287`）构建"内部端口 → 外部端口列表"映射，对最终 S 参数字典的键批量重命名。

## 6. S 矩阵合并：Redheffer 星积

### 6.1 Redheffer 星积定义

Redheffer 星积 $\star$ 是两个块 S 矩阵 $\mathbf{A},\mathbf{B}$ 的二元运算，表示"将 A 的部分输出连接到 B 的输入"后的合成 S 矩阵。设 $\mathbf{A}=\begin{pmatrix}A_{11}&A_{12}\\A_{21}&A_{22}\end{pmatrix}$, $\mathbf{B}=\begin{pmatrix}B_{11}&B_{12}\\B_{21}&B_{22}\end{pmatrix}$，则 $\mathbf{C}=\mathbf{A}\star\mathbf{B}$：

$$
\begin{aligned}
C_{11} &= B_{11}(I - A_{12}B_{21})^{-1}A_{11} \\
C_{12} &= B_{11}(I - A_{12}B_{21})^{-1}A_{12}B_{22} + B_{12} \\
C_{21} &= A_{21} + A_{22}(I - B_{21}A_{12})^{-1}B_{21}A_{11} \\
C_{22} &= A_{22}(I - B_{21}A_{12})^{-1}B_{22}
\end{aligned}
$$

要求 $(I-A_{12}B_{21})$ 与 $(I-B_{21}A_{12})$ 可逆（push-through identity 保证两者同时可逆）。

### 6.2 与子网络增长的关系

子网络增长算法的双端口消去公式是 Redheffer 星积在"每对子网络单端口连接"特例下的简化形式。多端口批量连接时，Redheffer 星积更高效（一次性矩阵求逆，避免多次消去）。SAX 的 KLU 后端即基于 Redheffer 星积 + 稀疏 KLU 求解器（`klujax`），将整个电路的 S 矩阵合并转化为一次稀疏线性系统求解。PoLaRIS 当前仅实现子网络增长（`cascade.py`），Redheffer 星积自研为 C03 聚类目标（⚠️ 间接覆盖）。

### 6.3 性质（保结构）

- **存在性**：$(I-A_{12}B_{21})^{-1}$ 存在 ⟺ $(I-B_{21}A_{12})^{-1}$ 存在。
- **结合律**：$(\mathbf{A}\star\mathbf{B})\star\mathbf{C} = \mathbf{A}\star(\mathbf{B}\star\mathbf{C})$，支持任意级联顺序。
- **耗散保持**：$\mathbf{A},\mathbf{B}$ 耗散 ⟹ $\mathbf{A}\star\mathbf{B}$ 耗散（功率守恒传递）。
- **幺正保持**：$\mathbf{A},\mathbf{B}$ 幺正 ⟹ $\mathbf{A}\star\mathbf{B}$ 幺正（无损网络级联仍无损）。

## 7. SAX 后端体系：Filipsson-Gunnar 与 KLU

### 7.1 Filipsson-Gunnar 后端（FG）

基于 Filipsson 1981 论文的多端口 S 矩阵级联算法，逐对连接端口消去（即 §5 子网络增长）。SAX 默认后端（klujax 未安装时）。优势：实现简单、逐端口处理适合任意拓扑；劣势：$O(N^3)$ 端口扫描，大规模电路慢。PoLaRIS `_cascade_with_sax`（`cascade.py:397`）调用 SAX `circuit()` 即 FG 后端。

### 7.2 KLU 后端（默认，SAX v0.10.0+）

基于 Davis 2010 KLU 算法（SuiteSparse）的稀疏直接求解器。将电路 S 矩阵合并转化为稀疏线性系统 $(I - \mathbf{S}_{\text{internal}})\mathbf{x} = \mathbf{b}$，用 KLU 一次性求解。KLU 针对电路仿真矩阵优化：Block Triangular Form (BTF) 排序 + 近似最小度 (AMD) 填充减少 + Gilbert/Peierls 左看 LU 分解。优势：大规模电路（>1000 端口）显著快于 FG；劣势：仅 CPU + complex128，依赖 `klujax`。PoLaRIS **❌ 缺失** KLU 后端（feature 8.4/8.5），是性能差距核心。

### 7.3 Additive 后端（SAX v0.15+）

逐次累加实例 S 参数到全局 S 矩阵，适合无反馈前馈电路（如级联波导链）。优势：极快；劣势：不处理反馈环。PoLaRIS **❌ 缺失**（feature 8.7）。

### 7.4 Forward-only 后端

仅前向传播，忽略反射，适合单向光路（如 WDM 链路）。PoLaRIS **❌ 缺失**（feature 8.8）。

```python
def cascade_circuit(instances, connections, ports=None):
    """S 参数电路级联主入口（双后端自动切换）"""
    if not instances:
        return {}
    _validate_netlist(instances, connections, ports)  # 端口匹配/无悬挂/无自连接
    # 后端选择（R01 创新点 1）：ports 非 None 优先 SAX，失败 raise 禁止 fall-back
    if ports is not None:
        try:
            return _cascade_with_sax(instances, connections, ports)
        except (ValueError, KeyError, RuntimeError) as e:
            raise RuntimeError(f"SAX 级联失败: {e}. 禁止 fall-back") from e
    # 纯 numpy 子网络增长（独立实现，与 SAX 互为验证）
    subnetworks = dict(instances)
    for conn in list(connections):
        connections = _merge_subnetworks(subnetworks, connections, conn)
    if not subnetworks:
        return {}
    final_s = next(iter(subnetworks.values()))
    return _rename_ports(final_s, ports) if ports else final_s


def _merge_subnetworks(subnetworks, connections, conn):
    """合并 conn 涉及的两个子网络，返回更新后的连接列表"""
    inst1, port1 = conn[0].split(".")
    inst2, port2 = conn[1].split(".")
    if inst1 not in subnetworks or inst2 not in subnetworks:
        return connections  # 已合并跳过
    merged = _connect_ports(subnetworks[inst1], subnetworks[inst2], [(port1, port2)])
    new_name = f"{inst1}+{inst2}"
    subnetworks[new_name] = merged
    del subnetworks[inst1], subnetworks[inst2]
    # 精确实例名替换（R03 修复子串误匹配 mzi1→mzi10）
    new_conns = []
    for c in connections:
        c0 = _replace_instance_name(c[0], inst1, inst2, new_name)
        c1 = _replace_instance_name(c[1], inst1, inst2, new_name)
        if c0.split(".")[0] != c1.split(".")[0]:  # 跳过已合并的
            new_conns.append((c0, c1))
    return new_conns


def _connect_ports(s1, s2, connections):
    """子网络增长：连接 s1/s2 的端口对，消去内部端口"""
    ports1, ports2 = _collect_ports(s1), _collect_ports(s2)
    conn1, conn2 = {c[0] for c in connections}, {c[1] for c in connections}
    remaining_1, remaining_2 = ports1 - conn1, ports2 - conn2
    remaining = list(remaining_1) + list(remaining_2)
    if not remaining:
        return {}
    n_freq = len(next(iter(s1.values())))
    ctx = CascadeContext(remaining_1, remaining_2, connections, n_freq)
    return {
        (p_i, p_j): _get_direct_s(s1, s2, p_i, p_j, ctx)
                  + _compute_cross_term(s1, s2, p_i, p_j, ctx)
        for p_i in remaining for p_j in remaining
    }


def _compute_cross_term(s1, s2, p_i, p_j, ctx):
    """计算通过连接端口的间接传输交叉项（子网络增长核心公式）"""
    i_in_1, j_in_1 = p_i in ctx.remaining_1, p_j in ctx.remaining_1
    same_subnet = (i_in_1 == j_in_1)
    s_cross = np.zeros(ctx.n_freq, dtype=complex)
    for c1, c2 in ctx.connected:
        s_iA = _get_s_value(s1 if i_in_1 else s2, p_i, c1 if i_in_1 else c2, ctx.n_freq)
        s_Bj = _get_s_value(s1 if j_in_1 else s2, c1 if j_in_1 else c2, p_j, ctx.n_freq)
        s_AA = _get_s_value(s1, c1, c1, ctx.n_freq)
        s_BB = _get_s_value(s2, c2, c2, ctx.n_freq)
        denom = 1.0 - s_AA * s_BB  # 反馈环路增益
        # 数值稳定性：分母趋零告警退出（规则 14.1，Simphony §3.3）
        if np.any(np.abs(denom) < DENOM_MIN):
            raise RuntimeError(
                f"子网络增长分母趋零 (|1-S_AA·S_BB|={np.min(np.abs(denom)):.3e})"
                "，电路存在强谐振或反馈环路"
            )
        if same_subnet:  # 同子网络经对侧反射折返
            s_cross += s_iA * (s_BB if i_in_1 else s_AA) * s_Bj / denom
        else:  # 异子网络直接交叉
            s_cross += s_iA * s_Bj / denom
    return s_cross


def _cascade_with_sax(instances, connections, ports):
    """SAX FG 后端：构建网表 → sax.circuit() → 调用"""
    netlist_instances, models = {}, {}
    for name, sdict in instances.items():
        netlist_instances[name] = f"model_{name}"
        models[f"model_{name}"] = _make_model(sdict)  # 闭包返回固定 sdict
    netlist = {
        "instances": netlist_instances,
        "connections": {_to_sax_ref(c[0]): _to_sax_ref(c[1]) for c in connections},
        "ports": {ext: _to_sax_ref(ref) for ext, ref in ports.items()},
    }
    circuit, _ = sax.circuit(netlist=netlist, models=models)
    return circuit()
```
