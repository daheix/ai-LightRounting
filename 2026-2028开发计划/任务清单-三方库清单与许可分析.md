## 阶段 3：网络调研求解器算法公式（并行执行）

- [x] Task 3.1: 调研 RCWA（严格耦合波分析）算法公式
  - 来源：Moharam 1995, Li 1996, T04 Tidy3D 文档, T15 曼光文档
  - 内容：Maxwell 方程在周期结构的傅里叶展开、特征模求解、S 矩阵递推
  - 公式：傅里叶系数、本征值问题、Redheffer 星积

- [x] Task 3.2: 调研 EME（本征模展开法）算法公式
  - 来源：Lumerical EME 文档, T07 Photon Design FIMMPROP, T16 SimWorks EME
  - 内容：纵向本征模展开、模式匹配、S 矩阵级联
  - 公式：本征值方程、模式重叠积分、界面 S 矩阵

- [x] Task 3.3: 调研 BPM（光束传播法）算法公式
  - 来源：T15 曼光 BPM, T07 Photon Design OmniSim, Hadley 1992
  - 内容：SVEA 近似、Crank-Nicolson/ADI 差分、透明边界条件
  - 公式：抛物化波动方程、ADI 分裂格式

- [x] Task 3.4: 调研 HEAT（热传导求解器）算法公式
  - 来源：T15 曼光 OFC 2026, Fourier 导热方程教材
  - 内容：稳态/瞬态热传导、5 类边界条件、光-热/电-热耦合
  - 公式：∂T/∂t = α∇²T + Q、有限元离散

- [x] Task 3.5: 调研 DDM（漂移扩散模型）算法公式
  - 来源：T15 曼光 DDM, Scharfetter-Gummel 1969, Selberherr 1984
  - 内容：Poisson 方程、连续性方程、FVM 离散、Scharfetter-Gummel 离散
  - 公式：∇·(ε∇φ)=-q(p-n+N)、J_n=qD_n∇n+qμ_n n E

- [x] Task 3.6: 调研 FDE（本征模求解器）算法公式
  - 来源：T04 Tidy3D FDE, T15 曼光 FDE, T16 SimWorks FDE
  - 内容：Maxwell 本征值问题、有限元/有限差分离散、模式归一化
  - 公式：∇×(1/ε ∇×H)=ω²μ H

- [x] Task 3.7: 调研 FDFD（频域有限差分）算法公式
  - 来源：T16 SimWorks FDFD, Shin 1997
  - 内容：频域 Maxwell 方程离散、稀疏线性系统求解、PML
  - 公式：Ax=b 稀疏系统

- [x] Task 3.8: 调研 2.5D-FDTD 算法公式
  - 来源：T15 曼光 2.5D-FDTD, Tidy3d 2.5D 文档
  - 内容：FDTD+FDE 混合、模式分解注入、等效 2D 问题
  - 公式：模态叠加 + Yee 网格
