### 4.1 PPO（Proximal Policy Optimization）

| 项 | 值 |
|----|-----|
| 论文 | Schulman et al., "Proximal Policy Optimization Algorithms", 2017 |
| arXiv | https://arxiv.org/abs/1707.06347 |
| 核心公式 | `L^CLIP(θ) = E_t[min(r_t(θ)·A_t, clip(r_t(θ), 1-ε, 1+ε)·A_t)]` |
| 比率 | `r_t(θ) = π_θ(a_t|s_t) / π_θ_old(a_t|s_t) = exp(log π_new - log π_old)` |
| clip 范围 | ε = 0.2（SB3 默认，Schulman 2017 §3 推荐） |
| 实现文件 | `ppo.py` / `ppo_torch.py` / `ppo_agent_discrete.py` / `gnn_ppo.py` |
| 一致性 | ✅ 4 文件 PPO-Clip 公式完全一致 |
| 价值函数裁剪 | `v_loss = max((V-returns)², (clip(V, V_old±clip_vf)-returns)²)`，clip_vf=10.0（SB3 风格） |
| 优势标准化 | `(adv - mean) / (std + 1e-8)`（SB3 风格） |
| 总损失 | `L = L^CLIP + c₁·L^VF - c₂·S[π_θ]`，c₁=vf_coef=0.5，c₂=ent_coef=0.0（Schulman 2017 Eq.7） |

### 4.2 GAE（Generalized Advantage Estimation）

| 项 | 值 |
|----|-----|
| 论文 | Schulman et al., "High-Dimensional Continuous Control Using Generalized Advantage Estimation", ICLR 2016 |
| arXiv | https://arxiv.org/abs/1506.02438 |
| 核心公式 | `A_t^GAE(γ,λ) = Σ_{l=0}^{∞} (γλ)^l δ_{t+l}` |
| TD 残差 | `δ_t = r_t + γ·V(s_{t+1}) - V(s_t)` |
| 参数 | γ=0.99（折扣因子），λ=0.95（GAE 参数，Schulman 2015 §3.3 推荐） |
| 反向递推 | `last_gae = δ + γ·λ·non_terminal·last_gae`（高效计算） |
| 实现文件 | `ppo.py:compute_gae` / `ppo_buffers.py:compute_gae` |
| 一致性 | ✅ 2 文件 GAE 公式完全一致 |

### 4.3 Adam 优化器

| 项 | 值 |
|----|-----|
| 论文 | Kingma & Ba, "Adam: A Method for Stochastic Optimization", ICLR 2015 |
| URL | https://arxiv.org/abs/1412.6980 |
| 一阶矩 | `m_t = β₁·m_{t-1} + (1-β₁)·g_t` |
| 二阶矩 | `v_t = β₂·v_{t-1} + (1-β₂)·g_t²` |
| 偏置修正 | `m̂_t = m_t / (1-β₁ᵗ)`, `v̂_t = v_t / (1-β₂ᵗ)` |
| 更新规则 | `θ_t = θ_{t-1} - η·m̂_t / (√v̂_t + ε)` |
| 默认参数 | β₁=0.9, β₂=0.999, ε=1e-8（Kingma & Ba 2015 §2 推荐） |
| 实现文件 | `nn/__init__.py:Adam` |
| 一致性 | ✅ 偏置修正 + 一阶/二阶矩 + eps 数值稳定，与原文完全一致 |

| 论文 1 | Mirhoseini et al., "A graph placement methodology for fast chip design", Nature 2021 |

| 论文 2 | Mirhoseini et al., "AlphaChip", Nature 2024 |

### 4.5 V-trace（IMPALA off-policy 修正）

| 项 | 值 |
|----|-----|
| 论文 | Espeholt et al., "IMPALA: Scalable Distributed Deep-RL with Importance Weighted Actor-Learner Architectures", ICML 2018 |
| arXiv | https://arxiv.org/abs/1802.01561 |
| 截断比率 | `ρ̄_t = min(ρ_t, ρ̄)`, `c̄_t = min(ρ_t, c̄)`，ρ̄=1.0, c̄=1.0 |
| V-trace 值 | `v_s = V(x_s) + Σ_{t≥s} γ^(t-s) (Π_{i=s}^{t-1} c̄_i) δ_t V` |
| TD 残差 | `δ_t V = ρ̄_t (r_t + γ V(x_{t+1}) - V(x_t))` |
| 优势 | `A_t = ρ̄_t (r_t + γ v_{t+1} - V(x_t))` |
| 实现文件 | `trainer/vtrace.py` |
| 一致性 | ✅ 与 Espeholt 2018 §2 公式一致 |

| 实现文件 | `trainer/transfer_learning_ewc.py` / `rl/pretraining.py` |
| 一致性 | ✅ Fisher 估计 + λ 惩罚与原文一致 |
