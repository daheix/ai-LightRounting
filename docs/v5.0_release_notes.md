## 核心功能

### 1. 全流程光子 EDA（5 大核心流程，端到端集成测试验证）

- **DRC 设计规则检查**：18 类标准规则 + 8 类扩展规则，覆盖宽度/间距/包围/面积/角度/曲线全维度
- **LVS 版图原理图对比**：基于图同构（VF2 算法）的网表比对，支持器件/连接/端口匹配
- **寄生提取**：RLC 一站式提取 + S 参数计算 + SPICE 网表生成
- **良率分析**：蒙特卡洛 + Sobol 灵敏度 + 最坏情况距离（WCD）+ 容差分配
- **RL 布局布线**：DREAMPlace 解析法布局 + 弯曲波导 A* 布线 + 质量评分

### 2. 多物理场仿真

- FDTD 时域有限差分（含 CPML 吸收边界 / 色散介质 / 亚像素平滑）
- FDE 本征模求解 / EME 本征模展开 / RCWA 严格耦合波 / BPM 光束传播
- FDFD 频域有限差分 / HEAT 热传导 / DDM 漂移扩散

### 3. AI 与逆向设计

- AlphaChip Edge-GNN 强化学习布局（对标 Google DeepMind）
- PPO 策略梯度训练 + 好奇心探索 + 多智能体 + 离线 CQL
- 伴随方法逆向设计 + 拓扑优化 + 贝叶斯优化

### 4. 量子光子电路

- KLM 光量子计算 + HOM 干涉 + 玻色采样
- BB84 协议 + 连续变量 QEC
- Clements/Reck/Spanke 分解

### 5. PDK 与 GDSII

- 50+ GDSII 工具集（导入/导出/DRC/分析/转换）
- 多 PDK 支持（SOI/LNOI/InP/SiN + gdsfactory + SiEPIC）
- KLayout DRC 桥接 + OptoDesigner 集成
