04 · Algorithms

05核心算法能力

placement · routing · inverse design

布局 Placement

DREAMPlace + AlphaChip

DREAMPlace 解析法把布局建模为凸优化，GPU 加速梯度下降；叠加 AlphaChip PPO 强化学习，以占用栅格 + 图摘要为状态表征，策略网络输出元件落点。

Lin et al., DAC 2019 · Mirhoseini et al., Nature 2021

布线 Routing

LiDAR curvy-aware

LiDAR 弯曲感知布线（ISPD'25），支持 Euler 弯曲波导以降低损耗；采用 rip-up and reroute 策略处理冲突，全局-详细两段式布线器。

LiDAR, ISPD 2025

逆向 Inverse*创新*

JAX 可微 FDTD

以 JAX 实现端到端可微 FDTD，通过 jax.grad 自动微分直接对器件几何求梯度，替代传统手动伴随方程推导，显著降低逆向设计工程门槛。

Piggott et al., Nature Photonics 2017 · JAX autodiff

14 · Strategy

15技术战略

CPU-only · portable · academic-friendly
R04 · STRATEGIC · IRREVOCABLE

不参与 GPU 计算

2026-06-25 项目所有者指示。禁止 CuPy / CUDA / ROCm / Apple Metal 等所有 GPU 后端，禁止 FP16/BF16 半精度与多卡分布式。纯 NumPy / SciPy / JAX(CPU) 实现。

可移植性高

无 GPU 依赖，任意服务器 / 笔记本 / CI 即可运行，部署门槛极低。

学术友好

无需申请 GPU 配额，研究者可零成本复现，契合开源科研生态。
