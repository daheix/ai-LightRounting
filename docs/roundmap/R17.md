# R17（2027-11）：layout-aware 仿真

**路标编号**: R17
**月份**: 2027-11
**追赶对象**: VPIphotonics（layout-aware schematic-driven）+ Synopsys OptoDesigner
**综合得分目标**: 7.85 → 7.9
**文档版本**: v1.0
**创建日期**: 2026-06-22

## 1. 交付目标摘要

本月聚焦 layout-aware（版图感知）仿真对齐。VPIphotonics 的 VPItoolkit PDK <fab> 实现了"layout-aware schematic-driven PIC 设计方法学"：电路仿真器支持指定 PDK BB 在最终版图上的物理位置与方向，通过"smart elastic optical connectors"连接固定位置的子电路，自动调用 layout 工具（OptoDesigner/IPKISS/Nazca）确定弹性连接器的实际物理长度与形状，构建紧凑仿真模型。本月交付目标：(1) 实现 layout-aware 仿真模块 `src/polaris/sim/layout_aware.py`；(2) 实现 smart elastic optical connector 模型；(3) 实现寄生参数提取（波导长度、弯曲、损耗）；(4) 与 PoLaRIS 现有布局布线集成；(5) 综合得分从 7.85 提升至 7.9。

## 3. 公式与理论依据

### 3.1 Smart Elastic Optical Connector 模型

VPI 的 smart elastic optical connector 自动确定连接 BB 的波导长度与形状：

$$
L_{elastic} = f_{router}(P_{start}, P_{end}, \mathcal{O})
$$

$$
S_{elastic}(\lambda) = e^{-\alpha L_{elastic}/2} \cdot e^{j \beta(\lambda) L_{elastic}} \cdot \prod_{k} S_{bend}(\lambda, R_k)
$$

**变量定义**：
- $L_{elastic}$：弹性连接器物理长度（由布线器确定）
- $P_{start}, P_{end}$：起止端口位置
- $\mathcal{O}$：障碍物集合
- $f_{router}$：布线函数（A*/Rip-up&Reroute/曲线）
- $\alpha$：波导损耗（dB/cm）
- $\beta(\lambda)$：传播常数
- $S_{bend}(\lambda, R_k)$：第 $k$ 个弯曲的 S 参数（半径 $R_k$）

**推导来源**：Mingaleev 2016 ECIO；VPIphotonics-Luceda Whitepaper。

**适用条件**：BB 位置固定，连接器自动布线。

### 3.2 寄生参数提取

光子电路的"寄生"参数主要来自 layout 引入的额外波导长度：

$$
L_{parasitic} = L_{routed} - L_{schematic}
$$

$$
\alpha_{parasitic} = \alpha_{wg} \cdot L_{parasitic}, \quad \phi_{parasitic} = \beta \cdot L_{parasitic}
$$

**变量定义**：
- $L_{routed}$：实际布线长度
- $L_{schematic}$：原理图理想长度
- $L_{parasitic}$：寄生长度
- $\alpha_{wg}$：波导损耗系数

**推导来源**：Silvaco Hipex-RC 文档；电子 EDA 寄生提取理论。

**适用条件**：layout 与 schematic 存在长度偏差。

**数值示例**：MZI 两臂理想长度差 $\Delta L = 100\ \mu m$，实际布线 $\Delta L_{routed} = 105\ \mu m$，寄生 $L_{parasitic} = 5\ \mu m$，引入额外相位 $\phi_{parasitic} = 2\pi \cdot 2.4 \cdot 5 / 1.55 \approx 48.7\ \mathrm{rad}$。

### 3.3 Layout-aware 仿真反馈

Layout-aware 仿真将 layout 信息反馈到电路仿真：

$$
\mathbf{S}_{circuit}^{layout-aware}(\lambda) = \mathrm{Cascade}\left( \mathbf{S}_{BB_1}(\lambda), \mathbf{S}_{elastic_1}(\lambda, L_1), \mathbf{S}_{BB_2}(\lambda), \dots \right)
$$

**变量定义**：
- $\mathbf{S}_{circuit}^{layout-aware}$：layout-aware 电路 S 参数
- $\mathbf{S}_{BB_i}$：第 $i$ 个 BB 的 S 参数
- $\mathbf{S}_{elastic_i}$：第 $i$ 个弹性连接器的 S 参数（含 layout 长度 $L_i$）

**推导来源**：Mingaleev 2016 ECIO；Bogaerts 2013 SPIE 862702。

**适用条件**：BB 位置已确定，连接器已布线。

### 3.4 弯曲波导损耗模型

弯曲波导的辐射损耗（Marcuse 1982）：

$$
\alpha_{bend}(R) = C_1 \exp(-C_2 R), \quad C_1, C_2 = f(n_{eff}, \Delta n, \lambda)
$$

**变量定义**：
- $R$：弯曲半径
- $C_1, C_2$：与波导参数相关的常数
- $\alpha_{bend}$：弯曲辐射损耗（1/m）

**推导来源**：Marcuse, *Light Transmission Optics*, 2nd ed., §10；VPIphotonics 弯曲模型。

**适用条件**：单模波导，$R > R_{crit}$（临界半径）。

## 4. 开源方案缺点分析

### 4.1 gdsfactory 无 layout-aware 仿真反馈

- **问题描述**：gdsfactory 支持版图生成与布线，但无 layout-aware 仿真反馈（layout 信息不反馈到电路仿真）
- **影响**：用户需手动提取 layout 长度，重新构建电路网表仿真
- **来源 URL**: https://gdsfactory.github.io/gdsfactory/（无 layout-aware sim 模块）
- **根因分析**：gdsfactory 定位为版图工具，layout-aware 仿真需 VPI/IPKISS 商业工具

### 4.2 KLayout 无电路仿真

- **问题描述**：KLayout 是版图查看/DRC/LVS 工具，无电路仿真能力
- **影响**：无法在 KLayout 内做 layout-aware 仿真
- **来源 URL**: https://www.klayout.org/
- **根因分析**：KLayout 定位为版图工具

### 4.3 SAX/Simphony 无 layout 信息

- **问题描述**：SAX/Simphony 仅处理电路网表，无 layout 位置/长度信息
- **影响**：仿真结果不含 layout 寄生效应
- **来源 URL**: https://flaport.github.io/sax/
- **根因分析**：SAX/Simphony 定位为电路仿真器，与 layout 独立

### 4.4 OpenROAD-photonics 无 layout-aware 光子仿真

- **问题描述**：OpenROAD 的 layout-aware 仿真聚焦电子 IC（RC 寄生提取），无光子 layout-aware
- **影响**：无法处理光子电路的 layout 寄生（波导长度、弯曲损耗）
- **来源 URL**: https://github.com/The-OpenROAD-Project/OpenROAD
- **根因分析**：OpenROAD 聚焦电子 IC，光子扩展未实现 layout-aware

## 5. 源代码解读分析

### 5.1 `src/polaris/sim/sim_loop.py` — SimLoop 仿真回馈闭环

**关键函数**：
- `SimLoopConfig`：最大迭代次数 3，目标损耗 5.0 dB
- `SimLoopResult`：成功标志、最终布局/布线、总损耗、交叉数、违规列表
- 仿真回馈闭环：布局 → 布线 → S参数仿真 → 约束检查 → 反馈调整

**当前实现逻辑**：
1. 5 步闭环：布局 → 布线 → S参数仿真 → 约束检查 → 反馈调整
2. 反馈到布局/布线，但无 layout-aware 仿真（layout 信息未反馈到 S 参数）

**局限性**：
- 无 layout-aware 仿真（layout 长度未注入 S 参数）
- 无 smart elastic optical connector
- 无寄生参数提取

**改进点**：
- 增加 `LayoutAwareSimulator` 类，将 layout 长度注入 S 参数
- 增加 `ElasticConnector` 类，自动布线 + S 参数建模
- 增加 `ParasiticExtractor` 类，提取 layout 寄生

### 5.2 `src/polaris/router/waveguide_router.py` — 波导布线器

**关键函数**：
- 波导布线（A*/Rip-up&Reroute/曲线）
- 输出布线路径（waypoint 列表）

**当前实现逻辑**：
1. 8 方向 A* + Rip-up&Reroute + 拥塞感知
2. 输出 waypoint 路径，但路径长度未反馈到 S 参数

**局限性**：
- 布线结果未直接用于 S 参数仿真
- 无 elastic connector 抽象

**改进点**：
- 增加 `ElasticConnector` 类，封装布线结果 + S 参数建模
- 增加 `path_to_sparam(path, wavelengths) -> SDict`，将路径转为 S 参数

### 5.3 `src/polaris/sim/device_models.py` — 器件到 S 参数模型映射

**关键函数**：
- `_SMODEL_DISPATCH`：分发表，按器件名匹配 S 参数模型
- 波导模型 `waveguide_s(wl, length, neff, ng, loss_db_cm)`

**当前实现逻辑**：
1. 波导长度 `length` 为用户输入参数
2. 无 layout 自动提取长度

**局限性**：
- 波导长度需用户手动指定，无 layout 自动提取
- 无 elastic connector（自动布线 + S 参数）

**改进点**：
- 增加 `elastic_connector_s(path, wavelengths) -> SDict`，从布线路径自动计算 S 参数

### 5.4 `src/polaris/sim/calibration.py` — 校准与验证

**关键函数**：
- `CalibrationConfig`：损耗容差 0.5 dB
- `CalibrationItem`：单项校准结果（基准损耗 vs 仿真损耗）

**当前实现逻辑**：
1. 对比自研仿真与基准数据
2. 修正仿真模型参数

**局限性**：
- 无 layout-aware 校准（layout 寄生未纳入校准）
- 无弹性连接器校准

**改进点**：
- 增加 layout-aware 校准（含寄生长度）
- 增加弹性连接器校准

### 6.1 复刻清单（VPI layout-aware 能力对齐）

| Layout 长度注入 S 参数 | 无 | 新增 `path_to_sparam()` 函数 | 长度自动提取 |

### 6.2 改进点

1. **Elastic Connector**：实现 VPI 风格的 smart elastic optical connector，自动布线 + S 参数建模。
2. **Layout-aware 仿真**：将 layout 长度/弯曲/损耗注入电路 S 参数，实现 layout-aware 仿真。
3. **寄生参数提取**：提取 layout 引入的寄生长度/相位/损耗，反馈到电路仿真。

### 6.3 创新点（标注"创新"）

1. **【创新】AI 驱动的 layout-aware 布线优化**：利用 PoLaRIS PPO 框架，以 layout-aware 仿真损耗为奖励信号，优化布线路径，实现"损耗驱动的布线"。
   - *创新逻辑*：VPI 的 elastic connector 用最短路径布线，PoLaRIS 用 RL agent 优化布线以最小化仿真损耗（含弯曲、交叉）。
   - *支持理论*：RL 优化黑盒函数（Sutton & Barto 2018 §13）；布线 = 序列决策问题。
   - *案例预估*：Clements 8×8 矩阵，RL 布线预计比 A* 布线损耗降低 0.3 dB。

2. **【创新】Layout-aware 仿真与布局布线联合优化**：将 layout-aware 仿真损耗作为布局布线的奖励信号，实现"layout-aware 驱动的布局布线"。
   - *创新逻辑*：传统布局布线仅优化几何指标，PoLaRIS 增加 layout-aware 仿真损耗反馈。
   - *支持理论*：Apollo 2025 的"布线感知布局反馈"扩展到 layout-aware 仿真。
   - *案例预估*：Clements 8×8 矩阵，layout-aware 驱动布局预计比几何驱动布局损耗降低 0.5 dB。

3. **【创新】寄生参数的自动补偿**：在 layout-aware 仿真后，自动调整 BB 参数（如移相器相位）补偿 layout 寄生，实现"自补偿 PIC"。
   - *创新逻辑*：VPI 需用户手动补偿寄生，PoLaRIS 用优化算法自动补偿。
   - *支持理论*：凸优化（Boyd & Vandenberghe, *Convex Optimization*, §9）；寄生补偿 = 参数优化问题。
   - *案例预估*：MZI 两臂寄生 5μm，自动补偿移相器相位，预计补偿后消光比恢复 > 30 dB。

### 6.4 预期收益

- 综合得分 7.85 → 7.9（D03 仿真精度 8→8，D11 光电协同 6→7）
- Layout-aware 仿真支持弹性连接器
- 寄生参数自动提取与补偿
