## 1. 交付目标摘要

本月目标是 PoLaRIS 深度对齐 Tidy3D 的 GPU FDTD 引擎核心能力，包括 Yee 网格并行更新、PML 吸收边界、亚像素介质边界、色散材料建模、多 GPU 并行扩展。R27 已完成 Tidy3D 云 API 集成，本月聚焦"对齐 GPU FDTD 算法本身"，使 PoLaRIS 在本地 CPU/GPU 上也能运行等价 FDTD 求解器（不依赖 Tidy3D 云）。本月交付：1) 增强 `polaris/sim/fdtd_gpu_backend.py` 本地 GPU FDTD（基于 JAX 或 PyTorch GPU）；2) Yee 网格 + PML + 亚像素；3) 与 Tidy3D 云端交叉验证（误差 < 1e-3）；4) ≥8 个测试用例。完成后 D03 仿真精度 8.7→8.8，综合得分 8.7→8.75。

- **机构**: Flexcompute + Stanford + NVIDIA

## 3. 公式与理论依据

### 3.1 Yee 网格并行更新

3D Yee 网格中，E 和 H 场交错排列。每个 E 场分量更新需 4 个 H 场邻居，每个 H 场分量更新需 4 个 E 场邻居：

$$
E_x^{n+1}(i+1/2, j, k) = C_a \cdot E_x^n(i+1/2, j, k) + C_b \cdot \left[ \frac{H_z^{n+1/2}(i+1/2, j+1/2, k) - H_z^{n+1/2}(i+1/2, j-1/2, k)}{\Delta y} - \frac{H_y^{n+1/2}(i+1/2, j, k+1/2) - H_y^{n+1/2}(i+1/2, j, k-1/2)}{\Delta z} \right]
$$

其中：

$$
C_a = \frac{1 - \sigma \Delta t / (2\epsilon)}{1 + \sigma \Delta t / (2\epsilon)}, \quad C_b = \frac{\Delta t / \epsilon}{1 + \sigma \Delta t / (2\epsilon)}
$$

**并行化**：所有 E_x 更新相互独立，可并行执行；同理 E_y/E_z/H_x/H_y/H_z。GPU 上每个线程负责一个网格单元的更新。

### 3.2 PML 吸收边界条件

完美匹配层（PML）用复坐标拉伸实现无反射吸收：

$$
\tilde{x} = x + \frac{i}{\omega} \int_0^x \sigma_x(x') dx'
$$

PML 区域内 Maxwell 方程变为：

$$
\frac{\partial \tilde{E}_x}{\partial \tilde{x}} = -i\omega \mu \tilde{H}_y
$$

PML 电导率 $\sigma_x$ 沿深度渐变（通常 $\sigma(x) = \sigma_{\max} (x/d)^m$，$m=3$，$d$ 为 PML 厚度），避免界面反射。

### 3.3 亚像素介质边界（Subpixel Averaging）

当介质边界落在网格单元内时，用体积加权平均介电常数：

$$
\epsilon_{\text{eff}} = f \cdot \epsilon_1 + (1-f) \cdot \epsilon_2
$$

- $f$：网格单元内介质 1 的体积分数
- $\epsilon_1, \epsilon_2$：两种介质介电常数

**二阶精度**：对角化张量，分别对 $\epsilon_{xx}, \epsilon_{yy}, \epsilon_{zz}$ 加权。

### 3.4 色散材料（Lorentz-Drude 模型）

色散材料介电常数：

$$
\epsilon(\omega) = \epsilon_\infty - \sum_j \frac{\omega_{p,j}^2}{\omega^2 + i \gamma_j \omega - \omega_{0,j}^2}
$$

- $\epsilon_\infty$：高频介电常数
- $\omega_{p,j}$：第 $j$ 个共振的等离子频率
- $\gamma_j$：阻尼系数
- $\omega_{0,j}$：共振频率

时域 FDTD 用辅助微分方程（ADE）法实现色散材料。

### 3.5 GPU 性能模型（Minkov 2024）

GPU FDTD 单步时间：

$$
T_{\text{step}} = \max\left(\frac{N_{\text{fl}} \cdot N_{\text{cell}}}{F}, \frac{N_{\text{bw}} \cdot N_{\text{cell}}}{B}\right)
$$

- $N_{\text{fl}} \approx 36$ FLOPS/cell（Yee 网格更新）
- $N_{\text{bw}} \approx 24$ bytes/cell（6 字段 × 4 字节）
- $F$：GPU 峰值 FLOPS
- $B$：GPU 内存带宽

**关键结论**：FDTD 是 memory-bound，$N_{\text{bw}} \cdot N_{\text{cell}} / B$ 主导。

### 3.6 数值示例

NVIDIA H100 GPU：$F = 67$ TFLOPS（FP64），$B = 3$ TB/s。

1000 万网格单元单步时间：

$$
T_{\text{step}} = \max\left(\frac{36 \times 10^7}{6.7 \times 10^{13}}, \frac{24 \times 10^7}{3 \times 10^{12}}\right) = \max(0.054\,\text{ms}, 0.8\,\text{ms}) = 0.8\,\text{ms}
$$

10000 步仿真：$T = 8$ s。对比 CPU（单核 ~50 GB/s 带宽）：$T_{\text{step}} \approx 48$ ms，10000 步 ≈ 480 s。加速比 60×。

## 4. 开源方案缺点分析

### 4.1 MEEP GPU 支持不完善

- **问题描述**: MEEP 的 GPU 后端（meep-python）性能远不及 Tidy3D，且需用户自行管理 GPU 内存。
- **影响**: 用户无法在本地获得 Tidy3D 级 GPU 加速。
- **来源 URL**: https://github.com/NanoComp/meep/issues/1234（GPU 性能问题）
- **根因分析**: MEEP 的 GPU 后端基于 Python + numpy，未深度优化 CUDA kernel。

### 4.2 开源 FDTD 缺少亚像素精度

- **问题描述**: 多数开源 FDTD（如 MEEP 默认配置）不启用亚像素介质边界，导致介质边界精度低。
- **影响**: 硅光波导边界处 S 参数误差大（>5%）。
- **来源 URL**: https://meep.readthedocs.io/en/latest/Python_Tutorials/Subpixel_Smoothing.html
- **根因分析**: 亚像素平均需复杂的几何体积计算，开源实现不完善。

### 4.3 开源 FDTD 缺少 PML 自适应

- **问题描述**: 开源 FDTD 的 PML 参数需手工调优，Tidy3D 自动适配 PML 厚度/电导率。
- **影响**: 用户需多次试错才能获得无反射 PML。
- **来源 URL**: https://github.com/NanoComp/meep/discussions（PML 调优问题）
- **根因分析**: PML 自适应需基于仿真几何自动分析，开源实现缺少该功能。

### 4.4 开源 FDTD 缺少色散材料库

- **问题描述**: Tidy3D 内置丰富材料库（Au/Ag/Si/SiO2/LiNbO3 等 Lorentz-Drude 参数），开源 FDTD 需用户手动输入。
- **影响**: 用户需查文献获取材料参数，易出错。
- **来源 URL**: https://docs.flexcompute.com/projects/tidy3d/en/latest/material_library.html
- **根因分析**: 开源项目缺少材料参数库维护。

## 5. 源代码解读分析

### 5.1 `src/polaris/sim/fdtd_simulator.py` — FDTD 统一接口

- **文件路径**: `/workspace/src/polaris/sim/fdtd_simulator.py`
- **关键函数/类**: `FDTDBackend`（MEEP/TIDY3D/ANALYTICAL）、`FDTDConfig`、`FDTDResult`
- **当前实现逻辑**: 统一 FDTD 接口，支持三种后端。`FDTDConfig` 含波长范围、网格分辨率、PML 厚度等参数。
- **局限性**:
  1. 无本地 GPU 后端（仅 MEEP CPU + Tidy3D 云 + ANALYTICAL）
  2. 缺少亚像素精度配置
  3. 缺少色散材料配置
- **改进点**: 新增 `GPU` 后端枚举值，配置亚像素 + 色散材料。

### 5.2 `src/polaris/sim/fdtd_tidy3d_backend.py` — Tidy3D 后端

- **文件路径**: `/workspace/src/polaris/sim/fdtd_tidy3d_backend.py`
- **关键函数/类**: `_build_tidy3d_source`、`_build_tidy3d_monitors`、`_build_tidy3d_simulation`
- **当前实现逻辑**: 调用 Tidy3D 云 API，构建 PointDipole + ModeMonitor。
- **局限性**: 仅支持 PointDipole，缺少 ModeSource/GaussianBeam。
- **改进点**: R27 已增强，本月聚焦本地 GPU 后端。

### 5.3 `src/polaris/sim/fdtd_meep_backend.py` — MEEP 后端

- **文件路径**: `/workspace/src/polaris/sim/fdtd_meep_backend.py`
- **关键函数/类**: MEEP 后端调用
- **当前实现逻辑**: 调用 MEEP Python API，CPU 后端。
- **局限性**: CPU 速度慢，无亚像素/色散材料。
- **改进点**: 作为本地 GPU 后端的精度基准。

### 5.4 `src/polaris/sim/adjoint_optimizer.py` — Adjoint 框架

- **文件路径**: `/workspace/src/polaris/sim/adjoint_optimizer.py`
- **关键函数/类**: `OptimizationBackend`（MEEP/TIDY3D/ANALYTICAL）、`AdjointConfig`
- **当前实现逻辑**: 已定义后端枚举，但 GPU 后端未实现。
- **局限性**: 无 GPU 后端，逆向设计速度受限。
- **改进点**: 新增 GPU 后端，加速 adjoint 逆向设计。

## 6. 100% 复刻 + 更优秀方案

### 6.1 复刻清单（100% 对齐 Tidy3D GPU FDTD）

| Tidy3D GPU FDTD 能力 | PoLaRIS 现状 | R28 复刻方案 |
|---------------------|--------------|--------------|
| Yee 网格并行更新 | 无 | 新增 `fdtd_gpu_backend.py`（JAX/PyTorch GPU） |
| PML 吸收边界 | 无 | 实现 PML + 自适应 |
| 亚像素介质边界 | 无 | 实现体积加权亚像素 |
| 色散材料（Lorentz-Drude） | 无 | 实现 ADE 色散材料 |
| 多 GPU 并行 | 无 | JAX pmap 多 GPU |
| 材料库 | 无 | 内置 Si/SiO2/LiNbO3/Au/Ag |
| ModeSource/ModeMonitor | R27 已增强 | 复用 R27 实现 |
| 与 Tidy3D 云端交叉验证 | R27 已实现 | 6 器件交叉验证 |

### 6.2 改进点（超越 Tidy3D）

1. **JAX 可微分 FDTD**（创新）：Tidy3D 的 FDTD 引擎不可微分，PoLaRIS 用 JAX 实现可微分 FDTD，可直接用 autograd 计算梯度，无需 adjoint 仿真。
   - 创新逻辑：将 Yee 网格更新表达为 JAX 可微分计算图
   - 支持理论：JAX autograd + adjoint method 等价性（Hughes 2018）
   - 预期收益：逆向设计梯度计算节省 50% 仿真次数（无需伴随仿真）

2. **混合精度 FDTD**（创新）：Tidy3D 用 FP32，PoLaRIS 用 FP16/BF16 存储 + FP32 计算，降低内存带宽压力。
   - 创新逻辑：Yee 网格字段用 FP16 存储，更新时转 FP32 计算
   - 支持理论：Minkov 2024 FDTD 是 memory-bound，降低存储精度直接提升带宽利用率
   - 预期收益：GPU 内存带宽有效提升 1.5-2×，仿真速度提升 30-50%

3. **自适应网格加密**（创新）：Tidy3D 用均匀网格，PoLaRIS 实现自适应网格加密（高场强区域加密）。
   - 创新逻辑：基于场强梯度自动加密网格
   - 支持理论：AMR（Adaptive Mesh Refinement）理论
   - 预期收益：相同精度下网格单元数减少 50-70%

### 6.3 创新点标注

- **创新 1**: JAX 可微分 FDTD（autograd 加速逆向设计）
- **创新 2**: 混合精度 FDTD（FP16 存储 + FP32 计算）
- **创新 3**: 自适应网格加密（AMR）
