## 1. 交付目标摘要

本月聚焦 VPIphotonics 风格的系统级光子电路仿真对齐。VPIcomponentMaker Photonic Circuits 的核心创新是"时域 + 频域无缝混合仿真框架"：所有无源子电路用频域级联散射矩阵（S-matrix）精确建模，时域仿真仅用于无源子电路与有源器件的接口，避免纯时域方法在数千个色散组件上的精度损失。本月交付目标：(1) 实现系统级仿真模块 `src/polaris/sim/system_level.py`，支持频域/时域/TLLM 三种模式；(2) 实现信号流图（SFG）抽象，支持光通信链路级仿真；(3) 至少 3 个光通信链路示例（NRZ/PAM4/QAM）；(4) 与 VPIphotonics 公开示例数值对齐；(5) 综合得分从 7.55 提升至 7.65。

## 3. 公式与理论依据

### 3.1 系统级传递函数（信号流图）

光子电路可表示为信号流图（SFG），节点为器件端口信号，边为 S 参数传输。系统传递函数用 Mason 增益公式计算：

$$
H = \frac{\sum_k P_k \Delta_k}{\Delta}, \quad \Delta = 1 - \sum L_i + \sum L_i L_j - \sum L_i L_j L_k + \dots
$$

**变量定义**：
- $P_k$：第 $k$ 条前向路径增益
- $\Delta$：图行列式（determinant of graph）
- $L_i$：第 $i$ 个环路增益
- $L_i L_j$：非接触环路对乘积
- $\Delta_k$：与第 $k$ 条前向路径不接触的子图行列式

**推导来源**：Mason, *Feedback Theory: Further Properties of Signal Flow Graphs*, Proc. IRE 44(7), 920-926 (1956)。

**适用条件**：线性时不变系统，单输入单输出（MIMO 需逐对计算）。

### 3.2 TLLM（Transmission-Line Laser Model）时域模型

VPI 的 TLLM 将激光器分段，每段用传输线模型建模：

$$
\frac{\partial N(z,t)}{\partial t} = \frac{I}{qV} - \frac{N}{\tau_n} - v_g G(N) S
$$
$$
\frac{\partial S(z,t)}{\partial t} = \Gamma v_g G(N) S - \frac{S}{\tau_p} + \beta \frac{N}{\tau_n}
$$

**变量定义**：
- $N(z,t)$：载流子浓度（cm⁻³）
- $S(z,t)$：光子密度（cm⁻³）
- $I$：注入电流（A），$q$：电子电荷，$V$：有源区体积
- $\tau_n$：载流子寿命，$\tau_p$：光子寿命
- $v_g$：群速度，$G(N)$：增益函数（通常 $G = a(N-N_0)$）
- $\Gamma$：限制因子，$\beta$：自发辐射因子

**推导来源**：Lowery 等, *Transmission-line laser model*, IEE Proc. J 134(5), 281-289 (1987)。

**适用条件**：半导体激光器/放大器，载流子速率方程近似。

**数值示例**：典型 InGaAsP 激光器，$N_0 = 1.5\times10^{18}\ \mathrm{cm^{-3}}$，$a = 2\times10^{-16}\ \mathrm{cm^2}$，$\tau_n = 1\ \mathrm{ns}$，$\tau_p = 1\ \mathrm{ps}$，$\beta = 10^{-5}$。

### 3.3 频域-时域混合仿真接口

VPI 的混合框架将无源子电路（频域 S-matrix）与有源器件（时域 TLLM）通过"虚拟双向连接"耦合：

$$
\mathbf{a}_{active}(t) = \mathcal{F}^{-1}\left\{ \mathbf{S}_{passive}(\omega) \cdot \mathcal{F}\{\mathbf{b}_{active}(t)\} \right\}
$$

**变量定义**：
- $\mathbf{a}_{active}(t)$：有源器件入射波时域信号
- $\mathbf{b}_{active}(t)$：有源器件出射波时域信号
- $\mathbf{S}_{passive}(\omega)$：无源子电路频域 S 矩阵
- $\mathcal{F}$ / $\mathcal{F}^{-1}$：FFT / IFFT

**推导来源**：Mingaleev 2015 SPIE 951602；VPIphotonics 白皮书。

**适用条件**：无源子电路线性时不变，有源器件非线性但可分段时域求解；时间步长需满足 Nyquist 采样（$\Delta t < 1/(2 f_{max})$）。

### 3.4 多尺度 PIC 仿真

VPI 支持同一芯片上 μm 到 cm 尺度混合：

$$
\Delta t_{global} = \min\left( \frac{\Delta z_{min}}{v_g}, \frac{L_{min}}{v_g} \right)
$$

为避免全局时间步过小，VPI 采用"子电路抽象"：长波导用频域相位 $e^{j\beta L}$ 精确建模，无需时域分段。

**适用条件**：无源长波导 + 有源短器件混合，频域处理长尺度，时域处理短尺度。

## 4. 开源方案缺点分析

### 4.1 Simphony 仅支持频域，无时域仿真

- **问题描述**：Simphony 仅实现频域 S 参数级联，无 TLLM/时域脉冲响应
- **影响**：无法仿真激光器瞬态、调制器时域波形、光脉冲传输
- **来源 URL**: https://simphonyphotonics.readthedocs.io/en/stable/（无 time-domain API）
- **根因分析**：Simphony 定位为频域电路仿真器，时域需借助 MEEP FDTD（器件级，非电路级）

### 4.2 SAX 无系统级链路仿真

- **问题描述**：SAX 聚焦 S 参数级联，无光通信链路（发射机→光纤→接收机）级仿真
- **影响**：无法评估 BER、眼图、OSNR 等系统级指标
- **来源 URL**: https://github.com/flaport/sax（无 link/system 模块）
- **根因分析**：SAX 定位为电路级仿真器，系统级需 VPItransmissionMaker Optical Systems 等专用工具

### 4.3 OpenROAD-photonics 无光子电路仿真

- **问题描述**：OpenROAD 作为电子 EDA 工具，无光子电路仿真能力
- **影响**：无法在 OpenROAD 流程中评估光子电路性能
- **来源 URL**: https://github.com/The-OpenROAD-Project/OpenROAD
- **根因分析**：OpenROAD 聚焦数字 IC，光子扩展仅覆盖 DRC

### 4.4 MEEP FDTD 无法处理电路级大规模 PIC

- **问题描述**：MEEP 是器件级 FDTD 仿真器，处理整个 PIC（数百器件）计算量爆炸
- **影响**：电路级仿真需用 S 参数级联，不能直接用 FDTD
- **来源 URL**: https://meep.readthedocs.io/（FDTD 计算量 ~ N³，N 为网格数）
- **根因分析**：FDTD 是全波电磁仿真，计算复杂度 O(N³)，电路级需用紧凑模型 + S 参数级联

## 5. 源代码解读分析

### 5.1 `src/polaris/sim/simulator.py` — CircuitSimulator

**关键函数**：
- `CircuitSimulator.simulate(netlist, wavelengths, **model_kwargs) -> SDict`：频域仿真

**当前实现逻辑**：
1. 仅频域 S 参数级联
2. 无时域、无 TLLM、无系统级链路

**局限性**：
- 无时域脉冲响应计算
- 无系统级链路（发射机/光纤/接收机）抽象
- 无 BER/眼图/OSNR 评估

**改进点**：
- 新增 `src/polaris/sim/system_level.py`，实现系统级链路仿真
- 新增 `TimeDomainSimulator` 类，支持 TLLM 风格时域仿真
- 新增 `LinkBudget` 类，评估 OSNR/BER

### 5.2 `src/polaris/sim/fdtd_simulator.py` — FDTD 全波仿真

**关键函数**：
- `run_fdtd_simulation(device, config) -> FDTDResult`：器件级 FDTD 仿真
- `_select_fdtd_backend(device, config) -> FDTDResult`：后端调度（MEEP/Tidy3D/ANALYTICAL）

**当前实现逻辑**：
1. 器件级 FDTD，非电路级
2. 支持 MEEP/Tidy3D/解析三种后端
3. ANALYTICAL 后端为独立接口（非 fall-back）

**局限性**：
- 仅器件级，无法处理电路级大规模 PIC
- 无时域电路仿真（TLLM）

**改进点**：
- 增加 `TimeDomainCircuitSimulator`，基于 TLLM 处理电路级时域
- 与频域 S 参数级联混合（VPI 风格）

### 5.3 `src/polaris/sim/cascade.py` — S 参数级联器

**关键函数**：
- `cascade_circuit(instances, connections, ports) -> SDict`：频域 S 参数级联

**当前实现逻辑**：
1. SAX 后端优先，失败则纯 numpy 子网络增长
2. 仅频域，无时域

**局限性**：
- 无时域 S 参数（脉冲响应）级联
- 无频域-时域混合接口

**改进点**：
- 增加 `cascade_time_domain(instances, connections, ports, t_array) -> dict`，时域级联
- 增加 `hybrid_cascade(frequency_instances, time_instances, ...)`，混合级联

### 5.4 `src/polaris/sim/sparam_calibration.py` — S 参数校准

**关键函数**：
- `SParamCalibrationConfig`：校准配置（幅度容差 0.5 dB，相位容差 0.1 rad）
- `SParamPairResult`：单端口对校准结果

**当前实现逻辑**：
1. FDTD → S 参数提取 → Lorentzian 拟合 → 精度校准
2. 仅器件级，无系统级

**局限性**：
- 无系统级 BER/眼图校准
- 无链路预算评估

**改进点**：
- 增加系统级校准（BER vs OSNR）
- 增加眼图/星座图评估

## 6. 100% 复刻 + 更优秀方案

### 6.1 复刻清单（VPIphotonics 能力对齐）

| VPI 能力 | PoLaRIS 现状 | 复刻方案 | 验收标准 |
|----------|--------------|----------|----------|
| 频域 S-matrix 级联 | ✅ 已有 | 复用 R13 Redheffer 星积 | 误差 < 1e-4 |
| 时域 TLLM 仿真 | 无 | 新增 `TimeDomainSimulator` 类 | 支持激光器瞬态 |
| 频域-时域混合 | 无 | 新增 `HybridSimulator` 类 | 无单时间步延迟 |
| 信号流图（SFG） | 无 | 新增 `SignalFlowGraph` 类 | Mason 增益公式 |
| 系统级链路仿真 | 无 | 新增 `OpticalLink` 类 | NRZ/PAM4/QAM 示例 |
| BER/眼图评估 | 无 | 新增 `BerEvaluator` 类 | Q-factor 计算 |
| 多尺度 PIC 支持 | 部分 | 频域处理长波导，时域处理短器件 | μm-cm 混合 |
| Kerr/TPA 非线性 | 无 | 新增 `NonlinearModel` 类 | 支持自相位调制 |

### 6.2 改进点

1. **频域-时域混合接口**：实现 VPI 风格的"无源频域 + 有源时域"混合，避免纯时域在大规模 PIC 上的精度损失。
2. **TLLM 实现**：基于 Lowery 1987 的 TLLM 模型，实现多段半导体激光器/放大器时域仿真。
3. **信号流图抽象**：用 Mason 增益公式计算系统传递函数，支持复杂拓扑分析。

### 6.3 创新点（标注"创新"）

1. **【创新】AI 驱动的系统级参数优化**：利用 PoLaRIS PPO 框架，自动优化系统级链路参数（激光器偏置、调制器驱动幅度、光纤色散补偿），目标函数为 BER 最小化。
   - *创新逻辑*：VPI 的参数优化依赖网格扫描或梯度下降，PoLaRIS 用 RL agent 探索高维参数空间，适用于非凸、多模态优化。
   - *支持理论*：RL 优化黑盒函数（Sutton & Barto 2018 §13）；BER 作为不可微目标函数，RL 优于梯度方法。
   - *案例预估*：PAM4 链路参数优化，网格扫描需 1000 次仿真，RL agent 预计 50 次达到同等 BER。

2. **【创新】频域 S 参数 → 时域脉冲响应一键转换**：基于 FFT/IFFT，将频域 S(λ) 转换为时域 h(t)，支持任意脉冲激励仿真。
   - *创新逻辑*：VPI 需用户手动切换频域/时域，PoLaRIS 提供 `to_time_domain()` API 一键转换。
   - *支持理论*：LTI 系统频域-时域对偶（Oppenheim & Willsky §3）。
   - *案例预估*：10 Gb/s NRZ 通过 MZI 的时域响应，频域 1000 点 + IFFT < 100 ms。

3. **【创新】系统级仿真与布局布线联合优化**：将系统级 BER 作为布局布线的奖励信号，实现"BER 驱动的布局布线"。
   - *创新逻辑*：VPI 的系统级仿真与布局独立，PoLaRIS 将 BER 反馈到 RL 布局布线 agent，实现端到端优化。
   - *支持理论*：Apollo 2025 的"布线感知布局反馈"扩展到"BER 感知布局布线"。
   - *案例预估*：Clements 8×8 矩阵，BER 驱动布局预计比几何驱动布局 BER 降低 0.5 dB。

## 7. 改进计划路线图

### 7.1 步骤 1（第 1 周）：信号流图与 Mason 增益公式

- **依赖**：R13 完成
- **任务**：新增 `src/polaris/sim/signal_flow_graph.py`，实现 `SignalFlowGraph` 类 + Mason 增益公式
- **验收标准**：MZI/Sagnac/Clements 电路传递函数计算正确，单元测试 ≥6
- **风险**：Mason 公式实现复杂，需严格按 Mason 1956 原文

### 7.2 步骤 2（第 2 周）：TLLM 时域仿真器

- **依赖**：步骤 1
- **任务**：新增 `src/polaris/sim/time_domain.py`，实现 `TimeDomainSimulator` 类 + TLLM 激光器模型
- **验收标准**：激光器瞬态（开启延迟、弛豫振荡）仿真，与 Lowery 1987 结果定性一致
- **风险**：TLLM 数值稳定性需满足 CFL 条件

### 7.3 步骤 3（第 3 周）：频域-时域混合仿真

- **依赖**：步骤 2
- **任务**：新增 `src/polaris/sim/hybrid_simulator.py`，实现 `HybridSimulator` 类，频域 S-matrix + 时域 TLLM
- **验收标准**：无源子电路频域 + 有源器件时域混合，无单时间步延迟（VPI 风格）
- **风险**：FFT/IFFT 接口的同步与边界处理

### 7.4 步骤 4（第 4 周）：系统级链路与 BER 评估

- **依赖**：步骤 3
- **任务**：新增 `OpticalLink` 类 + `BerEvaluator` 类，实现 NRZ/PAM4/QAM 链路示例
- **验收标准**：3 个链路示例，BER vs OSNR 曲线与理论一致（误差 < 1 dB）
- **风险**：BER 计算需足够的统计样本（≥10⁶ bit）
