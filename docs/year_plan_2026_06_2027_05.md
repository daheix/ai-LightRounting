## 学术诚信声明

1. **功能点来源真实**：本计划所有功能点均引用 `feature_gap_full_analysis.md` 中的 P0/P1/P2/P3 功能点列表，禁止臆造。
2. **工作量估算保守**：每月功能点数基于 P0（从零实现，工作量大）、P1（实验性提升，工作量中）、P2（已有增强，工作量小）、P3（创新启动，工作量小）的差异合理分配。
3. **覆盖率提升估算**：基于功能点完成对覆盖率的边际贡献估算，P0 约 +0.8%/个、P1 约 +0.4%/个、P2 约 +0.25%/个、P3 约 +0.15%/个。
4. **P2 月度功能点数超 15**：P2 为已有功能增强（非从零实现），工作量较小，故月度 20-21 个为合理范围。
5. **P3 仅启动**：2027-05 仅启动 P3 创新级 10 个功能点，剩余 28 个作为未来工作。

## 2. 逐月详细计划

### 2026-06：基线对齐月

- **核心目标**: 固化已有能力，构建物理求解器核心能力（RCWA/BPM/varFDTD/FETD/Active FDTD/子网格），填补周期性结构与波导分析空白
- **交付功能点**:
  1. [P0-1] **RCWA 求解器（严格耦合波分析）**（来源: T01 Lumerical/T04 Tidy3D/T07 Photon Design；阻断原因: 周期性结构（光栅/超表面）分析核心能力，光子设计必备）
  2. [P0-3] **BPM 光束传播法（2D/3D 全矢量）**（来源: T05 VPIphotonics/T07 Photon Design；阻断原因: 波导/锥形/耦合器分析核心能力）
  3. [P0-12] **varFDTD 求解器（2.5D）**（来源: T01 Lumerical；阻断原因: 2.5D 变分 FDTD 缺失，宽带波导器件仿真受限）
  4. [P0-13] **FETD 有限元时域求解器**（来源: T07 Photon Design；阻断原因: 有限元时域缺失，等离激元/超材料精确建模受限）
  5. [P0-14] **Active FDTD（纳米激光器）**（来源: T07 Photon Design；阻断原因: Active FDTD 缺失，纳米激光器仿真受限）
  6. [P0-15] **子网格（sub-gridding）加速**（来源: T07 Photon Design；阻断原因: 子网格缺失，局部高分辨率仿真受限）
  7. [P0-11] **完整材料库（含色散/各向异性）**（来源: T01 Lumerical/T04 Tidy3D；阻断原因: 无自研材料库，依赖后端）

  9. [P0-16] **AWG Designer（阵列波导光栅）**（来源: T02 IPKISS；阻断原因: 无 AWG 专用设计器）
  10. [P0-17] **IP Manager（光子 IP 自动化测试）**（来源: T02 IPKISS；阻断原因: 无 IP 自动化测试工具）

  - `tests/test_subgridding.py` 全部通过（4x 加速验证）

## 4. 风险与缓解

### 风险 1：P0 功能点工作量超估

- **风险描述**: P0 阻断级 35 个功能点（RCWA/BPM/varFDTD/FETD/Active FDTD/子网格/GUI 编辑器等）均为从零实现，工作量可能超出预估
- **影响程度**: 高（可能导致 P0 阶段延期，影响后续 P1/P2/P3 阶段）
- **概率**: 中（物理求解器实现复杂度高）
- **缓解措施**:
  1. 优先核心 3 个求解器（RCWA/BPM/varFDTD），确保 2026-06 完成
  2. 采用第三方库（如 MEEP/Tidy3D 后端）降低实现复杂度
  3. 每周评估进度，必要时调整后续月度计划
  4. 预留 2026-09 作为 P0 缓冲月，集中清除剩余 P0

### 风险 2：GUI 版图编辑器开发复杂度高

- **风险描述**: 完整 GUI 版图编辑器（曲线多边形编辑/对象抓取/飞线/拖放/宏 IDE）涉及大量交互逻辑，开发复杂度高
- **影响程度**: 高（GUI 是用户体验最大差距）
- **概率**: 中（GUI 开发需要前端技术栈）
- **缓解措施**:
  1. 分阶段实现：基础框架（2026-07）→ 曲线多边形（2026-08）→ 交互功能（2026-08）
  2. 基于 Web 技术（HTML5 Canvas/WebGL）降低开发难度
  3. 参考 KLayout/gdsfactory+ 开源 GUI 实现
  4. 优先核心交互（层管理/单元管理/视图渲染），宏 IDE 作为增强

### 风险 3：Lumerical/Tidy3D 商业级集成依赖闭源 API

- **风险描述**: Lumerical/Tidy3D 商业级集成可能依赖闭源 API，无法完全对齐商业级能力
- **影响程度**: 中（可能导致部分功能仅达到接近商业级）
- **概率**: 中（商业工具 API 限制）
- **缓解措施**:
  1. 优先自研核心求解器（FDE/EME），减少对闭源 API 依赖
  2. 采用适配器模式，封装闭源 API 差异
  3. 通过基准测试验证与商业工具的一致性
  4. 必要时采用开源替代（如 MEEP 替代 Lumerical FDTD）

### 风险 4：700+ 模块库规模扩展工作量大

- **风险描述**: VPIphotonics 700+ 光子电子模块库规模扩展需要大量器件建模工作
- **影响程度**: 中（模块库规模直接影响覆盖率）
- **概率**: 中（器件建模需要领域知识）
- **缓解措施**:
  1. 分阶段实现：2026-09 启动 200 个 → 2026-12 完成 700+ 个
  2. 优先核心器件（激光器/调制器/探测器/耦合器），覆盖 80% 应用场景
  3. 采用参数化 PCell 模板，减少重复建模工作
  4. 参考 gdsfactory 43+ foundry PDK 开源器件库

### 风险 5：流片验证记录获取困难

- **风险描述**: 500+ 流片验证记录需要实际流片数据，PoLaRIS 作为开源工具可能难以获取
- **影响程度**: 中（流片验证是商业化关键差距）
- **概率**: 高（流片数据通常保密）
- **缓解措施**:
  1. 与 foundry 合作获取脱敏流片数据
  2. 采用开源流片基准（如 TILOS Ariane/OpenROAD）
  3. 通过仿真验证替代部分流片验证
  4. 优先积累 5+ 流片验证记录，逐步扩展到 500+

### 风险 6：P2 月度功能点数超 15

- **风险描述**: P2 阶段月度 20-21 个功能点超出建议的 8-15 个范围
- **影响程度**: 低（P2 为已有功能增强，工作量较小）
- **概率**: 低（增强已有功能比从零实现简单）
- **缓解措施**:
  1. P2 为已有功能增强（非从零实现），工作量较小，月度 20-21 个为合理范围
  2. 优先核心增强（DRC/LVS/布局引擎），次要增强作为后续工作
  3. 必要时将部分 P2 延伸到 P3 阶段
  4. 每周评估进度，确保质量优先

### 风险 7：P3 创新级功能商业化不确定

- **风险描述**: P3 创新级功能（光子 AlphaChip/量子光子/AI 逆向设计）为前沿能力，商业化路径不确定
- **影响程度**: 低（P3 为创新启动，不影响覆盖率）
- **概率**: 中（前沿技术商业化需要市场验证）
- **缓解措施**:
  1. 2027-05 仅启动 10/38 个 P3 功能点，降低风险
  2. 优先启动光子 AlphaChip Edge-GNN（已有 R33 对齐基础）
  3. 通过学术论文验证创新价值
  4. 剩余 28 个 P3 功能点作为未来工作
