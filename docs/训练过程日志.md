## 训练分析

### 策略损失趋势

策略损失经历了四个阶段：
1. **快速下降期** (批次1-7): 5.58 → 1.63，下降73%
   - PPO从随机策略开始学习
2. **平台期** (批次7-50): 1.48 → 1.57，小幅波动
   - 策略已收敛到局部最优
3. **缓慢上升期** (批次50-139): 1.57 → 1.67
   - 策略损失微升，cosine LR调度在后期自动衰减
4. **负值收敛期** (批次356+): -0.0166
   - 离散PPO + 专家奖励塑形后，策略损失转为负值
   - 表明策略已学会选择高优势动作

### 奖励趋势

- 布局 best_reward: 0.508 → 1.28195（提升 152%，突破性进展）
- 布线 best_reward: -0.300 → -0.23679（持续改善中）
- 专家奖励塑形（ICLR'26）注入后，布局策略显著改善

### 关键观察

1. **断点续训机制工作正常**: 沙箱重启后从 171,000ep 正确恢复
2. **离散PPO 优势明显**: 离散动作空间（Categorical）比连续（Gaussian）更适合布局问题
3. **专家奖励塑形有效**: ICLR'26 方法注入光子学知识后 best_reward 提升 152%
4. **Agent 持久化**: 跨批次复用 agent，避免每批重新初始化
5. **自动提交正常**: 每5分钟自动 git commit + push
6. **训练速度**: ~6,655 ep/s（PyTorch 加速 + 离散PPO）

### 预估

- 当前速度: ~6,655 ep/s
- 剩余: 2,000,000 - 172,000 = 1,828,000ep
- 预估剩余时间: ~1,828,000 / 6,655 ≈ 275秒 ≈ 4.6分钟（理论值）
