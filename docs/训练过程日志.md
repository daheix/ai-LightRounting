## 训练分析

### 策略损失趋势

策略损失经历了三个阶段：
1. **快速下降期** (批次1-7): 5.58 → 1.63，下降73%
   - PPO从随机策略开始学习
   - 每批200ep后agent权重更新显著
2. **平台期** (批次7-50): 1.48 → 1.57，小幅波动
   - 策略已收敛到局部最优
3. **缓慢上升期** (批次50-139): 1.57 → 1.67
   - 策略损失微升，可能需要学习率衰减
   - cosine LR调度在2M轮中应该会在后期自动衰减

### 奖励趋势

- 布局best_reward: 0.508（在第1批达到后未改善）
- 布线best_reward: -0.300（在第5批达到后未改善）
- 布线avg_reward持续改善: -109 → -84 → -63（每20批改善约10分）
- 布局avg_reward波动大: 环境对重叠/违规惩罚重，需要更多轮次

### 关键观察

1. **续训机制工作正常**: 每批都能从上一批的检查点加载agent
2. **布线训练较慢**: 每次布线批次耗时~80s vs 布局~4s，差20倍
3. **内存稳定**: 分批策略有效避免了OOM
4. **自动提交正常**: 每5分钟自动git commit
5. **进程稳定**: 已连续运行50分钟无中断
6. **监控守护已启动**: 自动检测+重启，无需人工干预

### 预估

- 当前速度: ~9.3 ep/s
- 2M轮预估: ~59小时
- 布线奖励持续改善中，布局需要更多轮次突破
