## 训练分析

### 策略损失趋势

策略损失经历了两个阶段：
1. **快速下降期** (批次1-7): 5.58 → 1.63，下降73%
   - 这是PPO从随机策略开始学习的阶段
   - 每批200ep后agent权重更新显著
2. **平台期** (批次7-50): 1.48 → 1.57，小幅波动
   - 策略已收敛到局部最优
   - 需要更多轮次或调整超参数来突破

### 奖励趋势

- 布局best_reward: 0.508（在第1批达到后未改善）
- 布线best_reward: -0.300（在第5批达到后未改善）
- avg_reward持续为负（-10495），说明大部分episode的放置/布线仍有问题
- 需要更多训练轮次让策略从探索转向利用

### 关键观察

1. **续训机制工作正常**: 每批都能从上一批的检查点加载agent
2. **布线训练较慢**: 每次布线批次耗时~80s vs 布局~4s，差20倍
3. **内存稳定**: 分批策略有效避免了OOM
4. **自动提交正常**: 每5分钟自动git commit

### 预估

- 当前速度: ~10 ep/s
- 2M轮预估: ~55小时
- 策略损失已进入平台期，需要更多轮次观察是否突破
