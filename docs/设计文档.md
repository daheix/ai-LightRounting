## 2. 数据流

```
输入: circuit.yaml (网表)
  │
  ├─1─▶ NetlistParser → NetworkX 图 + 器件列表 + 连接列表
  │
  ├─2─▶ GraphEncoder (GNN) → 节点嵌入 (每器件64维向量)
  │
  ├─3─▶ PPOAgent → 逐步放置器件 (位置+旋转)
  │     │  reward = 专家奖励(端口对齐/弯曲/交叉/拥塞/热串扰)
  │     │        + 仿真回馈(S参数损耗/约束违反)
  │     │        + 布线可行性(cosWA线长 + CNN拥塞)
  │     ▼
  │   布局结果: {device_name: (x, y, rotation)}
  │
  ├─4─▶ Router 选择:
  │     ├─ CurvyRouter (弯曲波导, LiDAR ISPD'25)
  │     ├─ HybridRouter (混合波导, Ada-Routing ICCAD'25)
  │     ├─ OptoElectricalRouter (光电协同)
  │     ├─ DiagonalGridRouter (8方向A*)
  │     └─ MultiLayerRouter (3D多层)
  │     + Rip-up & Reroute 增强
  │     ▼
  │   布线结果: {net_id: WaveguidePath}
  │
  ├─5─▶ S参数仿真 (SimLoop):
  │     cascade_s_params() → 总S矩阵 → 插入损耗/串扰
  │     ├─ 损耗 < 目标? → 通过
  │     ├─ 约束违反? → 反馈到布局/布线
  │     └─ 迭代优化 (最多N轮)
  │
  ├─6─▶ DRC检查 + 版图验证
  │
  └─7─▶ 输出: GDS + 报告 + 训练数据
```

## 3. 核心模块设计

### 3.1 SimLoop — 仿真回馈闭环

**目标**: 将 S 参数仿真结果反馈到布局布线优化循环中。

```python
class SimLoop:
    """仿真回馈闭环。

    流程: 布局 → 布线 → S参数仿真 → 损耗评估 → 反馈
    如果仿真不通过，自动调整布局/布线参数重试。
    """

    def run(self, circuit, max_iterations=3):
        for i in range(max_iterations):
            # 1. 布局
            placements = self.placer.place(circuit)
            # 2. 布线
            routes = self.router.route(circuit, placements)
            # 3. S参数仿真
            s_result = self.simulator.simulate(circuit, placements, routes)
            # 4. 约束检查
            violations = self.checker.check(s_result)
            if not violations:
                return SimLoopResult(success=True, ...)
            # 5. 反馈: 调整参数
            self.placer.update_from_feedback(violations)
```

**关键接口**:
- `Simulator.simulate(circuit, placements, routes) → SimResult`
  - 调用 `cascade_s_params()` 级联所有器件和波导的 S 参数
  - 返回: 总S矩阵、插入损耗、串扰、反射
- `ConstraintChecker.check(sim_result) → list[Violation]`
  - 检查: 损耗上限、弯曲半径、间距、交叉数
- `FeedbackAdapter.adapt(violations) → PlacementHint`
  - 将仿真违规转化为布局调整建议

### 3.2 IntegratedPipeline — 一体化流水线

**目标**: 将现有 pipeline.py 升级为仿真回馈闭环。

```python
class IntegratedPipeline:
    """一体化流水线: 网表 → 布局 → 布线 → 仿真 → 反馈 → 输出。"""

    def run(self, netlist_path, config):
        # 1. 加载网表
        circuit = self.load_circuit(netlist_path)
        # 2. GNN编码
        embeddings = self.encoder.encode(circuit)
        # 3. 仿真回馈闭环
        result = self.sim_loop.run(circuit, config.max_iterations)
        # 4. DRC + 导出
        drc = self.verify_and_export(result)
        return PipelineResult(result, drc)
```

### 3.3 TrainingPipeline — 训练流水线

**目标**: 用基准数据训练 RL agent，仿真校验每个训练样本。

```python
class TrainingPipeline:
    """训练流水线: 基准数据 → 变体生成 → RL训练 → 仿真校验。"""

    def train(self, benchmark_dir, config):
        # 1. 加载基准数据
        circuits = self.load_benchmarks(benchmark_dir)
        # 2. 生成变体
        variants = self.variant_gen.generate(circuits, config)
        # 3. 训练PPO (含专家奖励+仿真回馈)
        agent = self.ppo_trainer.train(variants, config)
        # 4. 校准验证
        cal_results = self.calibrate(agent, circuits)
        return agent, cal_results
```

## 4. 训练方法论

### 4.1 训练数据来源

| 阶段 | 数据 | 规模 | 用途 |
|------|------|------|------|
| 预训练 | GDSFactory 38个电路 | 38 | 基础布局策略学习 |
| 强化训练 | LiDAR 9个基准 + PICBench 24个 | 33 | 大规模布局布线训练 |
| 变体增强 | 参数扫描+位置扰动+规模缩放 | 1000+ | 数据增强 |
| 校准验证 | 标准成品布局(已知最优解) | 71 | 仿真结果校准 |

### 4.2 奖励函数设计

```
total_reward = (
    + 0.30 * port_alignment_reward     # 端口对齐(专家知识)
    + 0.25 * wirelength_reward          # cosWA弯曲感知线长
    + 0.20 * congestion_reward          # CNN拥塞预测
    - 0.15 * bend_violation_penalty     # 弯曲半径违反
    - 0.10 * crossing_penalty           # 波导交叉惩罚
    - 0.10 * thermal_penalty            # 热串扰惩罚
    + sim_feedback_bonus                # 仿真回馈奖励(通过/不通过)
    - sim_loss_penalty                  # 仿真损耗惩罚(超出目标)
)
```

### 4.3 训练流程

```
Phase 1: 预训练 (GDSFactory小电路, 2-10器件)
  → 学习基础放置策略(避免重叠、端口对齐)

Phase 2: 强化训练 (LiDAR/PICBench, 10-300器件)
  → 学习大规模布局布线策略
  → 仿真回馈闭环: 每N步做一次S参数仿真

Phase 3: 校准验证 (已知最优解的基准电路)
  → 对比自研仿真 vs 基准数据
  → 修正仿真模型参数

Phase 4: 迁移学习 (新电路/新PDK)
  → 离线RL + 经验回放
  → 少样本微调
```

## 5. 仿真校准策略

### 5.1 校准目标

| 指标 | 校准方法 | 数据来源 |
|------|---------|---------|
| 波导损耗 | 对比 Simphony S参数 vs 自研级联 | SiEPIC PDK 测量数据 |
| 弯曲损耗 | 对比 LiDAR 基准损耗 vs 自研估算 | LiDAR 基准 |
| 交叉损耗 | 对比 PICBench 参考损耗 vs 自研估算 | PICBench |
| 总插入损耗 | 对比端到端仿真 vs 基准报告 | 所有基准 |

### 5.2 校准流程

```
1. 加载基准电路 + 已知最优布局/布线
2. 用自研工具重新布线
3. 用自研仿真计算S参数
4. 对比: |自研损耗 - 基准损耗| < 容差?
5. 若超出容差 → 调整仿真模型参数 → 重新校准
```

## 8. 关键技术决策

| 决策点 | 方案 | 理由 |
|--------|------|------|
| 仿真频率 | 每个episode结束时仿真1次 | 平衡精度和速度 |
| 反馈粒度 | 器件级(哪个器件损耗高) | 精确定位问题 |
| 布线器选择 | CurvyRouter(默认) + HybridRouter(混合波导) | LiDAR方法最先进 |
| 训练数据 | 基准+变体混合(1:5比例) | 增强泛化能力 |
| 校准容差 | 插入损耗 ±0.5 dB | 工程可接受范围 |
